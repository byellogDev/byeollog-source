별록 운영자(개인 개발자, 이하 “운영자”)는 「개인정보 보호법」 등 관련 법령에 따라 이용자의 개인정보를 보호하고, 관련 문의와 권리 행사를 원활히 처리하기 위해 이 방침을 공개합니다.

2. SOOP API·Chat SDK 연동

  • 본인 방송·최소 권한: 이용자가 직접 연결한 본인 방송과 신청·동의한 권한에서만 조회·발신합니다.
  • 방송 여부 체크: 생방송 시작·종료에 맞춰 별록 Agent의 이벤트 수집을 자동으로 켜고 끄며, 종료 후 불필요한 연결을 중단합니다.
  • 방송국 정보 조회: 연동 계정과 방송국을 확인하고, SOOP이 제공하는 범위의 방송국·팬·서포터 상태를 기능에 사용합니다.
  • 채팅 조회·발신: 채팅·별풍선·구독·스티커 이벤트를 규칙 실행에 사용합니다. 메시지 발신은 스트리머가 직접 켠 감사·결과·상태 안내에 한정합니다.
  • OAuth: authCode는 토큰 교환 후 즉시 폐기하며, 접근·갱신 토큰은 서버에서 암호화해 보관하고 로그·화면에 노출하지 않습니다.

성별 등 자동화에 필요하지 않은 정보는 기능 조건으로 사용하지 않습니다. 회장·부회장 등 추가 등급은 SOOP이 공식적으로 제공하는 범위가 확인된 경우에만 별도 고지 후 적용합니다.

3. Windows 로컬 처리와 관리형 TTS 처리

Windows PC 처리: OBS·오디오 출력 장치 설정, 선택한 오버레이 이미지와 재생 설정은 이용자의 PC에 저장·처리됩니다.

관리형 TTS 처리: 후원알림과 추첨 음성이 실제로 실행될 때 서버가 확정한 안내 문장만 HTTPS로 Google Cloud Text-to-Speech에 전송하며, 주 음성 장애 시 Cartesia를 예비 제공자로 사용할 수 있습니다. 추첨 후보 전체를 미리 보내거나 합성하지 않습니다. 생성된 음성은 실행 중 Agent에 전달되며 광고·프로파일링 목적으로 사용하지 않습니다.

Agent는 추첨 음성을 영구 캐시하지 않습니다. 별록은 요청 인증값과 음성 무결성 해시를 검증하며, 애플리케이션 로그에 닉네임이나 음성 본문을 기록하지 않습니다. 제공자의 처리·보유는 아래 위탁·국외 이전 내용과 각 제공자 정책에 따릅니다.

4. 보유 및 이용 기간

대상보유 기간삭제 기준

SOOP 접근·갱신 토큰연동 해제, 동의 철회, 토큰 만료·폐기 또는 회원 탈퇴 시까지연결 해제 시 토큰을 폐기하고 이후 API 호출을 중단합니다.
Agent 진단 로그수집일로부터 최대 30일일일 정리 작업으로 삭제합니다.
관리형 TTS 요청·생성 음성실행 요청 처리와 제공자 정책에 따른 기간별록 애플리케이션 로그에 문장·닉네임을 남기지 않으며 Agent는 추첨 음성을 영구 저장하지 않습니다.
가입 신청 기록심사·재신청 확인에 필요한 기간거절·철회된 신청자는 삭제를 요청할 수 있으며 운영자는 확인 후 지체 없이 삭제합니다.
문의 기록응대·분쟁 대응에 필요한 기간목적 달성 후 삭제하며, 이용자는 조기 삭제를 요청할 수 있습니다.
워크스페이스 백업일일 백업 최대 30개, 수동·안전 백업 각 최대 10개보관 개수를 넘은 오래된 백업을 자동 삭제합니다.

법령에 따라 보존해야 하는 경우에는 해당 법정 기간 동안 별도 분리하여 보관하고, 기간이 끝나면 복구하기 어려운 방법으로 삭제합니다.

5. 제3자 제공

운영자는 이용자의 동의 없이 개인정보를 판매하거나 제3자에게 제공하지 않습니다. 다만 이용자가 직접 요청한 기능 수행, 법령에 따른 의무 이행 또는 수사기관의 적법한 절차가 있는 경우 관련 법령이 허용하는 범위에서 처리할 수 있습니다.

7. 쿠키·로컬 저장소

  • 필수 세션 쿠키: bangsel_admin_session은 로그인 유지와 권한 확인에 사용되며 최대 12시간 후 만료됩니다. HttpOnly·Secure·SameSite=Strict가 적용됩니다.
  • 브라우저 로컬 저장소: 화면 테마, 가입 상태 확인 토큰, 이용자가 등록한 일부 표시 설정을 해당 브라우저에 저장할 수 있습니다.
  • 광고, 제3자 행태 추적, 맞춤형 광고를 위한 쿠키는 사용하지 않습니다.
