비업보 관리
비업보로 자동 분류된 Collector 원본을 삭제하지 않고 보관합니다. 잘못 분류된 항목은 여기서 바로 업보로 변경할 수 있습니다.
비업보 기록을 불러오세요.

별풍선 유형 분류

저장된 분류를 수정하는 화면입니다. 처음 보는 유형의 최초 분류는 수신함 상단에서 처리합니다.
학습된 분류 관리
한 번 분류해 저장한 룰렛 결과를 업보 / 비업보로 수정하거나 삭제할 수 있습니다. 삭제한 결과는 다음에 다시 들어오면 처음 보는 데이터로 분류됩니다.
후원 1건에서 여러 번 돌아간 룰렛을 하나의 묶음으로 보여줍니다. 룰렛 무효는 별풍선 후원 원본/통계는 유지하고, 해당 후원에서 생성된 업보만 취소합니다.
룰렛 기록을 불러오세요.

위플랩 룰렛 → 업보 일괄등록
위플랩 후원관리에서 룰렛 결과를 모두 펼친 뒤 여러 행을 한꺼번에 복사해서 붙여넣으세요.
1. 위플랩 복사내용
2. 풍선 개수별 룰렛명 지정
이 매핑은 이번 일괄등록에만 적용됩니다. 룰렛명을 비워두면 해당 풍선 수의 후원은 전체 제외됩니다.
3. 룰렛 결과 분류
등록은 결과명을 그대로 쓰거나 쉼표로 여러 업보종류로 나눌 수 있습니다. 저장된 규칙은 다음 일괄등록에도 자동 적용됩니다.
4. 등록 미리보기
아직 미리보기를 만들지 않았습니다.
유저 관리 · SOOP ID 전환
SOOP ID를 동일인 식별의 기준으로 사용합니다. 별명은 화면 표시용이며 언제든 변경할 수 있습니다.
기존 데이터 변환 등록
기존 방송국 주소의 /station/아이디 부분을 읽어 SOOP ID를 자동 추출합니다. 자동 변환되지 않은 예외 데이터만 여기에서 직접 수정할 수 있습니다.
등록된 SOOP 유저
별명을 변경하면 기존 작업의 표시명도 함께 변경됩니다. 최근 닉네임은 위플랩 일괄등록에서 자동 갱신할 수 있도록 준비한 필드입니다.
DB 백업 / 복구
매일 자동 백업 · daily 최근 30개 · 수동 10개 · 복구 전 안전백업 10개
복구는 안전한 merge 방식입니다. 백업 이후 새로 만든 현재 데이터는 지우지 않습니다. JPG/GIF/MP4 등 브라우저 로컬 파일은 DB 백업에 포함되지 않습니다.
백업 목록을 불러오지 않았습니다.
