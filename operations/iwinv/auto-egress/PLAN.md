# SOOP 목적지별 출발 통신 자동 허용 후보

상태: 구현·검증 중, 자동 개방 미활성화.

- SOOP 공식 HTTPS `broad/access/chatinfo` 응답으로 확인한 접속 정보만 사용한다. 수집기의 요청에서 임의 목적지 IP·포트를 받지 않는다.
- 별도 호스트 제어기가 공식 응답의 계정 일치, 공인 IPv4, 포트, SOOP 호스트를 검증한다. 새 규칙은 단일 목적지 /32의 TCP 출발 통신만 허용한다.
- 수집기에는 iwinv 키를 제공하지 않는다. 전용 제어기에 키를 보관하고 API 키 사용 IP는 운영 서버 한 곳으로 제한한다. 공급자 키의 리소스별 권한 제한은 콘솔·실제 API에서 별도 확인해야 한다.
- 제어기는 지정한 보안 그룹의 조회·개별 규칙 추가·자기가 만든 규칙 삭제만 구현한다. 기존 SSH·인바운드·수동 규칙을 수정·삭제하지 않는다.
- 동시 규칙 수·생성 빈도·대기 시간을 제한한다. 불확실한 생성 결과는 재조회로 확인하며 중복 생성하지 않는다. 활성 연결은 보존하고 자동 생성한 유휴 규칙만 정리한다.
- 별도 후보 규칙으로 API 추가·확인·정리를 시험한다. 운영 반영 시 수집기 설정·큐·이전 이미지 및 감시 복구 파일을 보존한다.
- 성공·실패·권한 오류·한도 초과를 기존 Discord 운영 알림으로 알린다. 비밀키·OAuth 토큰·회원 정보는 메시지나 공개 기록에 넣지 않는다.
