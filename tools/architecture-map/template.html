선은 선택한 역할의 연결만 표시합니다. 화살표는 호출 방향이며, 좁은 화면에서는 지도를 좌우로 움직일 수 있습니다.

Agent는 별도 섬이 아닙니다

웹 API, Edge Function, DB RPC로 이어집니다. 원래 그래프가 HTTP 주소를 함수 호출 관계로 해석하지 못해 연결이 빠졌습니다.

서버와 PC는 DB를 통해 인계합니다

오버레이 워커와 Agent가 같은 소유권·결과 RPC를 사용합니다. 실제로 없는 직접 통신선을 추가하지 않았습니다.

폴더 이름만으로 제외하지 않습니다

lab·Trial 이름이 남은 코드도 운영 진입점에서 재사용됩니다. 참조를 확인한 파일은 서비스 소스로 분류했습니다.

파일별 역할 분류

기존 그래프에 출처가 있는 파일을 분류했습니다. 기호가 추출되지 않은 파일과 그래프 생성 이후의 새 파일까지 모두 포함한 목록은 아닙니다. ‘서비스 소스’는 현재 배포를 보증하지 않습니다.

RPC 호출 이름 ↔ SQL 정의

문자열에 적힌 RPC 이름과 저장소 SQL 정의를 기계적으로 대조한 후보입니다. 동적 이름, 스키마·오버로드, 주석, 변경 이력과 실행 가능 여부까지 확정한 호출 그래프는 아닙니다.

같은 함수의 여러 SQL 정의는 서로 다른 서비스가 아니라 변경 이력일 수 있습니다. 목록의 마지막 파일이 현재 운영 정의라는 뜻은 아닙니다.

외딴 점을 해석하는 방법

화면의 점 하나는 대개 함수 하나가 아니라 코드 묶음(커뮤니티)입니다. 내부에 연결이 있어도 다른 묶음과의 선이 없으면 외딴 점으로 보입니다.

SQL 변경 이력

앱이 함수명으로 호출하지만 AST는 SQL 정의와 연결하지 못합니다. 별도 RPC 이름 대조에서 추적합니다.

테스트·설정·도구

CI, 스케줄러, 빌드 명령으로 실행되는 파일은 import 선이 적습니다. 연결 없음은 삭제 근거가 아닙니다.

출처 미해결

외부 라이브러리 이름이나 파서가 소스를 해석하지 못한 참조일 수 있습니다. 억지로 서비스에 연결하지 않았습니다.

읽기 전용 로컬 분석입니다. 실제 요청·추첨·DB 변경·운영 배포를 수행하지 않았습니다. 원본 그래프는 보존되어 있으며, 이 지도는 주요 서비스 경계를 보강한 별도 보기입니다.
