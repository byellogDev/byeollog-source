# 소스 연결 지도

기존 Graphify 결과를 보존하고, AST가 연결하지 못한 주요 HTTP·RPC·이벤트·설정 경계를 별도 보기로 보강합니다. 운영 코드나 DB를 변경하거나 외부 서비스에 요청하지 않습니다.

## 생성

Python 3 표준 라이브러리와 Git만 사용합니다. 먼저 저장소 루트에 로컬 Graphify `graphify-out/graph.json`이 있어야 합니다.

```powershell
python tools/architecture-map/build.py
```

- `graphify-out/architecture.html`: 네트워크 연결 없이 열 수 있는 서비스 지도·파일 분류·RPC 대조·외딴 묶음 분석.
- `graphify-out/architecture-evidence.json`: 근거 경로·줄·앵커·파일 SHA-256, 원본 그래프 SHA-256, 분석 기준 커밋.
- 기존 `graph.json`과 `graph.html`은 수정하지 않습니다.
- 위 산출물은 로컬 분석 자료입니다. 생성기가 이를 커밋·업로드하지 않습니다.

## 해석 원칙

1. 주요 연결은 사람이 호출 측·처리 측을 대조한 근거를 보관합니다. 외부 플랫폼은 호출 측만 확인했다고 구분합니다.
2. 재생성 시 근거 앵커가 없어지면 오류로 중단합니다. 앵커가 남아 있어도 주변 의미가 바뀔 수 있으므로 변경 후 검토를 대체하지 않습니다.
3. RPC 이름 대조는 정규식 기반 후보입니다. 동적 이름, 스키마·오버로드·주석·권한·현재 배포 상태는 자동으로 확정하지 않습니다. SQL 정의 여러 개는 변경 이력일 수 있습니다.
4. 파일 분류는 원본 그래프의 출처 파일 기준입니다. 기호 없는 파일, 문서 의미, 새 파일 등 전체 저장소의 완전한 관계를 보증하지 않습니다.
5. `lab`·`Trial` 이름만으로 실험 코드를 제거하지 않습니다. 운영 진입점에서 참조하는 오버레이 워커 파일은 명시적으로 서비스 소스로 분류합니다.
6. 출처 미해결 참조와 연결 없는 노드는 미사용·삭제 가능 판정이 아닙니다. 서비스 지도에 가짜 선을 추가하지 않습니다.

연결의 추가·수정은 `build.py`의 `link()` 목록에서, 시각적 표현은 `template.html`에서 관리합니다. 근거에는 비밀값·개인 URL·회원 데이터 대신 저장소 소스의 경로와 일반 계약 문자열만 사용합니다.
