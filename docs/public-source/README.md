# 공개 소스와 개발 이력

이 저장소는 별록의 실제 개발 소스와 Git 이력을 공개하기 위해 운영 원본에서 분리한 사본입니다. 운영 원본을 공개로 전환하거나 과거 작업을 새로 만든 이력으로 대체하지 않았습니다.

## 보존한 기록

- [GitHub Releases](https://github.com/byellogDev/byeollog-source/releases)에도 과거 버전 기록을 게시합니다. [원본 게시일순 이력과 대응 기준](RELEASES.md)에서 원본 86건과 공개 게시물을 대조할 수 있습니다. GitHub의 재게시 시각과 원본 출시일은 구분합니다.
- 2026-10-23 기준 원본의 도달 가능한 커밋 250개를 모두 보존했습니다. `main`의 132개와 별도 과거 공개본의 이력을 포함합니다.
- 각 커밋의 작성·커밋 시각과 부모 커밋 관계를 대조했습니다. 실패·수정·대규모 반입·늦은 통합 기록도 유지했습니다.
- 최초 커밋은 2026-08-25의 v0.7.0.71 기준본 반입입니다. 최초 개발부터 모든 작업이 세부 커밋으로 남아 있다는 뜻은 아닙니다.
- 공개용 정리로 파일 내용과 커밋 해시가 달라졌습니다. [커밋 대응표](commit-map.txt)는 원본 해시와 공개 해시를 연결합니다. 원본 저장소와 원본 태그는 비공개 상태로 그대로 보존합니다.
- 과거 PR·CI 링크는 원본의 기록입니다. 공개 저장소에서 과거에 PR 검토·CI가 실행된 것처럼 재생성하지 않았습니다. 이 저장소의 Actions 기록은 공개 후 실행한 검사만 보여 줍니다.

## 공개 사본의 차이

실제 계정 이름·일부 식별값·운영 호스트·개인 연락처를 예시 값으로 바꾸었습니다. 작성자 이름은 유지하고 개인 이메일은 GitHub 비공개 이메일 또는 명시적인 익명 이메일로 바꾸었습니다. 소스의 과거 제품명·클래스 이름과 공개된 제3자 문헌 출처는 유지합니다.

재배포 권한을 확인하지 못한 이미지·음원·영상·PDF·바이너리는 과거 이력에서도 제외했습니다. JavaScript와 HTML에 인코딩된 이미지·음원, 비공개 인계 자료도 포함합니다. 현재 빌드에 필요한 자산은 새로 만든 `ASSET OMITTED` 표시 이미지, 무음 WAV, 안내 PDF로 대체했습니다. [대체 자산 목록](placeholder-assets.json)을 확인할 수 있습니다. 제품의 실제 화면·소리를 재현하는 자료가 아닙니다.

실제 환경변수, 사용자 데이터, 백업, 원문 로그, 비공개 복구 사본, GitHub Actions 첨부 파일은 가져오지 않았습니다. 현재 파일과 전체 공개 이력의 알려진 비밀 패턴, 정규식 안의 식별값, 인코딩된 HTML을 검사했습니다. 자동 검사는 모든 민감정보를 탐지한다는 보증이 아닙니다.

## 실행과 검증

Node.js 22와 Windows .NET 8을 사용합니다. 운영 서비스에 연결하는 자격증명은 포함하지 않습니다. 공개 소스 폴더에서 운영 배포·운영 DB 마이그레이션을 실행하지 마세요.

```sh
npm ci --ignore-scripts --no-audit --no-fund
npm run verify:source
node tools/scan-publication.mjs --tracked
npm run test:public
npm run build:web
```

```powershell
dotnet build apps/windows-agent/HurogiCollector.csproj -c Release
dotnet run --project tools/agent-ui-tests/AgentUiTests.csproj -c Release
```

`test:public`은 전체 Node 검사에서 원본 자산·원본 캡처 해시가 필요한 6개 검사를 명시적으로 제외합니다. [검사별 이유](test-exclusions.json)를 출력하며, 다른 실패는 그대로 실패 처리합니다. `npm test`에는 원래 검사를 남겼으므로 제외 자산을 복원하지 않으면 해당 검사가 실패합니다.

AgentStoreTests의 과거 영상·음원 자산 검사는 원본이 필요하므로 공개 CI에 포함하지 않습니다. 과거 릴리스 문서의 운영 원본 검증 수치와 공개 사본의 검사 결과를 합산하지 않습니다. 공개 빌드 성공은 실방송·고객 PC·서명된 배포 패키지 검증을 대신하지 않습니다.

`source-manifest.json`은 공개 사본 기준의 파일 해시입니다. 이전 운영 원본 manifest는 [기록용 사본](original-source-manifest.json)으로 남겼으며, 공개 사본이 운영 원본과 바이트 단위로 동일하다는 의미가 아닙니다.

## 이용 범위

이번 공개에서 별도의 오픈소스 재사용 라이선스를 새로 부여하지 않았습니다. 의존성 및 제3자 코드의 기존 라이선스·출처 표시는 유지합니다. 제품명·외부 자산·운영 서비스 이용 권한은 소스 공개와 별개입니다.
