- 대상: Windows Agent 패키지, 웹 다운로드 경로와 웹·관리 서버의 업데이트 목록. 수집기·DB·권한 변경 없음.

## 목적과 변경 전 문제

금액별 묶음 전체를 끄지 않고 특정 후원 카드 한 장만 방송에서 숨기고 복원할 수 있도록 한다.

## 변경 내용과 소유 구성요소

- 로컬 풍벽지 편집기 카드의 **×** 버튼으로 개별 숨김. **숨긴 풍벽지** 목록에서 검색·개별 복원한다.
- 일반·개별 배치·백두산 카드에 적용하며, 방송 오버레이에는 편집 버튼이 나오지 않는다.
- PC·계정별로 설정을 저장하고 재시작 후 유지한다. 카드 자리·원본 후원·업보·통계·백두산 진행은 유지한다.
- Windows Agent 버전, 서명된 업데이트 목록, 패키지 출처·해시 기록, 설치기 기본값, 공개 다운로드 경로와 관련 검사를 1.0.0.53으로 갱신했다.
- 선택형 위플랩 설정과 기존 SOOP 경로는 유지한다. URL 미설정 사용자의 동작도 유지한다.

## 사용자 영향과 복구

- 업데이트 후 풍벽지 배치 편집에서 ×로 숨기고 숨긴 풍벽지 목록에서 복원한다. 숨김은 삭제가 아니다.
- 복원 시 해당 방송 회차와 금액별 표시 설정이 켜져 있어야 한다. 기존 7일 보관 기간을 지난 원본 카드를 되살리는 기능은 아니다.
- 숨긴 카드 자리를 자동 압축하지 않는다. 다른 PC로 숨김 설정을 동기화하지 않는다.
- 1.0.0.52 설치 자산과 이전 웹·관리 서버 배포 영수증을 보존한다. 자동 업데이트는 단조 증가 sequence 조건 때문에 단순히 이전 피드를 다시 올리지 말고 새 sequence의 복구 카탈로그를 사용한다.
- 구버전은 개별 숨김 설정을 지원하지 않아 숨긴 카드가 다시 보일 수 있으므로 복귀 시 방송 화면을 확인한다.

## 제거·보존한 파일과 근거

기존 설치 파일·사용자 데이터·수집 자료 삭제 없음. 새 실행 파일·서명·패키지 메타데이터만 추가했다. 비공개 배포 영수증·검증 로그·인증정보는 게시하지 않는다.
