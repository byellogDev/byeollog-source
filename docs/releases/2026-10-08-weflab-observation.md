# 위플랩 URL 비교 관측 준비 · 2026-10-08

후속: [독립 결과 수신 조사](2026-10-08-weflab-independent-results.md). 기존 결과 조회는 진단용이며 대체 수집기의 작동 조건으로 사용하지 않는다.

## 상태와 범위

- 상태: 연구 체크포인트, 별도 서버 후보 예약 완료. 운영 수집 전환 아님.
- 확인: 2026-10-08 KST. 시작 예약: 2026-10-09 19:00 KST.
- 대상: 승인된 단일 스트리머의 URL 후보와 기존 운영 후원·룰렛 데이터 대조.
- 기존 [직접 WebSocket 운영 전환](2026-10-08-direct-production.md)과 독립적인 연구다.

## 목적과 변경 전 문제

URL 기반 후원/결과 테스트는 있었으나 실제 방송의 계정 격리, 원문, 연결 공백 및 기존 수집과의 비교 체계가 없었다. 결과 API가 저장값이 없으면 추첨을 생성하는 성질을 확인해 실시간 자동 조회와 분리했다.

## 변경 내용과 소유 구성요소

- `tools/weflab-lab`: 계정 고정 수신기, 원문/규칙/자원 기록, 페이지 단위 기준 데이터 조회, 서로 유일한 후원 비교, 기존 결과 확정 후 제한적인 결과 대조 도구.
- iwinv 연구 전용 서비스와 서버 타이머 예약. 자격증명 없는 별도 컨테이너, CPU/메모리/증거 용량 제한.
- 연구 연결·검사 자료와 운영 데이터는 분리. 연구 서버에는 DB 키나 SOOP OAuth를 전달하지 않는다.

## 사용자 영향과 복구

후보가 운영 후원을 추가 저장하거나 화면 추첨을 실행하지 않는다. 실제 방송에서 유의미한 표본을 받아야 결과를 판단할 수 있다. 기존 오버레이의 플랫폼 연결에 구독만으로 참여 가능한지, 특수 후원, 다회 룰렛, 장기 재연결은 미검증이다. 결과 조회 도구는 자동 실행하지 않으며 저장 결과가 확인되지 않은 건은 미검증으로 둔다. 연구 서비스/타이머만 중지하면 복구되며 운영 배포를 되돌릴 필요가 없다.

## 제거·보존한 파일과 근거

기존 파일 삭제 없음. 비공개 주소·연결 설정·계정 정보·원문과 실행 receipt는 `.local` 및 연구 전용 서버 폴더에 보존하고 게시에서 제외한다.
