## 목적과 변경 전 문제

룰렛 금액과 회전 수를 직접 등록하던 설정을 후원알림 오버레이 주소와 수집 ON 중심으로 단순화했다. 이름은 선택 사항으로 분리하고, 사용 흐름을 짧은 안내와 PC·모바일 화면으로 제공한다.

## 변경 내용과 소유 구성요소

- 웹: ‘업보 수집 설정’, 필수 오버레이 주소와 ON/OFF, 하단 ‘이벤트명 사전 등록’. 공개 링크 가져오기·수동 회전 수 입력을 제거했다. 기본 이름은 한국 시간 기준 첫 룰렛 결과 월 + 후원 수량(예: 10월 330개).
- 안내: 기본 명칭은 ‘후원알림 오버레이’. 서비스 이름은 접힌 도움말의 예시에만 사용한다. 현재 미지원 서비스 주소는 거절한다.
- 관리·수집 API: 주소 소유 계정과 제공자 설정을 검증하고, 룰렛 조건을 자동 읽어 후원 시점에 고정한다. OFF 이전에 시작한 건은 마무리하고 새 업보만 중단한다. 통계·풍벽지 후원 수집은 유지한다.
- DB: 앞선 보류로 복귀했던 트리거·함수를 재활성화하고 수집 제어 5개를 protocol 1로 전환했다. 기존 저장 주소의 실제 설정 6개를 다시 확인했다. 적용 직후 유효 ON 1계정이며 나머지는 주소 입력과 ON 설정이 필요하다.
- Agent: 1.0.0.56 안내 문구와 명칭 정리. 서명된 안정 카탈로그 및 기본 설치 다운로드 반영. 이전 설치 자산 보존.

## 사용자 영향과 복구

- 대시보드의 업보 수집 설정에서 지원하는 후원알림 주소를 저장하고 ON으로 켠다. 주소 없는 계정은 새 업보 수집을 켤 수 없다. 이미 시작한 후원은 마무리하며 후원 통계·풍벽지 자료는 보존한다.
- 제공자 설정을 읽지 못하면 새 룰렛을 추정하지 않고 확인 필요로 남긴다. 미지원 조건과 주소는 저장을 거절한다. 투네이션은 예시이며 연결 지원 완료를 뜻하지 않는다.
- **운영 결과의 주 경로는 기존 채팅 수집이다. 별도 오버레이 시험 결과의 운영 합산·누락 보완 승격은 포함하지 않는다.** 화면에 없는 결과를 자동 복구했다고 주장하지 않는다.
- 배포 후 모든 계정이 방송 대기였으므로 실제 새 후원부터 업보 완료까지는 아직 확인하지 않았다. 고객 PC 업데이트와 방송 화면 확인도 별도다.
- 복구 시 비공개 이전 배포 ID로 웹·관리·수집 API를 함께 되돌리고, 검증된 복구 SQL로 기존 함수·트리거·제어를 함께 복귀한다. 설정·후원 원본을 삭제하거나 과거 자료를 자동 재처리하지 않는다. Agent 1.0.0.55 자산과 이전 서명 피드는 보존한다.

## 제거·보존한 파일과 근거

임시 인증 검증 함수는 소스 작업 공간에서 제거했고 검증 전용 원격 배포 3개도 삭제했다. 기존 운영 배포·원문·설정·이전 설치 패키지는 복구를 위해 보존한다. 실제 주소·회원 식별자·운영 인증값·정확한 배포 증거는 비공개로 유지한다.
