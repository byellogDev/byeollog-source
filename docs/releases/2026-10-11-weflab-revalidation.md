## 상태와 범위

- 연구 검증 기록. 운영 변경·데이터 승격·추가 제공자 결과 API 호출 없음.
- 2026-10-11 07:23 KST 기준, 승인된 한 계정의 위플랩 별도 저장소와 기존 운영 후원·결과를 읽기 전용으로 대조했다.
- 구간: 10/09 03:00~10/11 07:23 KST. 실제 후원은 10/09 20:07:52~10/10 20:12:32 KST다. 자정을 넘어 같은 방송의 자료를 포함한다.
- 이전 [10/09 검증](2026-10-09-weflab-live-comparison.md)의 후원 19건·룰렛 7건은 이번 새 결과에 중복 합산하지 않는다.

## 목적과 변경 전 문제

단일 회차만 확인했던 오버레이 주소 기반 수집의 새 실방송 결과, 다회 순서 및 기존 경로와의 차이를 확인한다. 기존 결과를 정답으로 강제하거나 새 경로의 추가 결과를 임의로 삭제하지 않는다.

## 변경 내용과 소유 구성요소

제품 코드 변경 없음. 계정·구간을 고정한 전체 배열과 SQL count를 대조하고 원본 결과 응답을 로컬에서 재해석했다. 비공개 자료에 원본 응답, 요청 계획·규칙, 대응 근거 및 차이를 보존했다. 원문·회원 식별자·오버레이 URL은 게시하지 않는다.

### 다회 결과의 차이

10/09 21:17:26 KST의 510개 후원은 기존 DB에서도 예상 회차 13으로 기록돼 있다. 오버레이 경로가 21:20:29에 저장한 제공자 원본 응답에는 결과 13개가 있지만, 기존 경로에는 12개만 있다. 기존 기록은 사용자 종료가 아니라 21:21:21 대기 만료 상태다.

새 배열에서 동일 항목 1회를 제거하면 기존 12개 배열과 순서까지 일치한다. 해당 항목이 연속된 10·11번째에 있어 어느 한 회차가 빠졌는지는 두 배열만으로 구분할 수 없다. **새 경로가 기존 기록에 없는 결과 한 개를 확보한 사례**다. 봇 미송신, 기존 수신·분류·저장 중 누락 중 어느 단계인지는 확정하지 않았다. 해당 시각의 일반 collector 로그 조회는 0건이었으며, 이를 오류가 없었다는 증거로 사용하지 않는다. 방송 화면 녹화와 대조한 결과도 아니다.

### 후원 대응과 지연

- 기존 1초 기준으로 26건은 양방향 유일 대응한다. 두 건은 원본 시각 차이가 각각 1.642초·1.849초여서 이 기준을 벗어났다.
- 추가 진단에서 계정·후원자 ID·수량을 그대로 요구하고 허용 시각을 5초로 넓히면 28건 모두 양방향 유일 대응한다. 모호한 대응·중복 UID·충돌은 0이다. 두 건을 원래 1초 검사의 통과로 소급하지 않는다. 시각 차이가 난 원인은 미확정이며 해당 후원에는 룰렛 결과가 없다.
- 후원 발생부터 시험 DB 첫 저장까지 0.206~9.805초. 결과 예약은 시험 DB 첫 저장 후 182.551~183.054초다. 승인된 180초 지연 정책에 따른 값이며 네트워크 수신 지연과 구분한다.
- 결과 저장은 기존의 마지막 결과 저장보다 약 127.964~186.212초 뒤였다. 실제 업보 즉시 반영 속도를 개선했다고 해석하지 않는다.

### 담당권과 현재 상태

일반 후원 28건 중 Agent 27건·서버 1건의 수집 주체를 확인했다. 결과 조회 6건은 모두 Agent다. 조회 시점 Agent 담당권은 유효했고 서버는 standby, 최근 오류 없음·전송 대기 0이었다. 서버 실행 소스 해시는 현재 소스와 일치한다. 서버 증거·시험 DB를 보존했다.

같은 후원의 중복 UID·충돌은 없었지만 서버와 Agent의 전체 과거 연결 이력이 없어 모든 인계 공백이 0이라고 보증하지 않는다. 이번 재검증은 위플랩 결과 API를 다시 호출하지 않았다. sql 응답 6건은 해당 요청에서 저장 결과를 반환했다는 근거이며 API가 어떤 상황에서도 결과를 생성하지 않는다는 보장은 아니다.

## 사용자 영향과 복구

- 기존 SOOP 운영 처리와 위플랩 별도 수집을 유지했다. 예약 비교를 재개하거나 서비스를 재시작하지 않았다.
- 추가 결과 한 개를 운영 업보에 자동 합산·복구하지 않았다. 향후 승격 때 후원·회차 대응, 중복 방지, 특수 배수와 & 분리의 원자 처리, 부분 수신 보완 정책을 정해야 한다.
- 다회 11개 전체 순서 일치는 이번에 새로 확인했다. 13개 결과 차이의 정확한 누락 단계, 실제 화면 일치, 전체 담당권 전환 공백, 다른 계정·범위 규칙·규칙 변경은 미확정이다.
- 읽기 전용 검증이라 운영 복구 작업은 없다. 기존 기록을 정정할 때도 이번 원문과 비교 자료를 보존한다.
