# 위플랩 방송 표시 결과 관측 설계 · 2026-10-08

## 상태와 범위

연구 체크포인트. 2026-10-08 소스·문서 검토. [독립 결과 경로 조사](2026-10-08-weflab-independent-results.md)의 후속이며 구현·OBS 연결·운영 배포는 하지 않았다.

## 목적과 변경 전 문제

시청자가 보는 실제 룰렛 결과를 수집하려는 요구에 맞춰 설계를 재검토했다. 추첨 응답이나 결과 알림 수신만으로 화면 표시를 입증할 수 없고, 위플봇 채팅은 누락될 수 있어 기준에서 제외한다.

## 변경 내용과 소유 구성요소

- OBS 렌더러 접속 경로를 조사했으나, 사용자가 방송 프로그램을 OBS로 한정하지 않아 공통 우선안으로 채택하지 않았다. 확정 결과 전달·페이지 연동·Agent 단일 렌더러·프로그램별 어댑터를 구분했다. 경쟁하는 두 번째 추첨 인스턴스와 추첨 재호출은 제외한다.
- 슬롯의 선행 DOM 삽입, 다회 결과 대기열, 원판 canvas, 타임아웃·취소 등 표시 완료를 오판할 수 있는 지점을 기록했다.
- 원래 응답·회차별 표시 상태·방송 프로그램 출력 근거를 구분하는 계약 초안과 시험 기준을 정했다. 공통 수집 경로 선정은 미완료다.
- 기존 Agent OBS 클라이언트의 재사용 범위와 별도 CDP 어댑터 필요성을 확인했다. 문서만 변경했다.

이 검토는 수집 성공 건수를 추가하지 않는다. 실제 응답 수신·회차별 화면 일치·채팅 없는 수신·재연결·부하는 모두 앞으로 검증한다.

## 사용자 영향과 복구

운영 동작 변화 없음. OBS 전용 시험은 실행 설정과 재시작이 필요할 수 있으나 전체 사용자에게 이를 요구하는 구조로 정하지 않았다. 일반 사용자용 기능으로 바로 배포하지 않는다. 10월 9일 URL 관측 예약은 기존 후원 연구 범위이며 화면 결과 검증으로 간주하지 않는다. 되돌릴 운영 배포 없음.
