# Agent 1.0.0.47 · 풍벽지 커스텀 · 2026-10-04

## 상태와 범위

- 상태: **운영 반영 완료**. 2026-10-04 07:23 KST 기준 후보·운영 소스와 공식 다운로드 대조 완료.
- 대상: Windows 풍벽지 설치본, 공식 다운로드, 웹·관리 런타임의 서명 업데이트 피드(sequence 10048).
- 이전 운영 기준: [Agent 1.0.0.46](2026-10-02-agent-10046.md).
- 기능 후보와 상세 검증: [풍벽지 커스텀 후보](2026-10-04-wallpaper-custom.md). 후보 소스 e0ac6b1에서 실행 파일을 빌드했습니다.

## 목적과 변경 전 문제

고정된 폰트·빨간 닉네임·카드 배경을 방송 화면에 맞게 조정할 수 있도록, 검증한 커스텀 기능을 실제 설치본과 자동 업데이트에 반영합니다.

## 변경 내용과 소유 구성요소

- 로컬 풍벽지 배치 화면의 **풍벽지 커스텀**에서 폰트 파일 링크, 후원자 닉네임 색, 후원 수량 색, 카드 배경색, 카드 크기에 맞는 글자 크기를 설정합니다.
- 작은 카드의 기존 한 줄 문구·표시 방식은 유지합니다. 줄 수 선택이나 텍스트 내용 편집 기능은 포함하지 않습니다.
- 계정별 로컬 저장과 미리보기, 취소, 기본 스타일 복원을 지원합니다. 일반·묶음 해제 카드·백두산의 채워진 칸에 적용됩니다.
- 설치 패키지는 버전 1.0.0.47, 업데이트 피드는 sequence 10048입니다. 기존 설치 루트 9개 파일과 이전 버전 자산을 보존합니다.
- 웹 후보는 운영 소스에서 다운로드 리디렉션과 피드만 변경했습니다. 관리 후보는 피드만 변경했습니다. 기존 운영 소스와 차이 나는 로컬 파일은 배포에 섞지 않았습니다.

## 사용자 영향과 복구

- 1.0.0.47로 업데이트한 뒤 로컬 배치 화면에서 커스텀 버튼을 사용할 수 있습니다. 기본 스타일로 복원하면 기존 출력으로 돌아갑니다.
- 외부 폰트는 HTTPS 파일 링크와 CORS 허용이 필요합니다. 링크가 끊기면 기본 폰트로 표시합니다. 커스텀 설정은 계정별로 이 PC에 저장됩니다.
- 이미 설치된 프로그램이 실제로 새 버전을 받았는지, 각 고객 PC에서 설치·재실행·OBS 표시가 정상인지는 별도 사용자 확인 범위입니다. 새 EXE의 모든 보안 제품 통과를 보증하지 않습니다.
- 회귀 시 비공개 배포 기록의 직전 웹·관리 배포를 복원하고 1.0.0.46 설치 자산을 사용할 수 있습니다. 자동 업데이트 복구는 단조 증가 sequence를 유지하는 후속 수정본으로 수행합니다.

## 제거·보존한 파일과 근거

이전 설치 자산·서명 신뢰 키·사용자 설정·후원 자료를 삭제하지 않았습니다. 개인 서명키와 배포 인증값·운영 기록은 공개 저장소에 포함하지 않습니다. 바이너리는 설치 자산 전용 저장소에 게시합니다.
