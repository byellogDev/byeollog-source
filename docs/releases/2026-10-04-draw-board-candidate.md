# Agent 1.0.0.49 후보 · 후원 연동 뽑기판

## 상태와 범위

- 상태: **로컬 후보 구현·검증, 운영 설치본과 업데이트 피드 미반영**.
- 확인일: 2026-10-04 KST.
- 대상: Windows Agent, 로컬 풍벽지 편집기, 로컬 OBS 브라우저 화면.
- 기존 SOOP 수집기·후원 원장·업보·웹/관리 API·DB 권한·배포 도메인은 변경하지 않았습니다.
- 이전 운영 기준: [Agent 1.0.0.48](2026-10-04-agent-10048.md). 이 문서는 해당 운영 버전의 후속 기능 후보입니다.

## 목적과 변경 전 문제

후원으로 번호를 열어 상품을 공개하는 방송용 뽑기판을 추가합니다. 사용자가 지정한 참고 사이트의 역할을 참고하고, 화면·코드·이미지는 새로 작성했습니다.

시작 전에 스트리머가 **후원 연동 랜덤 추첨** 또는 **직접 번호 입력**을 고릅니다. 공개 화면이 추첨까지 담당하면 OBS 새로고침과 여러 브라우저 소스가 중복 추첨을 만들 수 있어, Agent가 추첨과 저장을 담당하고 공개 화면은 결과를 읽기만 하도록 분리했습니다.

## 변경 내용과 소유 구성요소

### Windows Agent

- `DrawBoard`가 계정별 로컬 저장소에서 한 판을 관리합니다. 이름, 칸 수, 열 수, 상품별 수량과 빈 칸을 설정합니다. 최대 500칸·20열, 후원당 최대 20회, 보관 최대 100판·16 MiB입니다.
- 시작할 때 암호학적 난수로 상품 위치를 섞어 고정합니다. 랜덤 모드는 아직 열리지 않은 번호를 선택합니다. 수동 모드는 번호를 입력해 공개합니다. 진행 중 모드·상품·수량 변경은 지원하지 않습니다.
- 랜덤 모드는 진행 중인 방송 하나에 연결합니다. 기존 `baekdusan-log` 읽기 API의 페이지를 끝까지 조회해 시작 위치를 잡고, **그 뒤에 수집된 일반 별풍선 중 설정 수량과 정확히 일치하는 후원**만 처리합니다. 배수 환산·미션·구독·지난 후원 소급 추첨은 하지 않습니다.
- 방송 종료를 확인한 마지막 페이지까지 처리하고 판을 종료합니다. 다음 방송의 후원은 섞지 않습니다. 수동 종료와 남은 칸 소진도 지원합니다.
- 결과·후원 식별자·조회 위치·공개 순서를 한 파일에 함께 저장합니다. 임시 파일 flush 후 원자적으로 교체하며, 저장 실패 시 화면에 결과를 공개하지 않습니다. 재전송·중복 클릭·동시 요청은 다시 추첨하지 않습니다.
- 실행 중 판은 기존 풍벽지 변경 알림을 이용하며 요청 간 최소 5초, 알림이 없을 때 약 15초 주기로 확인합니다. 네트워크 지연·페이지 추가 처리 시간은 별도입니다. 대기/수동/종료 상태는 후원 API를 호출하지 않습니다.
- 재시작 시 같은 판을 복원하고, 계정 전환 시 이전 작업을 취소하고 계정별 파일을 분리합니다. 손상된 파일은 덮어쓰지 않습니다. 이전 판의 요약만 평상시 전송하고 결과 내역은 펼칠 때 읽습니다.

### 로컬 편집기·OBS

- 풍벽지 편집 화면의 **뽑기판** 버튼 → 설정·실시간 진행·이전 기록 화면.
- 밝은 설정 패널과 남색 번호판을 분리하고, 당첨은 금색, 꽝은 어두운 칸으로 구분합니다. 데스크톱에서 판 전체와 설정 스크롤을 분리합니다.
- **OBS 오버레이 주소 복사** 버튼과 직접 복사할 수 있는 주소 필드를 제공합니다. 기본 주소는 `http://127.0.0.1:43120/overlay/draw-board`, 권장 화면 크기는 1920×1080입니다.
- Agent가 저장한 공개 일정에 맞춰 번호 강조 → 결과 공개를 순서대로 표시합니다. 종료된 판의 마지막 공개가 끝나기 전에는 새 판으로 바꾸지 않습니다.
- 공개 응답에는 미공개 상품 배치와 내부 후원·방송 식별자를 넣지 않습니다. 여러 OBS 소스와 새로고침은 추첨을 일으키지 않습니다. 연결이 끊어지면 기존 화면을 숨기고 연결 상태를 표시합니다.
- 로컬 HTTP의 기존 호스트/Origin 검증과 GET/HEAD 제한을 유지합니다. 조작은 현재 계정의 신뢰된 편집기 메시지 경로에서만 받습니다.

## 사용자 영향과 복구

- 현재 배포된 사용자 프로그램에는 아직 변경이 없습니다. 정식 설치·업데이트 배포는 별도 단계입니다.
- 판은 **현재 PC의 계정별 로컬 자료**입니다. 여러 PC 사이의 공유나 클라우드 복원은 제공하지 않습니다. Agent가 꺼져 있으면 새 추첨은 진행되지 않으며, 재실행 시 같은 방송의 보관된 후원부터 이어 확인합니다.
- 서버 후원 보관 기간이 지난 장기 오프라인 구간은 복구를 보장하지 않습니다. 오류는 편집기에 표시하고 조회 위치를 임의로 건너뛰지 않습니다.
- Agent 종료 동안 예정된 공개 시각이 지난 결과는 재접속 시 이미 공개된 결과로 복원합니다. 미접속 시간의 애니메이션을 모두 재생하는 기능은 아닙니다.
- 부하·시각 가독성은 판 크기와 상품명 길이에 영향을 받습니다. 500칸 실방송 부하, 실제 후원→OBS 지연, 고객 PC 재시작·장기 연결은 미검증입니다.
- 폐기 시 이전 1.0.0.48 운영 설치본을 유지합니다. 후보의 계정별 `draw-board-v1.json`은 기존 풍벽지/후원 원장과 독립이므로 원본을 보존한 채 후보만 교체할 수 있습니다.

## 제거·보존한 파일과 근거

레거시·설치 자산·복구 자료를 삭제하지 않았습니다. 새 뽑기판 소스·시험 코드·리소스만 추가하고 Agent 내부 연결 지점과 UI 리소스 캐시 버전을 변경했습니다.
