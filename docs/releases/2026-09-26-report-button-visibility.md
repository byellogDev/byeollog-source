## 목적과 변경 전 문제

리포트 버튼을 누르면 긴 통계 표 아래에 패널을 열면서 화면 위치는 유지했다. 100행 통계가 있는 전체 대시보드에서 클릭 함수와 API가 정상 실행되어도 결과가 화면 아래에 있어 무응답처럼 보이는 배치를 재현했다. 앞선 독립 패널 검사는 실제 관리 모달과 긴 표의 조합을 확인하지 못했다.

## 변경 내용과 소유 구성요소

- 리포트를 통계 표 아래에서 버튼 바로 아래로 이동했다.
- 클릭 즉시 패널에 초점을 주고 화면 안으로 이동한다. 조회 중 다시 눌러도 패널을 보여주며 중복 요청은 만들지 않는다.
- 펼침 상태를 접근성 속성으로 알리고, 닫으면 원래 버튼으로 초점을 돌린다.

## 사용자 영향과 복구

새로고침 후 리포트 버튼을 누르면 기간 선택과 생성 상태를 바로 볼 수 있다. 첫 방송일~최근 방송일 기본값과 기존 집계는 유지한다. 이번에는 실제 운영 계정으로 로그인한 클릭 검증을 하지 않았으며 이를 합성 화면 검사와 구분한다. 문제 시 비공개 승격 기록의 직전 관리자 배포로 되돌린다.
