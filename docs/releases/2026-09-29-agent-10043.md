# Agent 1.0.0.43 · 2026-09-29

## 상태와 범위

- 상태: 관리자 API·공식 다운로드·서명 업데이트 피드 운영 반영 완료.
- 확인 시각: 2026-09-29 KST, 최종 운영 응답·다운로드 해시 확인 완료. 정확한 시각과 배포 ID는 비공개 운영 기록에 보관.
- 대상: 관리자 백두산 읽기 API, Windows 풍벽지 Agent, 공식 다운로드·서명 업데이트 피드.
- 이전: [Agent 1.0.0.42](2026-09-29-agent-10042.md). 구현 근거와 규칙: [백두산 후보](2026-09-29-wallpaper-baekdusan.md).
- DB 스키마·권한·운영 수집기·원본 후원과 통계는 변경하지 않는다.

## 목적과 변경 전 문제

일반 후원에서 시작 건과 목표 숫자를 정해 백두산을 표시할 수 있도록 검증한 후보를 설치 가능한 버전으로 발행한다. 금액 범위를 통째로 합치는 대신 직전 참여 건 뒤에 수신된 다음 숫자의 첫 후원만 포함한다.

## 변경 내용과 소유 구성요소

- Agent: 백두산 만들기·관리, 기존 기록 및 신규 후원 채움, 일반 카드 중복 제거·해제 복원, 계정별 저장과 재시작 복구, 영역 이동·크기·열 수 조절.
- 관리자: 기존 인증·계정 권한 확인 뒤 해당 방송의 일반 후원만 읽는 `baekdusan-log` 추가. 원장 변경 없음.
- 웹·관리자: 1.0.0.43, RSA-PSS 업데이트 피드 sequence 10044. 새 실행 파일은 정식 소스에서 빌드하고 기존 설치 루트 9개를 그대로 보존한다.
- 후보 소스: 웹 647개 중 다운로드 경로·피드 2개 변경, 관리자 143개 중 제어 모듈·피드 변경 및 읽기 모듈 1개 추가. 관련 없는 미배포 웹 파일 3개는 운영본 유지.
- 보호된 Preview 생성 동안 같은 프로젝트의 기존 인증값을 재사용하도록 사용자 승인을 받았다. 적용 범위는 후보 생성 후 원복하고 운영 도메인은 승격 전까지 유지했다.

Vercel 승격은 별도 운영 빌드를 생성했다. BUILDING 상태에서는 완료로 처리하지 않았으며, READY 확인 후 검증한 후보와 운영 소스 790개·라우팅·hnd1 지역을 다시 대조했다.

인증된 새 API에서 실제 후원을 조회하고 사용자 PC의 WebView2·OBS에서 진행되는 실방송 흐름은 남은 확인 항목이다. 기존 구현 단계의 합성 검사와 읽기 전용 DB 확인을 실제 사용자 수락으로 대신하지 않는다.

## 사용자 영향과 복구

- 업데이트 후 로컬 풍벽지 편집기의 `백두산 만들기·관리`를 사용한다. 방송과 시작 후원을 고르고 목표 숫자를 입력한다.
- 방송당 한 묶음, 묶음당 최대 500칸, 로컬 전체 1,000칸·10묶음 제한. 시작 선택은 보관된 풍벽지 기록(최근 7일) 범위다.
- 설정은 해당 PC·계정에 저장된다. 다음 방송으로 임의로 이어 채우지 않으며 서버 백업·다른 PC 자동 동기화는 제공하지 않는다.
- 장애 시 묶기 해제로 일반 카드를 복원한다. 웹·관리자 피드 장애 시 기록한 직전 배포로 복구한다. 이미 업데이트한 PC를 sequence를 낮춰 강제 다운그레이드하지 않는다.
