# Agent 1.0.0.55 · 숨긴 풍벽지 빈칸 제거

## 상태와 범위

- 상태: 정식 Agent 업데이트 및 안정 피드·다운로드 반영.
- 확인일: 2026-10-09 KST.
- 대상: Windows Agent 편집기·로컬 방송 오버레이. 수집·후원·업보 데이터 변경 없음.
- 이전 버전: [1.0.0.54 UI 캐시·트레이 수정](2026-10-09-agent-10054-ui-cache-tray.md). [개별 숨김 최초 후보](2026-10-09-wallpaper-hidden-cards.md)의 자리 유지 정책을 사용자 요청에 따라 일반 묶음에서 변경한다.

## 목적과 변경 전 문제

숨긴 풍벽지를 배치한 뒤 `visibility`만 바꿔, 중간 후원자 행을 숨겨도 그 높이와 칸이 남았다. 이제 일반 묶음은 숨긴 카드를 제외한 목록으로 크기·열·행·카드 좌표를 계산한다.

## 변경 내용과 소유 구성요소

- 편집기와 localhost 방송 오버레이가 동일한 숨김 필터로 쌓는다. 맨 아래·중간·맨 위를 숨기거나 여러 건을 숨겨도 남은 카드 사이에 숨김 칸을 예약하지 않는다.
- 그룹의 원본 카드 ID와 저장 배치 기준은 유지한다. 숨긴 기준 카드가 있어도 그룹 위치가 초기화되지 않으며, 묶음을 움직인 뒤 복원할 카드도 같은 배치에 포함한다.
- 전체가 숨겨진 그룹은 자동 배치 공간을 차지하지 않는다. 이후 새 후원은 보이는 카드부터 쌓이고, 복원하면 기존 후원 순서로 합류한다. 최근 기록·숨김 목록은 삭제하지 않는다.
- 로컬 규칙이 없는 이전 그룹 스냅샷에서도 동일하게 분리한다. 개별 배치 카드의 절대 위치와 백두산 번호·진행 데이터는 유지한다.
- 빌드별 UI 자산 추출은 기존 1.0.0.54 방식을 유지한다. 새 바이너리 설치 시 이전 캐시가 새 배치 코드를 가리지 않는다.

## 사용자 영향과 복구

- Agent 1.0.0.55로 업데이트한 뒤 적용된다. 숨겼던 기록은 그대로 읽고 빈칸 없이 다시 쌓는다.
- 설정한 그룹 영역의 크기·최대 행 수는 유지할 수 있지만, 숨김 카드 때문에 카드 사이에 빈 행을 남기지 않는다.
- 자동 업데이트 실패 시 [다운로드](https://byeollog.com/agent/download)로 설치한다. 실제 고객 PC 업데이트 여부는 별도 확인한다.
- 복구: 이전 1.0.0.54 패키지·서명 피드·배포를 보존했다. 필요하면 다운로드와 두 안정 피드를 함께 이전 검증 배포로 복구한다. 숨김 설정·원본 후원은 삭제하지 않는다. 구버전에서는 숨김 자리 유지 동작으로 돌아간다.

## 제거·보존한 파일과 근거

신규 설치·업데이트 출처 기록만 추가하고 이전 릴리스 파일은 보존한다. 실행 파일은 전용 자산 저장소에 게시하며 소스 저장소에는 출처·매니페스트만 기록한다.
