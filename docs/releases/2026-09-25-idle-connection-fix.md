# 연구 후보 유휴 연결 오종료 수정 · 2026-09-25

## 상태와 범위

- 상태: 연구 후보 서버 반영, 운영 수집 경로 전환 아님.
- 반영 시각: 2026-09-25 18:29:34 KST. 원래 종료 시각 9월 26일 14:00 KST 유지.
- 대상: `tools/soop-direct-lab/client.mjs`, 회귀 검사, 연구 관측용 bundle.
- 이전 기준: [원인 조사](2026-09-25-idle-disconnect-investigation.md). 기존 Chromium·운영 데이터·권한·배포 도메인은 변경하지 않았다. 사용자가 취소한 예약 자동화는 재개하지 않았다.

## 목적과 변경 전 문제

후보는 채팅 또는 pong이 180초 없으면 `transport_silent`로 종료했다. 감독기는 이를 `needs_review`로 처리하여 다음 메시지가 생겨도 다시 연결하지 않았다. 조용하지만 유효한 연결도 끊을 수 있는 결함이다. 실제 당시 공급자 측 무응답 원인까지 확정한 것은 아니다.

## 변경 내용과 소유 구성요소

- SDK와 같은 60초 SOOP 애플리케이션 keepalive를 유지하고 별도 WebSocket ping 및 무수신 단독 종료를 제거했다.
- 180초 무수신은 `idle_unconfirmed`로 기록한다. 다시 프레임이 오면 같은 연결에서 수신 상태를 갱신한다.
- 쓰기 오류·10초 쓰기 시한·버퍼 상한 초과는 구별하여 종료한다. 쓰기 완료는 로컬 전송 완료이며 상대 서버 정상 응답을 보증하지 않는다.
- 명시적 소켓 종료·오류, 입장·소유자 검사, 감독기 수신 불일치·텔레메트리 소실·자원 한도·정리 실패 중단을 유지했다.
- 자동 재연결 정책은 바꾸지 않았다. 독립 확인된 방송 종료는 다음 방송을 기다리며 그 외 오류는 검토 후 재개한다.

## 레퍼런스 대조

9월 23일 [설계 비교](../research/2026-09-23-collector-reference-comparison.md)와 보관된 소스가 있다. 직접 WebSocket, 연결 관리자 분리, 제한된 자원, 입장 ACK 확인을 참고했지만 복구 정책까지 동등하게 구현하지 않았다.

Meloming의 [SOOP connector](https://github.com/dylabs/meloming-chat-collector/blob/85b8aa1dd9284ded8717c97dc6aee556b5bcf70a/worker/internal/connector/soop.go)는 60초 ping·180초 읽기 시한을 사용한다. [manager](https://github.com/dylabs/meloming-chat-collector/blob/85b8aa1dd9284ded8717c97dc6aee556b5bcf70a/worker/internal/manager.go)의 `handleErrors`는 연결과 goroutine을 회수하고 coordinator에 알리며, `Reconcile`은 필요한 연결을 다시 만든다. 연결 실패 backoff도 존재한다. 별록 연구 후보는 오류 증거 보존을 위한 중단 정책이므로 시한 값만 같아도 복구 동작은 다르다.

이번 수정은 공식 SDK의 애플리케이션 keepalive와 실제 합성 재현을 근거로 한다. 참조 프로젝트의 인증·전송 경로가 별록 OAuth 경로와 같다는 가정이나 외부 코드 반입은 하지 않았다. 향후 운영 채택 전에는 계정별 제한된 재연결, 대기 간격, 소유권 재확인, 공백·중복 검사를 별도로 구현·검증해야 한다.

## 사용자 영향과 복구

운영 데이터에는 기존 Chromium 경로만 반영된다. 후보가 조용한 방을 정상으로 단정하지도, 침묵만으로 닫지도 않는다. 양쪽 모두 조용한 상태에서는 네트워크 정상 여부를 입증할 수 없으며, 기존 경로만 콘텐츠를 받으면 비교 감독기가 불일치를 감지한다.

문제 발생 시 새 연구 서비스만 중지하고 증거를 보존한다. 오종료가 확인된 옛 후보를 자동 복구하지 않는다. 수정 전 구간은 `before-idle-fix.json`과 receipt의 `previousIdleSegment`로 구분하며 실제 검증 시간에 공백을 포함하지 않는다.

## 제거·보존한 파일과 근거
