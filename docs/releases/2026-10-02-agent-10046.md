# Agent 1.0.0.46 · 자동로그인 복원 수정 · 2026-10-02

## 상태와 범위

- 상태: **운영 반영 완료**. 2026. 10. 2. 19시 59분 4초 KST 최종 확인.
- 대상: Windows Agent의 암호화 세션 저장, 공식 다운로드 및 서명 업데이트 피드(sequence 10047).
- 이전 기준: [Agent 1.0.0.45](2026-09-30-agent-10045.md). 서버 인증·권한·DB·수집기는 변경하지 않습니다.

## 목적과 변경 전 문제

자동로그인을 체크해도 프로그램을 다시 실행할 때마다 로그인을 요구한다는 제보를 조사했습니다. Agent의 저장 검사가 갱신 토큰을 20자리 이상으로 제한했습니다. [Supabase Auth의 토큰 생성 코드](https://github.com/supabase/auth/blob/master/internal/models/refresh_token.go)는 12자리 토큰도 발급합니다. 로그인 후 저장 실패를 잡아 메모리 세션만 유지하는 경로 때문에 로그인 자체는 성공해도 다음 실행에서는 복원할 파일이 없었습니다.

합성 12자리 토큰으로 기존 코드의 저장 예외를 재현했습니다. 고객 PC의 실제 토큰·파일을 읽거나 원격으로 같은 예외를 확인한 것은 아닙니다. 기존 검사에서는 긴 임의 토큰만 사용해 이 결함을 놓쳤습니다.

## 변경 내용과 소유 구성요소

- Agent: 갱신 토큰을 내부 형식을 해석하지 않는 불투명 문자열로 저장합니다. 임의 최소 길이를 제거하고 빈 값·공백·제어문자·과도한 크기는 거부합니다.
- Windows 사용자별 DPAPI 암호화, 계정·워크스페이스 고정, 복원 시 서버 인증·권한 검사, 명시적 로그아웃 및 체크 해제 삭제 동작은 유지합니다.
- 검사: 12자리 토큰 저장, 별도 .NET 프로세스 복원, 평문 비노출, 잘못된 입력 거부 시 이전 세션 보존, 자동로그인 해제를 추가했습니다.
- 배포: Agent 버전 1.0.0.46, 서명 피드 sequence 10047. 이전 설치 루트 9개 파일과 기존 다운로드 자산을 보존합니다.

## 사용자 영향과 복구

- 새 버전 적용 후 **자동로그인을 체크하고 한 번 로그인**해야 저장됩니다. 이전 버전에서 저장하지 못한 토큰은 복원할 수 없습니다.
- 새 버전 고객 PC 재실행, 실제 서버 토큰 갱신을 포함한 장기 로그인 유지, 새 EXE에 대한 고객 보안 제품 판정은 미검증입니다.
- 조사 중 별도 위험도 발견했습니다. 서버의 세션 검증 과정이 인증 제공자의 일시 오류를 401로 바꾸면 저장 세션을 지울 수 있습니다. 이번의 매번 재실행 증상과 구분하며, 서버 오류 분류 수정은 이 릴리스에 포함하지 않습니다.
- 회귀 시 직전 웹·관리 배포와 1.0.0.45 설치 자료가 복구 기준입니다. 이미 새 Agent를 받은 사용자는 필요 시 더 높은 버전·sequence의 수정본으로 복구합니다.

## 제거·보존한 파일과 근거

원본 로그인 정보·서명 개인키·운영 로그는 게시하지 않습니다. 기존 설치 자산·회원 데이터·풍벽지 설정을 삭제하지 않습니다. 바이너리는 전용 릴리스 저장소에만 게시합니다.
