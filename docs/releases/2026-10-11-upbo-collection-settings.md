# 업보 수집 설정 후보 · 2026-10-11

## 상태와 범위

- 상태: 소스 후보. 운영 DB 적용·웹 승격·Agent 설치 파일 배포 없음.
- 확인일: 2026-10-11 KST.
- 대상: 관리 화면, 관리자 API, 수집 설정 조회, DB 스냅샷, Agent 안내 문구.
- 이전 기준: [직접 WebSocket 전체 전환](2026-10-11-direct-all-production.md), [오버레이 비교](2026-10-11-weflab-revalidation.md). 기존 연구·운영 기록을 대체하지 않는다.

## 목적과 변경 전 문제

기존에는 사용자가 룰렛 금액·회전 수를 직접 등록해야 했다. 주소 입력과 수집 스위치를 중심으로 바꾸고 이벤트명 지정만 선택으로 남긴다. 제품의 기본 명칭은 ‘후원알림 오버레이’로 통일하며 특정 서비스 이름은 접힌 도움말의 주소 예시에만 사용한다.

## 변경 내용과 소유 구성요소

- 웹: ‘업보 수집 설정’에 주소 입력 → ON → 자동 수집 순서를 배치. 필수 주소·전체 스위치를 상단에, 선택 이벤트명을 하단에 배치. 공개 링크 가져오기와 수동 회전 수 입력 제거. PC·모바일·다크 모드·키보드 초점 고려.
- 안내: 기본 이벤트명은 한국 시간 기준 첫 룰렛 결과의 월 + 후원 개수(예: 10월 330개). 사전 지정한 금액 범위의 이름은 이후 후원에 적용. 진행 중·기존 이름 유지.
- 관리자 API: 로그인 권한과 계정 소유 범위 검증, URL과 연결된 숲 계정 검증 후 설정 저장. 설정 조회·저장 실패 시 입력 유지. 기존 권한 경계 유지.
- 수집: 제공자 설정의 금액·총 회전 수를 자동 확인해 후원별로 고정. 선택 이벤트명은 수집 조건이 아님. OFF는 새 업보 작업만 막으며 이미 시작된 다회 결과는 기존 제한 내에서 마무리한다. 후원 통계·풍벽지 수집 유지.
- 설정 갱신: 후원 발생 시 필요할 때만 확인. DB 예약으로 다중 실행·실패 반복 요청을 계정별 60초 간격으로 제한. 공급자 요청은 10초·2MiB·리디렉션 차단. 설정 읽기 요청만 사용하고 추첨 생성 요청은 하지 않는다.
- 오래된 설정: 2분 이상 갱신되지 않은 설정으로 새 룰렛을 추정하지 않는다. 후원에 진단 사유를 영속 보존하고 설정 화면에 확인 필요 건수를 표시. 같은 방송에서 앞선 미확인 후원이 있으면 기존 10분 상관 구간의 후속 결과를 다음 후원에 임의 배정하지 않고 검토 대상으로 보존한다.
- DB: 계정별 설정·선택 이름은 RLS 및 서비스 전용 인증 RPC로 보호. 기존 이름 이관, 과거 후원 스냅샷 유지. URL을 가진 기존 계정도 계정/설정 검증 전에는 실효 ON이 되지 않는다. URL 없는 계정의 새 업보는 OFF가 된다.
- Agent: 설정 이름·도움말을 ‘후원알림 오버레이’로 통일. Agent에 주소를 저장하는 것만으로 웹 수집이 켜지지는 않음을 안내.

## 사용자 영향과 복구

- 지원 구현은 현재 Weflab 후원알림 주소의 검증한 설정 형식이다. 투네이션은 주소 유형의 예시이며 연결 지원을 구현한 것은 아니다. 미지원 주소/조건은 ON을 거절하고 이전 상태를 보존한다. 가변 회전 수 옵션·중첩 금액 조건은 확인 전 거절한다.
- 운영 후원 결과의 주 경로는 기존 채팅 수집이다. 별도 오버레이 시험 결과의 운영 합산·누락 보완 승격은 이 후보에 포함되지 않는다. 주소 저장으로 연구 계정 등록이나 결과 재조회를 자동 시작하지 않는다.
- 기존 설정을 읽지 못한 후원은 자동 복구했다고 표시하지 않는다. 실제 결과와 대조한 운영 검토가 필요하다. 설정 조회 장애·지연 시 새 업보 처리가 보류될 수 있으며 통계 자료는 보존한다.
- 운영 적용 전 보호된 후보의 실제 로그인·설정 저장·후원부터 결과까지의 흐름을 확인해야 한다. 이 후보는 소스 검사만으로 운영 준비 완료를 주장하지 않는다.
- 적용 순서: 이전 앱·DB 함수 정의/권한을 비공개 보존 → DB 마이그레이션과 수집 런타임 호환 확인 → 동일 검증 후보 승격. DB만 먼저 적용한 채 장시간 운영하지 않는다. 새 설정 열을 사용하는 앱을 DB보다 먼저 배포하지 않는다.
- 복구: 이전 검증 앱 및 기존 트리거/함수·제어 설정으로 함께 복귀. 새 기록·설정 테이블은 보존하고 운영 데이터 삭제나 자동 과거 재처리 금지. 현재는 미배포이므로 운영 복구 작업 없음.

## 제거·보존한 파일과 근거

업보 수집 화면의 수동 등록·공개 가져오기 UI만 제거했다. 다른 기능에서 사용하는 공개 가져오기 API와 원본 기록·기존 매핑은 보존했다. 실험 원문·오버레이 실주소·회원 정보·로컬 화면/시험 자료는 Git에 포함하지 않는다.
