# 2026.09.24-minecraft-candidate · 2026-09-24

> 후속 상태: 리뷰 결함 수정 후 사용자의 명시적 승인으로 웹·관리자를 운영 반영했습니다. 아래는 당시 후보 검증 기록이며 최신 상태는 [운영 릴리스](2026-09-24-minecraft-production.md)에 구분했습니다.

> 후속 코드 리뷰에서 정지 연동 재활성화와 게임 쿠키에 따른 일반 OAuth 회귀를 확인했습니다. 아래 통과 기록만으로 운영 승격하지 않습니다. [리뷰 결과·재현·수정 조건](../reviews/2026-09-24-candidate-code-review.md).

## 목적과 변경 전 문제

마크 메인 1의 `BYEOLLOG_MAIN3_HANDOFF_20260924.md`와 43개 파일의 크기·SHA-256을 확인하고, 현재 별록 운영 기준에 필요한 수정만 병합했습니다. **보호된 Preview 통합 검증 단계이며 운영 승격은 하지 않았습니다.** Minecraft 후원 브리지 구현 완료를 뜻하지 않습니다.

인계본 전체를 덮어쓰면 최신 별록 로그인·보안·화면 변경이 사라질 수 있으므로, 이미 반영된 기능과 새 수정이 필요한 부분을 구분했습니다. 두 DB 마이그레이션은 실제 적용 이력을 확인했고 다시 실행하지 않았습니다.

## 변경 내용과 소유 구성요소

- 웹 프록시: Minecraft 조회 경로에만 서버 ID·요청 ID·시각 헤더를 전달합니다. 외부 요청이 내부 런타임 인증값을 덮어쓸 수 없습니다.
- 관리자 런타임: 잘못된 JSON과 4KB 초과 본문을 거절합니다. 문자열·Buffer·이미 파싱된 객체·스트림 모두 검사합니다.
- 공유 SOOP 콜백: 정상 별록 서명 state가 일치하면 남아 있는 게임 쿠키보다 우선합니다. state 없는 모호한 요청은 어느 시도도 소비하지 않고 거절합니다.
- 게임 연동: 만료 세션은 공급자 인증코드를 교환하기 전에 거절하며, 상충하는 code/authCode도 거절합니다.
- 서버 발급 도구: DB 호출 전에 비공개 키 파일을 배타적으로 저장합니다. 응답 유실 시 파일을 보존하고 `--resume`으로 같은 키와 권한을 재확인합니다. 실제 서버 키 발급은 수행하지 않았습니다.

배포된 운영 기준과 후보의 소스 차이는 웹 1개·관리자 3개 파일입니다. 빌드 설정·의존성·기존 화면 파일을 교체하지 않았습니다.

실제 후보 API 결과:

- 허용 서버 A 200, 같은 사용자에 권한 없는 서버 B 404.
- 잘못된 키 401, 과거·미래 10분 요청 각각 400.
- malformed JSON 400, 이미 파싱된 4KB 초과 본문 400.
- 동일 nonce 동시 요청은 200 한 건과 409 한 건.
- grant 취소 404, binding 정지 404, 서버 폐기 401, 회전 전 키 401.

시각 검사는 여유를 둔 ±10분 값이며 정확히 ±5분 경계의 실시간 검증을 뜻하지 않습니다. malformed JSON은 플랫폼 선행 파서의 400 응답일 수 있어 모든 응답이 동일한 JSON 코드라고 단정하지 않습니다.

합성 binding·서버·grant·nonce·audit는 검증 후 정리했습니다. 해당 binding·서버·nonce·audit 잔여 건수 모두 0을 확인했습니다. 실사용 계정과 권한은 변경하지 않았습니다.

## 사용자 영향과 복구

운영 도메인을 후보에 연결하지 않았습니다. 후보 프런트의 관리자 주소는 **후보 관리자 URL**이므로 이 프런트 후보를 그대로 운영 승격하면 안 됩니다. 운영 반영 시 올바른 관리자 배포 대상으로 구성한 별도 승격 후보를 만들고 다시 검증해야 합니다. 이번 후보가 운영 전환 준비까지 완료된 것은 아닙니다.

승인된 동일 프로젝트 내 기존 인증값 재사용으로 보호된 후보를 구성했습니다. 환경변수 값이 반환되지 않는 조회 API의 특성을 확인하는 과정에서 정상 동작하지 않는 초기 후보가 생성됐으며, 최종 검사에서 제외했습니다. 민감 값을 새 공개 파일에 저장하지 않았습니다. 임시로 확장한 환경변수 Preview 대상은 원래대로 복원했습니다. 로컬 배포 도우미 교체 실수와 초기 후보 실패의 상세 증거는 비공개 기록에 보존했습니다.

기존 운영 배포 ID, 최종 후보 ID와 프로젝트 연결, 환경 복원, 원격 소스 대조, HTTP 결과 및 정리 증거는 `.local/minecraft-handoff/`에 있습니다. 공개 문서에 실제 회원·비밀키·운영 로그 원문은 넣지 않습니다.

## 운영 승격 전 남은 항목

1. 실제 SOOP·Microsoft 신규/기존/충돌/동시 탭 흐름과 정상 별록 로그인·가입·연동 완료를 등록된 콜백 조건에서 확인해야 합니다. 이번 자동 회귀검사가 이를 대체하지 않습니다.
2. 기존 수집의 새 이벤트 수신과 출력은 이 후보 점검에서 수행하지 않았습니다. 별도 48시간 수집 연구의 결과를 이 후보의 검증 결과로 섞지 않습니다.
3. 요청 제한과 보관 정책은 [운영 검토](../integrations/minecraft-candidate-review.md)에 구분해 기록했습니다. 분산 요청 제한과 정기 정리 작업은 아직 적용되지 않았습니다. 실제 서버에 키를 제공하고 조회를 상시 활성화하기 전 구현·검증할 항목입니다.

## 제거·보존한 파일과 근거

운영·복구 파일과 이전 연구 자료는 제거하지 않았습니다. 합성 검증 데이터만 정확한 테스트 ID 범위로 정리했습니다. `.local/`과 `.server-credentials/`는 Git 게시 대상에서 제외합니다.
