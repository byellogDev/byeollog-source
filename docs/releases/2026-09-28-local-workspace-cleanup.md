# 2026.09.28-local-cleanup · 로컬 작업 공간 용량 정리

## 상태와 범위

- 상태: 로컬 정리 완료, 문서 변경. 운영 배포 없음.
- 확인일: 2026-09-28 KST.
- 대상: 개발 작업 공간의 승인된 원본 영상과 재생성 가능한 캐시, 과거 루트 저장소의 오래된 Git 임시 객체.
- 이전 개발 상태: [직접 수집 연결 교체 준비](2026-09-28-direct-handoff-preparation.md). 해당 후보와 진행 중 관측 자료는 보존했다.

## 목적과 변경 전 문제

작업 공간의 읽을 수 있는 일반 파일 합계가 약 73.97GiB였다. 원본 영상, 시뮬레이션 캐시와 실패한 Git 쓰기 작업의 임시 파일이 큰 비중을 차지했다. 소스나 복구 기준을 삭제하지 않고 확실한 대상부터 정리했다.

## 변경 내용과 소유 구성요소

| 삭제 대상 | 용량 | 판단 근거 |
| --- | ---: | --- |
| 원본 방송 영상 2개 | 21.47GiB | 사용자가 두 파일 삭제를 명시적으로 승인 |
| Blender REPLAY 시뮬레이션 캐시 8개 디렉터리 | 8.11GiB | 생성 스크립트의 캐시 설정 확인, 원본 장면과 완성 이미지·영상 보존 |
| 작업 공간 npm 캐시 | 0.93GiB | 다운로드 캐시이며 패키지 명세·lockfile·현재 설치 의존성은 보존 |
| Git의 오래된 `tmp_obj_*` 195개 | 9.88GiB | Git이 garbage로 집계, 최종 변경일 8월 24일, 정상 객체와 refs 제외 |
| **합계** | **40.38GiB** | **삭제 전 실제 파일 길이 합계 43,356,880,754바이트** |

모든 대상의 절대 경로가 작업 공간 안에 있는지, 재분석 지점이 없는지, 삭제 직전 크기가 계획과 같은지 확인했다. 일반 삭제 대상에는 Git 추적 파일이 없었다. 정확한 파일 목록과 전후 증거는 비공개 로컬 기록에 보존했다.

## 사용자 영향과 복구

- 웹·Agent 소스나 운영 서비스 동작 변경은 없다. 직접 WebSocket 관측도 계속 유지한다.
- Blender 캐시는 원본 장면·생성 스크립트로 다시 생성해야 하며, npm 캐시는 필요한 패키지를 다시 다운로드한다.
- 승인된 원본 영상은 영구 삭제했다. 이 작업에서 별도 복사본을 만들지 않았으므로 복구를 보장하지 않는다.
- Git 정상 객체·브랜치·과거 미완료 변경은 그대로다.

## 제거·보존한 파일과 근거

운영 안정본, 릴리스·아카이브 복구 자료, 현행 소스, 관측 원문·집계, 설치 배포물, 고유한 모델·제작 자산은 보존했다. 접근 제한 디렉터리와 링크는 전체 용량 조사에서 제외되어 조사 합계는 디스크 전체 사용량이 아니다. 오래되었다는 이유만으로 기능 작업 폴더를 통째로 제거하지 않았다.
