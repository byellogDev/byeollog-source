# 2026.09.29 · 풍벽지 편집 도구 가독성과 화면 끝 배치

> 후속: 사용자 승인 후 [Agent 1.0.0.42 운영 배포](2026-09-29-agent-10042.md)를 완료했습니다. 아래는 배포 전 후보 검증 당시 기록입니다.

## 상태와 범위

- 상태: Windows Agent 수정 후보. 로컬 빌드·브라우저 검증 완료, 설치 파일·자동 업데이트 피드는 미배포.
- 확인 날짜: 2026-09-29 KST.
- 대상: `apps/windows-agent/Ui/wallpaper_editor.html`. 후원 수집, 사용자 데이터, OBS 카드 렌더러, 설치·인증 프로토콜 변경 없음.
- 이전 배포: [설치 EXE 1.0.0.41-r2](2026-09-28-installer-r2.md). 이 문서는 새 Agent 배포를 의미하지 않습니다.

## 목적과 변경 전 문제

선택 정보와 편집 버튼이 1920×1080 카드 캔버스 안에 있어 미리보기 축소에 따라 글씨까지 작아졌습니다. 10~11px 글씨는 약 0.58배 화면에서 6px 정도로 보였습니다.

다른 카드의 수직선에 맞춘 뒤 화면 끝으로 끌면 기존 정렬 잠금이 계속 적용됐습니다. 이동 좌표는 이미 화면 끝에서 제한되므로 잠금 해제 거리까지 도달할 수 없었습니다. 캔버스 오른쪽 끝 1920에서 20px 앞인 1900에 잠긴 경우, 끝까지 끌어도 약 12px의 화면 여백이 남는 조건을 재현했습니다. 별도로 미리보기 테두리와 정수 높이를 기준으로 축소율을 계산하면서 작은 표시 여백도 생겼습니다.

## 변경 내용과 소유 구성요소

- 선택 정보·영역 조절·카드 크기·맨 위 버튼을 캔버스 밖의 도구막대로 이동했습니다. 글씨 14px, 조절 버튼 최소 높이 36px를 유지하고 좁은 창에서는 줄바꿈합니다.
- 드래그 조절점과 다음 열 안내도 화면 크기를 기준으로 표시합니다. 카드와 방송 출력 크기는 바꾸지 않습니다.
- 화면 끝에 접근하면 주변 카드 정렬 잠금보다 화면 경계를 우선합니다. 화면 중앙의 카드 간 정렬 잠금은 유지합니다.
- 테두리를 제외한 실제 미리보기 폭으로 축소율과 드래그 좌표를 계산해 오른쪽 표시 여백을 없앴습니다.

## 사용자 영향과 복구

- 다음 Agent 업데이트에 포함하면 편집 도구가 커지고 주변 정렬선에 막히지 않고 화면 끝으로 이동할 수 있습니다.
- 다음 열을 오른쪽에 둔 묶음은 해당 공간을 계속 예약합니다. 실제 카드를 오른쪽 끝에 두려면 기존의 다음 열 방향 전환을 사용해 왼쪽으로 둡니다.
- 기존 배치·크기·계정·권한과 OBS 전송 형식은 유지합니다.
- 현재 설치 파일과 업데이트 피드를 변경하지 않았으므로 설치된 1.0.0.41은 그대로입니다. 사용자 PC 적용 및 새 설치본 검증은 아직 하지 않았습니다.
- 후보 복구는 이 변경의 편집 HTML과 manifest 항목을 이전 커밋으로 되돌립니다. 사용자 데이터 삭제·초기화는 필요하지 않습니다.
