# 소스 연결 그래프 · 2026-10-13

## 상태와 범위

- 상태: 연구 체크포인트. 로컬 분석 도구의 시각화 변경, 운영 미배포.
- 대상: `tools/architecture-map/`. 이전 [고정 연결 지도](2026-10-13-source-connection-map.md)의 분석과 근거를 재사용합니다.

## 목적과 변경 전 문제

사용자는 Graphify처럼 점과 선을 움직이며 코드를 탐색하기를 원했습니다. 고정된 역할 카드 대신 확대·이동 가능한 그래프를 기본 화면으로 제공합니다.

## 변경 내용과 소유 구성요소

- 서비스·핵심 파일·전체 파일 보기, 서비스별 파일 펼치기/접기, 검색과 소스 근거 확인.
- 기존 확인 경로 20개를 보존하고 원본 AST 관계를 파일별로 집계합니다. 원본은 방향이 없으므로 호출 화살표를 추가하지 않습니다.
- 파일 소속선·AST 관계·추론·외부 호출 측·확인한 경로를 구분하며 선택적으로 표시합니다.
- 기존 고정 분석 화면은 `architecture-details.html`, 원본 Graphify는 `graph.html`로 보존합니다.
- 원본과 동일한 vis-network 버전/SRI를 사용합니다. 로컬 캐시가 있으면 검증 후 내장하며, 없으면 CDN과 실패 안내를 사용합니다. 생성기가 자동 다운로드하지 않습니다.

## 사용자 영향과 복구

기존 `architecture.html`을 새로고침하면 점·선 그래프가 표시됩니다. 우측 위 분석표 링크로 이전 고정 화면을 볼 수 있습니다. 운영 서비스 변경이나 데이터 복구는 필요하지 않습니다.

## 제거·보존한 파일과 근거

삭제 없음. 생성 산출물·캐시·원본 그래프·QA 캡처는 비공개 로컬에 보존하며 커밋하지 않습니다.
