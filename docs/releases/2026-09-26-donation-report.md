# 별풍선 리포트 · 2026-09-26

## 상태와 범위

- 상태: 관리자 런타임 운영 반영 완료, 2026-09-26 03:20 KST 확인.
- 대상: 관리 → 별풍선 통계 → **별풍선 리포트 받기**. 웹의 원본·생성물도 동기화했다.
- 이전 기준: [월별 별풍선 통계](2026-09-26-monthly-stats.md). 기존 운영 소스 141개 중 API 처리기와 화면 원본·생성물 3개 변경, 집계 모듈 1개 추가.
- 수집기·Agent·DB 스키마·회원 권한은 변경하지 않았다.

## 목적과 변경 전 문제

수작업 분석으로만 만들던 방송 시작 기준 후원 그래프를 계정별로 직접 받을 수 있게 한다. 최근 풍벽지 시작 기록만 사용하면 오래된 수집 원본의 방송 시작 기록이 빠지므로 두 자료를 합쳐야 한다.

## 변경 내용과 소유 구성요소

- 관리자 API: 살아 있는 회원 자격과 `data:read` 권한을 확인하고 서버 세션의 워크스페이스만 조회한다. 클라이언트의 다른 워크스페이스 지정은 적용하지 않는다. 응답은 비공개·캐시 금지이며 후원자 이름·아이디·메시지·이벤트 키를 반환하지 않는다.
- 기본 기간: 해당 계정의 `broadcast_start_local`과 `started_at`을 합친 **기록된 첫 방송일~가장 최근 방송일**, 한국 시간 기준. 기록이 없으면 오늘이나 후원일로 대신 채우지 않는다.
- 분석: 시작 후 첫 3시간의 30분별 평균·중앙값, 시작 시각별 개별 기록과 중앙값, 최근 20개 시작 기록의 히트맵. 전체 집계에는 선택 기간의 모든 비교 가능한 기록을 사용한다.
- 다음 시작과 3시간 이내로 겹친 기록은 동일 조건 비교에서 제외한다. 자정 뒤 후원은 방송이 시작한 날짜에 연결하고 이벤트를 중복 배정하지 않는다.
- 화면: 기간 선택, 생성 상태·빈 결과·실패 안내, 날짜 변경 시 이전 리포트 저장 차단, 2400×2440 PNG 다운로드. 기존 CSP 이벤트 위임을 사용하며 AI·외부 이미지 생성 서비스는 호출하지 않는다.
- 조회는 1,000행씩 페이지를 읽고 자료별 50,000행과 22초 제한을 둔다. 초과·실패를 부분 결과로 표시하지 않는다. 아직 장기간 대용량 성능을 검증하지 않았고, 시작 기록 조회도 원본 행 수에 영향을 받는다.
- 검사 도구: 기존 OAuth 관측 검사에서 120초 경계가 실행 시각의 수 ms 차이에 흔들리는 것을 발견했다. 해당 검사만 고정 시계로 실행하도록 수정했으며 운영 관측 코드는 변경하지 않았다.

## 분석 기준과 제한

일반·별풍선·룰렛·영상후원을 포함하고 구독과 미상 유형은 제외한다. **현재 미션은 최종 수락과 최초 후원 시각의 연결을 확인하지 못하므로 제외**한다. 성공 정산 시각을 최초 후원 시각으로 대체하지 않으며, 제외된 건수·금액을 표시한다. 따라서 기존 별풍선 통계의 전체 합계와 리포트 합계는 정의가 다르다.

시작 기록은 독립된 방송 횟수와 같다고 보장하지 않는다. 0은 저장 후원이 없다는 의미이고 수집 연속성을 증명하지 않는다. 실제 방송 종료 시각, 요일·콘텐츠 차이, 관측 공백을 보정하지 않았으므로 시간당 효율이나 최적 방송 시작 시각을 확정하지 않는다.

## 사용자 영향과 복구

새로고침 후 통계 메뉴에서 기간을 선택하고 PNG를 저장할 수 있다. 사용자 데이터 쓰기와 마이그레이션은 없다. 기존 인원별·날짜별·월별·풍선 개수별 통계는 유지한다.

오류 시 비공개 운영 기록의 직전 관리자 런타임 배포로 복구한다. 월별 통계가 포함된 이전 배포를 보존하며 다른 런타임이나 수집기를 재배포하지 않는다.
