# 로컬 빌드·중복 산출물 정리 · 2026-10-10

## 상태와 범위

- 상태: 로컬 정리 완료, 운영 배포 없음.
- 확인: 2026-10-10 06:35 KST.
- 사용자 요청에 따라 작업 공간의 재생성 가능한 산출물과 검증한 중복 사본을 제거했다.
- 이전 정리: [2026-10-05](2026-10-05-local-tts-cleanup.md). 이번 삭제량은 이전 실적과 별개다.

## 목적과 변경 전 문제

읽을 수 있는 프로젝트 파일은 약 26.142GiB였다. 최근 Agent 빌드와 과거 격리 테스트의 실행 파일, 같은 패키지의 검증용 복사본이 누적돼 있었다. 링크 대상과 접근할 수 없는 폴더는 조사 용량에서 제외했다.

## 변경 내용과 소유 구성요소

| 제거 대상 | 파일 수 | 바이트 |
| --- | ---: | ---: |
| .NET 빌드·publish·과거 격리 테스트 산출물 | 2,018 | 1,781,494,880 |
| 프로젝트 전용 npm 다운로드 캐시 | 804 | 244,141,051 |
| 보존한 설치 ZIP과 개별 SHA-256이 일치하는 압축 해제 사본 | 200 | 736,697,257 |
| 과거 설치 테스트·배포 확인 폴더의 동일 바이너리 사본 | 26 | 2,029,745,243 |
| **합계** | **3,048** | **4,792,078,431 (4.463GiB)** |

총 74개 경로를 명시적으로 선택했다. 동일 바이너리는 남겨 둔 원본 위치와 SHA-256을 비공개 영수증에 기록했다. 현재 설치 앱, 배포 피드, 설치 패키지 원본, 수집·연구 원문, 로그·검증 화면, 소스, Git 이력, 지정된 안정본·복구 아카이브는 유지했다. ASR·영상 도구의 라이브러리는 다른 파일과 해시가 같더라도 해당 실행 환경에 필요하므로 제거하지 않았다.

일부 과거 그래프용 Python 패키지 폴더는 접근 거부로 내용을 확인하지 못해 보존했다. 전체 불필요 파일이 모두 사라졌다고 판정하지 않는다. 코드 동작 변경이 없어 기능 테스트·고객 PC·방송 종단 검증은 다시 실행하지 않았다.

## 사용자 영향과 복구

서비스·수집기·설치 Agent 버전은 바뀌지 않는다. 다음 개발 빌드에서 bin/obj/publish가 다시 생성되며 npm 캐시는 필요할 때 다시 내려받는다. 압축 해제 폴더는 보존 ZIP에서, 중복 바이너리는 영수증에 지정한 사본에서 복구할 수 있다. 과거 격리 테스트 폴더를 그대로 재실행하려면 산출물을 다시 준비해야 한다.

## 제거·보존한 파일과 근거

정확한 목록, 삭제 시각, 해시, 보존 위치 및 Git 상태는 비공개 로컬 정리 영수증으로 보관했다. 공개 문서에는 인증정보·회원 정보·운영 원문을 포함하지 않는다. 삭제본의 별도 압축 백업은 만들지 않았다.
