## 목적과 변경

주사위가 이동할 때 클릭 대상이 달라지거나 입력이 누락될 수 있고, 게임 상태와 버튼 상태가 서로 다른 시점에 갱신되는 문제가 있었습니다. 상태 갱신 때 버튼 정보도 갱신하고, 누른 주사위 번호를 고정하며, 원시 입력의 중복 전달을 막습니다. 이동 중인 영역은 위치가 150ms 동안 안정된 뒤 활성화합니다. 점수는 기존처럼 한 번 선택하고 다시 눌러 기록합니다.

Unity 바이너리·채점·난수·DB 스키마는 동일합니다. 독립 소스 커밋은 `17ea5594751816cb6740e1b1b7fb79b1755a175b`입니다.

## 사용자 영향과 복구

새로고침하면 수정된 입력 처리가 적용됩니다. 게임 컨테이너만 교체했고 준비 확인까지 0.68초가 걸렸습니다. 이는 전체 사용자 체감 중단 측정값이 아닙니다. 공개 혼자 연습은 굴림 33회·보관/해제 34회·선택/확정 각 12회였고 예상 점수·보관 눈·자동 보관·두 번 눌러 기록·합계를 대조했습니다. 온라인 다중 사용자 UI와 실제 iPhone/Android의 이번 수정 검증은 미완료입니다.

이전 이미지·배포 설정·DB 온라인 백업을 보존합니다. 문제가 생기면 이전 이미지로 game 서비스만 되돌리며 DB를 과거 상태로 덮어쓰지 않습니다. 세부 이미지와 복구 자료 위치는 비공개 영수증에 보관합니다.
