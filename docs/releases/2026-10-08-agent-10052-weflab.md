# Agent 1.0.0.52 · 선택형 위플랩 수집 · 2026-10-08

## 상태와 범위

- 상태: 정식 Agent 1.0.0.52 운영 반영 완료, 후원 결과 비교는 시험운영. 확인: 2026-10-08 08:20 KST.
- 대상: Windows Agent, 위플랩 전용 연구 워커, 분리된 저장소와 인증 RPC, 서명된 업데이트 목록.
- 기존 SOOP 운영 후원·업보 처리, 권한, 직접 WebSocket 연구는 유지한다.
- 이전: [1.0.0.50](https://github.com/byellogDev/byeollog/releases/tag/agent-v1.0.0.50), [조회·인계 연구 후보](2026-10-08-weflab-browserless-handoff.md).

## 목적과 변경 전 문제

위플랩 봇 채팅 누락과 독립적으로 결과를 확인할 수 있도록 브라우저 없는 수집 경로를 Agent에 통합한다. 별도 시험용 설치파일 대신 정식 업데이트로 제공하고, URL 미설정 사용자의 기존 동작을 유지한다.

## 변경 내용과 소유 구성요소

- Agent: 상단 설정 버튼에서 위플랩 후원알림 URL을 저장·비울 수 있다. 계정 세션과 owner/manager 권한을 확인한다. URL만 저장했다고 신규 계정의 관측이나 운영 반영을 시작하지 않는다. 이번 비교 대상은 사전에 등록한 한 계정이다.
- 서버·PC: 서버가 기본 수신하고, Agent의 두 채널 연결이 준비되면 PC가 우선한다. 45초 담당권과 10초 확인 주기를 사용한다. PC가 없어도 서버가 담당한다. 실제 장애 중 무손실 전환은 아직 검증하지 않았다.
- 조회: 수신 후 최소 180초 뒤 조회하며 먼저 후원별 요청을 영구 예약한다. 응답 불명·타임아웃이면 제공자 요청은 다시 하지 않는다. DB 전송만 재시도한다.
- 저장: 원본 후원·규칙·요청·응답을 비공개 증거와 별도 DB에 보존한다. 같은 응답의 재전송은 중복 반영하지 않는다. 비활성 응답 때문에 미전송 증거를 삭제하지 않는다.
- API가 새 결과를 만든 것으로 응답하면 수집을 안전 중단한다. 지연은 원본 오버레이보다 항상 늦게 요청한다는 보장이 아니다.
- URL 없음·등록된 계정과 다른 URL·안전 중단 상태는 위플랩 연결/예약을 차단한다. URL을 삭제해도 기존 후원·업보 데이터와 시험 증거는 유지한다.
- 자동 비교 예약은 사용자 요청으로 중지했다. 이전 연구 타이머도 비활성화해 중복 실행을 막았다. 수집은 유지하고 방송 후 사용자가 요청할 때만 동일 구간 결과를 대조한다.

## 사용자 영향과 복구

정식 업데이트를 받아도 URL이 없는 사용자는 기존 경로를 사용한다. 새 수집 결과를 운영 업보에 자동 합산하지 않는다. 현재 대상 외 계정은 URL 저장 후에도 비교 등록 대기 상태를 표시한다. 방송 후 기존 수집 결과와 후원별 수량·회차·결과 순서·누락·중복을 대조하며, 연결 공백과 늦은 DB 저장은 별도로 구분한다.

URL을 비우거나 시험 캠페인을 비활성화하면 새 수집을 멈출 수 있다. 서버 서비스만 중지할 수 있고 기존 SOOP 컨테이너를 재시작할 필요가 없다. 기존 설치 파일과 배포 영수증은 보존한다. 서명 목록의 단조 증가 조건 때문에 복귀 시 높은 sequence의 새 복구 목록이 필요하며, 단순 이전 목록 교체를 고객 복구 성공으로 간주하지 않는다.
