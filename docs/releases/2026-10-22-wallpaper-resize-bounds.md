# 풍벽지 크기 조절 경계 보정 후보 · 2026-10-22

후속: [Agent 1.0.0.59 운영 배포](2026-10-22-agent-10059.md). 아래는 배포 전 후보 시점의 기록이다.

## 상태와 범위

- 상태: 수정·로컬 검증 후보. 운영 웹·Agent 자동 업데이트 피드·설치 파일은 변경하지 않았다.
- 대상: Windows Agent 배치 편집 화면과 동일한 웹 편집 로직의 4개 런타임 사본.
- 기준 커밋: `2e99b9c`. 기존 수집·후원 데이터·권한·방화벽·다른 UI 기능은 변경하지 않았다.

## 목적과 변경 전 문제

사용자가 카드 크기 조절 시 “풍벽지 카드가 편집 가능 영역을 벗어났습니다” 오류를 제보했다. 고객의 실제 배치 원문을 확보하지 않았으므로 아래 재현 중 어느 경우인지는 확정하지 않았다.

1. 13열 묶음을 오른쪽 끝으로 늘리면 허용 카드 폭의 소수점이 다시 반올림되어 전체 폭이 1924px이 됐다.
2. 80행·카드 폭 60px인 기존 묶음을 조절하면 최소 폭 80px 강제로 높이가 1287px이 됐다.
3. 이미지 없는 카드가 바닥에 있으면 편집용 최소 높이 60px로 변환되지만 Y좌표는 그대로여서 하단이 1094px이 됐다. 저장은 전체 묶음을 포함하므로 다른 카드 조절도 실패했다.

## 변경 내용과 소유 구성요소

- 최종 정수 카드 폭에 행·열 전체 크기의 화면 한도를 적용한다. 카드 크기 조절 시 최대 허용 폭은 내림해 반올림 초과를 방지한다.
- 기존 80px 미만의 조밀한 묶음은 그 크기에서 조절할 수 있게 한다.
- 편집 배치 계산 후 최소 영역 크기를 포함한 실제 묶음 크기로 X/Y를 제한한다. 이미 유효한 배치는 유지하고 경계 밖 계산만 보정한다.
- 카드 구성원·순서·숨김 정보는 유지한다. Agent의 영역 검사와 저장 계약을 완화하지 않는다.
- 기존 빌드별 UI 캐시 방식을 유지한다. 수정된 HTML은 이후 새 Agent 빌드에 포함되어야 한다.

## 사용자 영향과 복구

- 새 버전 적용 후 경계 근처의 크기 조절이 저장 가능한 영역 안에서 동작한다.
- 이번 후보 게시만으로 설치된 Agent는 업데이트되지 않는다. 운영 적용과 고객 PC 확인은 별도 단계다.
