# 설치 EXE 1.0.0.41-r2 · 2026-09-28

## 상태와 범위

- 상태: 설치 EXE 게시 및 공식 다운로드 운영 반영 완료.
- 확인 시각: 2026-09-28 KST. 정확한 배포 ID·시각·복구 기준은 비공개 배포 영수증에 보관.
- 대상: 온라인 설치 EXE의 바탕화면 바로가기 수정. Agent 본체는 1.0.0.41 그대로이며 ZIP·서명 업데이트 목록·관리 API·운영 및 연구 수집기는 변경하지 않았다.
- 이전 기준: [Unicode 바로가기 수정·CI](2026-09-28-shortcut-unicode-ci.md), [BOM·오류 안내 수정](2026-09-27-installer-shortcut.md).

## 목적과 변경 전 문제

다운로드 설치 파일에는 한글 바로가기 인코딩·저장 수정이 포함되지 않았다. 준비된 래퍼를 정식 소스에서 다시 빌드하고 기존 파일과 구분되는 설치 리비전 r2로 배포했다.

## 변경 내용과 소유 구성요소

- 설치 스크립트의 UTF-8 BOM과 Unicode Shell Link API 수정, 실제 오류를 전달하는 설치 실패 안내를 포함한다.
- Inno Setup 표시 버전은 1.0.0.41-r2, 내부 Agent 버전과 다운로드 ZIP은 1.0.0.41을 유지한다.
- 새 EXE와 SHA-256 파일을 기존 Agent 릴리스에 추가하고 기존 EXE를 덮어쓰지 않았다.
- 공식 /agent/download가 새 EXE로 연결되도록 웹 설정만 변경했다.
- 배포 전 대조에서 로컬 리포트 관련 파일 4개가 웹 운영본과 달랐다. 이 중 로컬에만 있는 파일 1개는 후보에서 제외하고 나머지 3개는 운영 바이트를 유지했다. 로컬 기능 코드는 수정하지 않았다. 최종 후보·운영 소스 647개 중 vercel.json만 이전 운영과 다르며 라우팅 차이도 다운로드 대상 1개뿐이다. 따라서 이 배포는 로컬 웹 트리 전체를 운영에 반영했다는 뜻이 아니다.
- Vercel 승격이 새 운영 빌드를 생성하므로 최종 운영 소스·라우팅을 검증 후보와 다시 대조했다. 도쿄 hnd1 유지.

## 사용자 영향과 복구

공식 다운로드에서 새 설치 EXE를 받는다. 기존 사용자 설정·데이터를 바꾸는 변경은 없다. 자동 업데이트는 기존 서명 ZIP을 계속 사용하며 이 수정은 설치 EXE 리비전이다.

Microsoft에 제출했던 기존 파일은 보존했다. 새 파일의 Defender 탐지 해제나 다른 PC 설치 성공은 확인하지 않았다. 기존 ZIP의 시작 메뉴 생성 및 Agent 내부 바로가기 갱신은 이번 수정 범위 밖이다.

다운로드 연결에 문제가 있으면 비공개 영수증의 이전 웹 배포로 되돌린다. 기존 EXE·ZIP·업데이트 feed를 삭제하지 않았으므로 복구 자산은 유지된다. 이전 EXE로 돌아가면 기존 바로가기 문제도 다시 남는다.

## 제거·보존한 파일과 근거

삭제한 릴리스 자산 없음. r2 EXE와 checksum만 추가했다. EXE는 전용 배포 저장소에 게시하고 개발 저장소에는 소스·공개 provenance·문서만 기록한다. 인증정보·비공개 배포 자료는 게시하지 않는다.
