# 백두산 만들기·관리 화면 개선 · 2026-09-29

후속 배포 상태는 [Agent 1.0.0.44 릴리스](2026-09-29-agent-10044.md)를 참고하세요. 아래는 배포 전 후보 검증 시점의 기록입니다.

## 상태와 범위

- 상태: **로컬 검증 완료 후보, 설치본 미배포**.
- 확인일: 2026-09-29 KST.
- 대상: Windows Agent의 백두산 만들기·배치 관리 대화창과 UI 리소스 캐시.
- 이전: [Agent 1.0.0.43](2026-09-29-agent-10043.md). 설치 경로 수정은 [1.0.0.43-r2](2026-09-29-installer-path-r2.md)에서 별도 처리했습니다.

## 목적과 변경 전 문제

작은 안내 글씨, 기본 흰색 입력칸과 후원 버튼, 붙어 있는 설명과 생성 버튼 때문에 선택 과정이 읽기 어려웠습니다. 방송·범위와 시작 후원 선택을 분리하고 선택 결과가 분명히 보이도록 정리했습니다.

## 변경 내용과 소유 구성요소

- `wallpaper-baekdusan-editor.css`: 대화창에만 적용하는 독립 스타일. 네이비 배경·민트 선택 표시·금색 주요 버튼, 48px 입력칸, 44px 이상 버튼, 16px 후원자 이름·수량, 긴 이름 줄바꿈을 적용합니다. 외부 CDN이나 CSS 런타임 의존성을 추가하지 않습니다.
- `wallpaper-baekdusan-editor.js`: 번호가 있는 두 단계, 후원자/시각/수량을 구분한 목록, 선택 표시, 준비할 칸 수와 시작 후원 요약, 고정 하단 버튼, 접을 수 있는 안내를 구성합니다. 관리 창에도 동일한 스타일을 적용합니다.
- HTML·프로젝트 리소스·UiAssetStore: CSS를 설치본에 포함하고 UI 캐시 경로를 변경해 이전 리소스가 남지 않게 합니다.
- 후원 매칭 규칙·인증·저장 API·OBS 렌더러·원본 데이터는 변경하지 않습니다. 기존 500칸 제한과 해제 확인을 유지합니다.

## 사용자 영향과 복구

- 다음 설치본에 포함해야 사용자에게 적용됩니다. 현재 다운로드·자동 업데이트 피드는 변경하지 않았습니다.
- 원본 후원이나 백두산 저장 형식 변경이 없어 데이터 이관이 필요하지 않습니다.
- 회귀 시 해당 UI 변경을 되돌리고 UI 캐시 버전을 갱신한 설치본을 검증합니다. 현재 운영 설치본은 보존되어 있습니다.

## 제거·보존한 파일과 근거

인라인 스타일을 전용 CSS로 분리했습니다. 운영 파일·사용자 데이터 삭제는 없습니다. 합성 브라우저 캡처 및 실행 도구는 비공개 `.local`에 보존합니다.
