## 목적과 변경 전 문제

안내문은 과거 채팅 결과 연결·룰렛 금액 등록 흐름을 설명했고, 크레딧 접근 위치와 연결 대기 메뉴가 현재 사용 흐름에 맞지 않았습니다. 특수룰렛 조회는 기존 채팅 경로만 읽어 오버레이 경로의 확정 배수를 표시하지 못했습니다.

## 변경 내용과 소유 구성요소

- 웹 안내: 후원알림 오버레이 주소 → 수집 ON, OFF 이후 진행 건 마무리, 자동 이벤트명·선택 사전 등록, 서버·Agent 역할, 미분류 배수 보존을 설명합니다. 외부 제공자 이름은 예시이며 지원 범위를 무조건 보장하지 않습니다.
- 개인정보: 오버레이 주소·응답·후원자·결과 처리, 현재 국내 서버 위탁 위치, Agent·외부 글꼴 요청, 추천 적립 표시 이름을 반영했습니다. 기존 연결 원본 보관 기준과 별도 시험·진단 자료의 실제 보관 차이를 구분했습니다. 기존 책임·해지·변경 절차와 과거 문서는 보존했습니다.
- 가입: 현행 고지 버전은 2026-10-11입니다. 프런트·API는 구버전 동의를 재확인하도록 하며 DB는 전환 기간 구·신 버전을 받아 실제 제출 버전 그대로 저장합니다. 기존 회원 동의 기록은 갱신하지 않았습니다.
- 매뉴얼: 현행 기능을 읽기 쉬운 11쪽 PDF로 재작성했습니다. 풍벽지 숨김·복원·텍스트 영역 배경·백두산·묶음 해제·뽑기판·통계를 포함합니다.
- 크레딧: 마이페이지에서 접근하며 추천 가입 적립에 표시 이름을 추가합니다. 인증 계정에 실제 적립을 만든 가입 기록만 조회하고 내부 식별자·이메일·원본 키는 반환하지 않습니다. 기록이 없으면 이름 확인 불가로 표시합니다.
- 관리: 룰렛 연결 대기 확인 메뉴와 관련 UI 호출을 제거하고 특수룰렛 이력을 관리로 이동했습니다. 새 읽기 전용 RPC가 기존 채팅과 오버레이 확정 배수를 합쳐 최근 50건을 제공합니다. 현재 방송의 배수 대기도 별도 표시합니다. 기존 백엔드 기록·호환 API는 보존했습니다.
- 빌드: 공통 화면 생성기에 변경을 반영해 옛 메뉴가 재생성되지 않도록 했습니다. 가입 HTML의 실제 스타일 바이트와 CSP 해시를 일치시켰습니다.

## 사용자 영향과 복구

- 페이지를 새로고침하면 새 메뉴와 안내가 표시됩니다. Agent 재설치는 필요 없습니다. 크레딧은 현재 적립 내역 안내 기능입니다.
- PDF를 다시 내려받으면 새 버전이며 이전 다운로드는 자동 변경되지 않습니다.
- 이미 시작된 수집·확정 후원·업보 및 기존 동의 기록은 그대로입니다.
- 이상 시 비공개 배포 기록에 보존한 직전 웹·관리 후보를 함께 복구합니다. 새 읽기 전용 RPC는 호출하지 않으면 영향이 없고, 동의 함수는 구버전도 수용하므로 기록을 되돌리거나 삭제하지 않습니다. 법적 고지와 동의 버전을 임의로 불일치시키지 않습니다.
