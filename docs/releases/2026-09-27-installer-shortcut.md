- 대상: 온라인 설치 래퍼와 설치 오류 안내. 서명된 Agent ZIP, 자동 업데이트 목록, 사용자 데이터는 변경하지 않음.

## 목적과 변경 전 문제

앱 설치와 무결성 검사가 완료된 뒤 바탕화면 바로가기 저장이 실패했다. 그러나 설치 UI는 모든 비정상 종료에 실행 중인 앱을 종료하라고 안내하여 실제 원인을 가렸다.

Windows PowerShell 5.1이 BOM 없는 UTF-8 래퍼를 로컬 코드 페이지로 읽으면서 한글 파일명에 금지 문자 U+003F가 생겼다. 원본 파일을 파싱하고 격리된 임시 폴더에 실제 WScript.Shell 바로가기를 저장하여 실패를 재현했다.

## 변경 내용과 소유 구성요소

- `apps/web/installer/Invoke-AgentInstall.ps1`: UTF-8 BOM으로 한글 리터럴 보존.
- `apps/web/installer/ByeollogAgentSetup.iss`: 실패를 프로세스 실행 중으로 단정하지 않고 실제 설치 로그 확인 안내.
- Windows 회귀 검사: BOM 제거 시 실패, 수정본으로 한글 바로가기 저장 성공. 앱을 실행하거나 사용자 바탕화면을 변경하지 않음.

## 사용자 영향과 복구

이미 앱 설치가 완료된 PC에서는 설치된 앱 경로로 실행할 수 있다. 이번 수정은 아직 기존 다운로드 EXE에 포함되지 않았다. 서명된 ZIP의 고정 루트 스크립트에도 BOM 없는 한글이 있으며 시작 메뉴 생성 경고가 관측됐지만, 해당 파일은 업데이트 호환성을 위해 수정하지 않았다. 후속 설치 후보에서 시작 메뉴까지 별도로 검증해야 한다.

다른 PC의 백신 차단은 별도 문제다. 이번 인코딩 재현으로 악성코드 탐지 원인이나 오탐 여부를 판정하지 않는다. 보안 예외 추가·차단 해제는 하지 않았다.

배포 설치 EXE는 로컬 보존본과 전체 SHA-256이 일치하며 Windows 게시자 서명이 없다. 현재 PC의 Microsoft Defender(플랫폼 4.18.26080.4, 정의 1.459.413.0)로 해당 파일만 자동 치료 없이 검사한 결과 위협 없음이었다. 다른 PC에서는 브라우저 재다운로드도 바이러스 발견으로 차단됐다는 화면이 확인됐다. 로컬 단일 검사 통과로 상대 PC의 탐지나 오탐 여부를 부정하지 않으며 탐지 이름은 미확보다.

소스 복구는 이 작업의 래퍼 인코딩·오류 안내 변경을 되돌리면 된다. 운영 배포 복구는 필요하지 않다.

## 제거·보존한 파일과 근거

제거 없음. 기존 ZIP·EXE 및 고정 루트 파일 보존. 원본 설치 로그와 재현 자료는 비공개 로컬에만 유지한다.
