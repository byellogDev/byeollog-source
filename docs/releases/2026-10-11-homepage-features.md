# ops-2026.10.11-homepage-features · 2026-10-11

## 상태와 범위

- 상태: 메인 인덱스 페이지 운영 반영.
- 확인 시각: 2026-10-11 KST, 최종 후보·운영 검증 기록 참조.
- 대상: `apps/web/index.html`과 메인 페이지 스타일의 CSP 해시.
- 이전: [현행 안내·설정](2026-10-11-guide-credit-history.md), [Agent UI 무결성](2026-10-11-agent-ui-integrity.md).
- Agent 설치 파일·업데이트 피드·수집기·관리 API·DB·사용자 데이터는 변경하지 않습니다.

## 목적과 변경 전 문제

메인 소개가 후원 정보와 룰렛 결과 연결 중심으로 남아 있어 현행 오버레이 기반 업보 수집 조건과 최근 풍벽지 기능·통계를 충분히 설명하지 못했습니다. 사용자가 요청한 기능 설명 중심으로 내용을 갱신했습니다.

## 변경 내용과 소유 구성요소

- 첫 화면에서 후원 수집·업보 관리·풍벽지·방송 통계 기능을 명시합니다. 감성 홍보 문구 대신 가능한 작업과 설정 조건을 설명합니다.
- 업보: 후원알림 오버레이 주소 저장 → 수집 ON → 최초 미분류 결과 분류. 룰렛 사전 등록 불필요, `10월 330개` 자동 이벤트명과 선택적인 이벤트명 사전 등록을 안내합니다.
- 풍벽지: 개별 숨김·복원, 숨김 카드 제외 쌓기, 백두산, 범위 묶음 해제, 글꼴·닉네임/본문 색·글자 영역 배경색·글자 크기를 설명합니다.
- 통계: 후원자·날짜·월·수량 조회와 방송 시작 후 흐름의 PNG 리포트, 기록된 첫 방송일~최근 방송일 기본 기간을 안내합니다. 무료 채팅창 꾸미기 링크를 유지합니다.
- 시작 방법과 이용 조건을 분리하고 세팅 체크리스트·설정 PDF·공지·로그인·가입 링크를 배치했습니다. 업보 OFF 이후 진행 건 마무리와 PC 풍벽지 실행 조건도 구분합니다.
- 기존 남색·금색 계열, 실제 렌더러로 만든 가상 닉네임 이미지와 문의 API 계약을 유지했습니다. 새 의존성·추적 스크립트는 추가하지 않았습니다.

## 사용자 영향과 복구

- 메인 페이지를 새로고침하면 최신 기능 설명을 볼 수 있습니다. 프로그램 재설치는 필요 없습니다.
- 문제가 생기면 비공개 배포 기록의 직전 웹 배포로 복구합니다. API·DB 마이그레이션이 없어 데이터 되돌림은 필요하지 않습니다.

## 제거·보존한 파일과 근거
