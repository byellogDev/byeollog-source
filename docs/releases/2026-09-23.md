# 2026.09.23 · 운영 소스 통합과 방송 대기 안정화

## 목적

운영 버전과 작업 폴더가 달라 발생할 수 있는 기능 회귀를 줄이고, 검증·배포·버전 기록을 한 기준에서 수행합니다. 이번 배포는 사용자 화면 재설계나 계정 권한 확대를 포함하지 않습니다.

### 검증 한계

가입·탈퇴·SOOP 재연결·로그인한 사용자의 전체 화면·실제 백업 복원·OBS 출력은 이 릴리스에서 다시 조작하지 않았습니다. 기존 사용자 인정 안정본을 보존한 채 소스와 배포 응답을 대조했습니다. `401`은 비인증 접근 차단의 확인이며 인증 후 기능 완료를 뜻하지 않습니다. 백업 대상 조회 성공도 신규 백업 생성·복원 성공과 구분합니다.

## 운영 영향과 복구

수집기 교체 시 연결 중인 방송이 재연결되었습니다. 반영 후 연결 복구와 빈 전송 큐를 확인했습니다. 방송 오프라인 상태의 재확인 주기는 30초이므로 방송 시작 감지에 해당 대기 시간이 추가될 수 있습니다. 환경변수·영속 볼륨·프로세스 한도는 보존했습니다.

Vercel은 검증한 후보를 승격했습니다. 팀 시스템 alias가 후보 생성 중 먼저 바뀔 수 있어 최종 alias도 조회합니다. 직전 배포 및 NCP 이미지·변경 전 파일을 비공개 운영 기록에 보존했습니다. 복구 방법은 [배포 문서](../DEPLOYMENT.md)를 따릅니다.

## 레거시 정리

- 로컬: 67개 경로, 3,642개 파일 제거. 과거 개발·릴리스 트리는 검증된 로컬 ZIP에 보존하고, 다운로드 검사 임시 ZIP은 제거했습니다.
- 공개 배포: Agent `0.7.0.52`~`0.7.0.63`의 릴리스 12개(902,683,451바이트)를 제거했습니다. 각 배포 자산은 로컬 복구 사본과 SHA-256이 일치합니다.
- 보존: 현재 `1.0.0.40`, 사용 기록이 있는 버전, 업데이트 호환 버전, 직전 복구 버전. 다른 과거 릴리스도 참조·복구 조건이 입증되지 않으면 이번 제거 대상에서 제외했습니다.
- 테스트 전용 과거 자산은 운영 코드와 분리했습니다. 사용자 PC에 설치된 Agent를 원격 삭제하지 않았습니다.
