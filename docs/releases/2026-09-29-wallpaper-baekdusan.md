# 풍벽지 백두산 · 2026-09-29

## 상태와 범위

- 후속 배포: [Agent 1.0.0.43 운영 반영 기록](2026-09-29-agent-10043.md). 아래 내용은 구현 후보 단계의 검증과 미배포 상태를 보존한 기록이다.
- 상태: 구현·로컬 검증 후보. 운영 API·설치 EXE·업데이트 피드 미배포.
- 대상: Windows Agent의 로컬 편집기·OBS 표시, 관리자 API의 권한 확인 후 읽기 전용 후원 조회.

- 운영 수집기·원본 후원·통계·DB 스키마와 권한은 변경하지 않았다.

## 목적과 변경 전 문제

백두산은 별도 후원 종류가 아니라 일반 별풍선의 숫자 연속이다. 100에서 끝날 필요도, 같은 후원자가 참여할 필요도 없다. 금액 범위 전체를 합병하면 중복 금액과 다른 순서의 후원이 섞이므로 사용자가 시작 후원과 목표를 정하도록 한다.

확정 규칙: 사용자가 고른 시작 후원 이후, 직전 선택 후원의 **수신 순번보다 뒤에서 다음 금액이 처음 등장하는 건**을 포함한다. 중간의 다른 금액은 건너뛴다. 32 이후 첫 33이 일반 후원인 것은 오류가 아니라 정상 참여다. 지나간 33을 소급해서 채우지 않는다. 발생 시각 표시는 선택을 돕고, 저장 순번을 정렬 기준으로 사용한다.

## 변경 내용과 소유 구성요소

- `백두산 만들기·관리`: 방송·시작 수량으로 후원을 찾고 시간·참여자·수량 목록에서 시작 건을 선택한다. 목표까지 빈 칸을 예약하고 기존 기록과 신규 기록을 같은 규칙으로 채운다.
- 시작 번호는 1로 고정하지 않는다. 방송당 한 묶음, 묶음당 500칸, 계정별 로컬 보관 10묶음·총 1,000칸으로 제한한다.
- 화면에 선택한 방송의 백두산만 표시한다. 선택하지 않은 방송의 묶음은 보관하며, 표시할 회차를 선택해야 한다는 안내를 제공한다.
- 편집기와 OBS가 같은 렌더러를 사용한다. 채운 칸에 숫자·참여자를 표시하고 미완성/완주를 구분한다. 영역 드래그, 위치·크기·열 수 편집을 지원한다.
- 포함된 후원 ID는 일반 표시에서만 제외한다. 원본 카드·배치는 그대로 유지해 묶기 해제로 기존 표시가 복원된다. 기존 풍벽지의 보관 기간과 표시 개수 제한은 유지한다.
- 현재 편집기의 최근 216장 제한을 검색 원본으로 사용하지 않는다. 인증된 계정·방송으로 제한한 후원 원장을 200건씩 읽으며, 구독·도전 성공 카드는 제외한다. 조회 API가 사용자에게 다른 계정의 식별자를 반환하지 않도록 동일한 workspace/session 조건을 사용한다.
- 계정별 로컬 파일에 시작 건·목표·참여 후원·다음 페이지·영역·선택 회차를 원자적으로 저장한다. 재시작 시 복원한다. 이 PC의 설정이며 서버 백업·다른 PC 자동 동기화 기능은 아니다.
- 편집기를 닫아도 Agent가 진행을 확인한다. 기존 풍벽지 변경 신호를 받고 최소 5초 간격으로 합쳐 조회하며, 신호가 없으면 약 60초마다 복구 조회한다. 활성 묶음이 없거나 완주·방송 종료 상태면 추가 후원 조회를 하지 않는다.
- 방종된 과거 회차도 남은 페이지까지 읽은 뒤 미완성으로 보존한다. 다음 방송의 후원으로 이어 채우지 않는다.
- 느린 읽기가 편집 잠금을 잡지 않으며, 해제·이동 이후 도착한 이전 응답은 새로운 상태를 덮어쓰지 않는다. 계정 종료 시 진행 중 작업을 취소·정리하고, 이전 계정 작업 정리가 끝난 뒤 새 관측을 시작한다.
- 로컬 UI 캐시 버전을 변경하고 두 스크립트를 실행 파일에 포함한다. OBS 응답은 원본 상태·백두산 버전이 같으면 가공 결과를 재사용한다.

브라우저 검사에서 일반 카드의 렌더 캐시가 백두산 편입을 반영하지 않는 문제를 발견했고, 참여 ID를 캐시 비교에 포함한 뒤 중복 제거·해제를 다시 확인했다. Windows 암호화·바로가기 검사는 샌드박스 접근 제한으로 처음 실패했으며 정상 사용자 권한에서 실제로 재실행해 통과했다.

## 사용자 영향과 복구

- 배포 전이므로 현재 이용 중인 풍벽지는 바뀌지 않는다. 반영 시 관리자 조회 API를 먼저 검증·배포하고 새 Agent를 발행해야 한다.
- 시작 선택은 서버에 보관된 풍벽지 기록 범위(현재 최근 7일)에서 가능하다. 로그가 이미 정리된 회차의 완전 복원 기능은 아니다.
- 실시간 표시는 네트워크와 위 조회 간격의 영향을 받는다. 즉시 도착이나 지연 0을 보장하지 않는다.
- 설정 파일이 손상되면 원본을 덮어쓰지 않고 오류를 표시한다. 원본 후원은 변경하지 않는다.
- 묶기 해제는 일반 풍벽지 표시를 복구한다. 프로그램을 이전 배포로 돌리면 백두산 표시만 사라지고 원본 후원·기존 배치는 유지된다.
- 남은 검증: 보호된 후보 API와 새 Agent의 인증 포함 연결, 실제 Windows WebView2/OBS, 실방송 중 후원·방종·재시작 흐름. 이 문서의 합성 검사를 사용자 수락으로 대신하지 않는다.

## 제거·보존한 파일과 근거

기존 사용자 파일·설치 파일·릴리스 자산은 제거하지 않았다. 합성 브라우저 증거·검사 로그는 비공개 `.local`에 보관하고 공개 Git에 올리지 않는다.
