# Agent 1.0.0.49 · 후원 연동 뽑기판 배포

후속 수정: [1.0.0.50](2026-10-04-agent-10050.md)에서 기존 PC 재로그인 인증 조건과 잘못된 재연결 안내를 수정했습니다. 아래는 1.0.0.49 당시 배포 기록입니다.

## 상태와 범위

- 상태: 정식 설치본·다운로드·서명 자동 업데이트 피드 운영 반영.
- 확인일: 2026-10-04 KST.
- 대상: Windows Agent 1.0.0.49, 웹/관리 프로젝트의 업데이트 피드, 웹의 설치 다운로드 경로.
- 이전 운영: [1.0.0.48](2026-10-04-agent-10048.md). 구현과 검사 기준: [뽑기판 후보](2026-10-04-draw-board-candidate.md).

## 목적과 변경 전 문제

로컬에서 검증한 뽑기판을 사용자가 설치·업데이트할 수 있도록 정식 배포합니다. 후보 커밋 `5c061730d3555fcc72b9113581c3d1fc45e8353c`의 기능 코드를 유지하고 정식 버전 메타데이터, 설치 패키지와 배포 경로를 갱신했습니다.

## 변경 내용과 소유 구성요소

- **Agent**: 풍벽지 편집기의 뽑기판 버튼에서 후원 연동 랜덤 추첨/직접 번호 입력을 선택합니다. 상품·꽝·칸 수를 설정하며, 결과를 먼저 저장하고 OBS에 순서대로 공개합니다. 중복 방지·계정별 저장·재시작 복구·이전 기록 조회를 포함합니다.
- **설치/업데이트**: 버전 1.0.0.49, 업데이트 sequence 10050. 이전 설치·복구 루트 9개를 보존하고 신규 앱을 동일 패키지 계약으로 봉인했습니다. 기존 서명키로 업데이트 카탈로그에 서명합니다. 개인키는 게시하지 않습니다.
- **웹/관리 배포**: 현재 운영 소스를 기준으로 관리 피드 1개, 웹 피드와 다운로드 경로 2개만 변경한 보호된 후보를 만든 뒤 검증·승격했습니다. 두 프로젝트 모두 도쿄 `hnd1`을 유지합니다. 운영과 다른 로컬 웹 파일 3개는 이번 배포에 포함하지 않고 기존 운영 파일을 보존했습니다.
- **기록**: 설치 자산은 기존 자산 저장소, 소스·배포 설명은 본 저장소 GitHub Release에 기록합니다. 후보 기록을 덮어쓰지 않고 후속 배포 링크를 추가합니다.

## 사용자 영향과 복구

- 업데이트 후 풍벽지 편집기에서 **뽑기판** 버튼을 사용합니다. OBS에는 판에서 복사한 로컬 오버레이 주소를 넣습니다.
- 판은 이 PC의 계정별 저장소에 보관됩니다. 랜덤 추첨은 지정 방송에서 시작 후 수집된 일반 별풍선 중 설정 수량과 정확히 일치하는 건만 대상으로 합니다. 기능 범위·보관 한계는 [후보 문서](2026-10-04-draw-board-candidate.md)에 기록했습니다.
- 실제 SOOP 후원·OBS·고객 PC 장기 사용 검증은 남아 있습니다. 이번 배포에서 실사용 후원 데이터를 변경하거나 판을 생성하지 않았습니다.
- 복구 시 보존한 이전 Vercel 배포와 1.0.0.48 설치 자산을 사용합니다. 이미 1.0.0.49를 설치한 사용자의 앱을 자동으로 낮추려면 기존 단조 증가 규칙을 지킨 별도 복구 버전/sequence가 필요합니다. 피드만 이전 버전으로 돌리는 것으로 다운그레이드를 보장하지 않습니다.
- 계정별 뽑기판 파일과 기존 풍벽지·원장 자료는 삭제하지 않습니다.
