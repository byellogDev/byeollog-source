# Agent 1.0.0.59 · 풍벽지 크기 조절 수정 · 2026-10-22

## 상태와 범위

- 상태: 운영 반영. 2026-10-22 21:03 KST 운영 피드·프로젝트 승격 확인.
- 대상: Windows Agent 1.0.0.59, 서명된 stable 피드(sequence 10059), 온라인 설치 파일, 4개 Vercel 런타임의 풍벽지 편집 함수.
- 이전: Agent 1.0.0.58. 변경 내용과 재현 근거는 [검증 후보](2026-10-22-wallpaper-resize-bounds.md)에 기록했다.
- 지속 실행되는 SOOP 수집 호스트·DB·사용자 데이터·인증 권한은 변경하지 않았다.

## 목적과 변경 내용

풍벽지 크기 조절 시 경계를 넘는 좌표가 만들어져 저장이 거부되던 문제를 배포했다. 13열 묶음의 반올림 초과, 조밀한 묶음의 최소 카드 폭 강제, 화면 아래 텍스트 카드의 편집용 최소 높이 변환을 보정한다. 카드 구성원·순서·숨김 정보를 유지하며, Agent의 실제 영역 초과 검사는 유지한다.

## 사용자 영향과 한계

Agent의 기존 자동 업데이트 경로와 수동 설치 링크가 새 버전을 제공한다. 사용자는 표시 버전이 1.0.0.59인지 확인해야 한다. 배포 완료는 고객 PC의 설치·실제 크기 조절 성공을 뜻하지 않는다. 배치 초기화나 데이터 삭제는 필요하지 않다.

## 제거·보존한 파일과 근거

삭제 없음. 기존 버전 자산과 사용자 설정·데이터를 보존한다. 신규 버전의 공개 manifest·provenance, 피드, installer 버전과 고정 검사를 함께 갱신했다. 운영 후보에는 해당 함수·업데이트 관련 파일만 변경하고 다른 운영 파일은 기존 해시를 유지했다.
