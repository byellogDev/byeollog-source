# 풍벽지 개별 숨김·복원 후보 · 2026-10-09

## 상태와 범위

- 상태: **구현·로컬 검증 완료 후보, 운영 미배포**. 기존 정식 Agent 1.0.0.52와 설치·업데이트 피드는 유지한다.
- 확인일: 2026-10-09 KST.
- 대상: Windows Agent 로컬 풍벽지 편집기, 계정별 로컬 표시 설정, localhost 방송 오버레이.
- 이전 기준: [Agent 1.0.0.52](2026-10-08-agent-10052-weflab.md). 웹·DB·수집 경로 변경은 없다.

## 목적과 변경 전 문제

기존에는 금액·종류별 표시만 바꿀 수 있었다. 같은 금액을 받은 카드 중 특정 한 건만 방송 화면에서 숨기고 나중에 복원할 수 있도록 했다.

## 변경 내용과 소유 구성요소

- 각 카드에 편집기 전용 **×** 버튼을 추가했다. 일반 카드·개별 배치 카드·백두산의 채워진 칸을 해당 카드 ID로 숨긴다. 방송 오버레이에는 조작 버튼이 나오지 않는다.
- **숨긴 풍벽지** 목록에 후원자·수량·받은 시각·복원 버튼을 표시한다. 검색, 빈 목록 안내, 페이지당 40건으로 많은 내역도 탐색할 수 있다.
- 같은 PC·계정의 로컬 파일에 원자적으로 저장한다. 새로고침·프로그램 재시작·새 후원 수신으로 기존 숨김이 풀리지 않는다. 서로 다른 계정의 저장 경로는 공유하지 않는다.
- 표시만 숨기므로 기존 자리와 배치를 유지한다. 백두산의 채운 후원과 진행 순서도 유지한다. 후원·업보·통계 및 원본 카드 데이터는 변경하지 않는다.
- 방송 회차 변경·설정 저장·새로고침 완료 시 숨김 버튼 활성 상태도 갱신한다. 숨긴 카드가 겹침 클릭 판정이나 개별 카드 키보드 탐색을 가로채지 않도록 한다.
- 잘못된 ID, 현재 상태에 없는 카드, 취소된 요청과 손상된 저장 파일을 검사한다. 한도(10,000건·4MiB)를 넘으면 오류로 안내하며 기존 숨김을 임의 삭제하지 않는다.

## 사용자 영향과 복구

- 다음 배포를 설치한 뒤 카드의 ×로 숨기고 목록에서 개별 복원할 수 있다.
- 복원은 숨김 해제이며, 해당 방송 회차와 금액별 표시 설정이 켜져 있을 때 나타난다. 기존 방송 기록 보관 기간(최근 7일)이 지나 원본 카드가 정리된 경우 다시 표시하지 않는다.
- 숨긴 카드의 자리는 유지하므로 주변 카드를 자동으로 당겨 채우지 않는다. 백두산의 빈 예약 칸에는 숨김 버튼이 없다.
- 설정은 현재 PC의 현재 계정에 저장한다. 다른 PC로 자동 동기화하는 기능은 포함하지 않는다.
- 복구: 목록에서 개별 복원한다. 구버전으로 되돌릴 경우 이 신규 표시 설정을 지원하지 않아 숨겼던 카드가 다시 나타날 수 있으므로 방송 화면을 확인한다. 손상 파일은 덮어쓰지 않는다.

## 제거·보존한 파일과 근거

기존 데이터·배치·설치 파일은 제거하지 않는다. 신규 숨김 설정과 UI·검사를 추가하며, 비공개 로컬 테스트 캡처는 게시하지 않는다.
