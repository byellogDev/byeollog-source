# 2026.09.23.2 · Agent 자동 로그인 선택과 SOOP 영상후원

## 목적과 변경 전 문제

Agent 로그인 화면에는 ID 저장만 있었지만 로그인 세션은 항상 저장됐습니다. 또한 SOOP 공식 SDK의 `VIDEOBALLOON_GIFTED` 이벤트가 수집기의 허용 목록에 없어 영상후원이 풍벽지에 들어오지 않았습니다.

## 변경 내용과 구성요소

- Windows Agent **1.0.0.41**: ID 저장과 자동 로그인 선택을 분리했습니다. 자동 로그인을 끈 로그인은 이전 암호화 세션도 무효화합니다. 켠 경우 기존 Windows 사용자별 암호화 방식을 유지하며 비밀번호는 저장하지 않습니다.
- SOOP gateway/collector: 영상후원의 금액·후원자·공식 이미지를 정규 후원 경로로 전달합니다. 일반 외부 입력 경로에는 영상후원 허용 범위를 넓히지 않았습니다.
- DB: 영상후원을 풍벽지·후원 내역·고정 업보에 기록하되 룰렛 결과 대기로 분류하지 않습니다. 기존 방송 소유권·중복 방지·실행 권한을 유지합니다.
- 웹/관리 서버: 새 업데이트 서명 목록과 다운로드 경로, 최신 Agent 버전 표시를 반영했습니다.

## 사용자 영향과 복구

Agent 변경은 1.0.0.41 업데이트 후 적용됩니다. 영상후원 서버 수정은 운영에 반영했습니다. 이미 무시된 과거 후원을 임의 금액으로 복원하지 않았습니다. 이 수정의 대상은 SOOP SDK 영상후원이며 다른 플랫폼의 영상후원은 별도 확인 대상입니다.

수집기 교체 당시 실사용 방송들은 오프라인이었고 테스트 연결만 재연결했습니다. 기존 이미지·DB 함수·배포 ID는 비공개 복구 자료로 보존했습니다. 48시간 연구는 배포 구간을 표시하고 같은 종료 시각으로 재개했습니다. 앞선 SDK 오류와 시험 중단 기록을 성공 기록으로 덮어쓰지 않았습니다.
