# Agent 1.0.0.58 · 2026-10-11

## 상태와 범위

- 상태: 정식 Agent 설치 자산과 웹·관리 안정 업데이트 피드 운영 반영.
- 확인 시각: 2026-10-11 20:55 KST.
- 대상: Agent 메인 화면, UI 캐시, 관련 회귀 검사·패키지 메타데이터.
- 이전: [Agent 1.0.0.57 공지 바로가기](2026-10-11-agent-announcements.md).
- 기존 수집 경로·로그인·후원/업보 데이터·공지 게시 시각·DB 권한은 변경하지 않습니다.

## 목적과 변경 전 문제

메인 화면에 사용하지 않는 오버레이 설정 톱니바퀴가 보였습니다. 이 버튼의 소스는 1.0.0.52에 들어갔지만, 1.0.0.53까지는 고정된 `v1.0.0.50` UI 캐시가 있으면 새 화면을 풀지 않았습니다. 빌드별 캐시 분리가 적용된 1.0.0.54 이후에는 현재 내장 화면을 사용하므로 이전 캐시에서 안 보이던 버튼이 드러날 수 있었습니다.

이번 확인 PC에서 실행 중인 1.0.0.57과 캐시는 해당 릴리스의 실행 파일·내장 화면과 일치했습니다. 이를 고객 PC 전체의 상태로 일반화하지 않습니다. 같은 빌드의 UI 파일이 바뀌거나 손상된 경우에는 여전히 기존 파일을 무조건 사용하는 부족함이 있어 보강했습니다.

## 변경 내용과 소유 구성요소

- 메인 HTML의 톱니바퀴와 클릭 연결, MainForm의 해당 분기, 사용하지 않는 WeflabSettingsForm을 제거했습니다. 실제 오버레이 수집 코드는 유지합니다.
- UI 폴더는 실행 assembly MVID로 계속 분리합니다. 화면을 준비할 때 내장 리소스와 캐시를 바이트 단위로 비교하고, 누락·불일치 파일만 임시 파일 완전 기록 후 교체합니다.
- 정상 파일은 다시 쓰지 않습니다. 이전 버전 캐시와 사용자 설정은 건드리지 않습니다. 프로세스 내부 동시 준비를 직렬화하고 남은 임시 파일을 정리합니다.
- 실제 앱 assembly에 제거한 UI가 재포함되지 않는지 검사하고, 공지 기능 유지·손상 복구 검사를 CI에 연결된 기존 검사에 추가했습니다.
- [UI 버전·패키지 일치 절차](../../tools/agent-release/README.md)를 명문화했습니다.

GitHub 전체 CI 완료 여부는 정식 소스 릴리스 게시 직전에 해당 커밋으로 확인합니다. 로컬/패키지 검사는 고객 PC에서 설치와 표시가 끝났다는 증거가 아닙니다.

첫 CI에서는 기존 WebSocket 합성 테스트의 종료 경합이 발견됐습니다. 두 번 교체 후 종료할 시나리오가 새 토큰을 한 번 더 발급해 세 번째 교체를 시작했고, 그 타이머가 방종 프레임 뒤에 가짜 후원을 보내 기대 수신 건수를 잘못 늘렸습니다. 병렬 반복 64회 중 3회 같은 순서를 재현했습니다. 마지막 토큰을 유지하도록 fixture만 수정하고 교체 준비 횟수 2회를 명시적으로 검사했습니다. 수정 후 동일한 64회 반복과 전체 JavaScript 933개가 통과했습니다. 운영 수집 소스·배포에는 변경이 없습니다.

## 사용자 영향과 복구

- 1.0.0.58 적용 후 메인 화면의 톱니바퀴가 없어집니다. 공지·긴급 호출·최소화·닫기와 기존 풍벽지는 유지합니다.
- 손상된 현재 UI 캐시는 실행 파일에 포함된 원본으로 복구합니다. 새로운 기능을 이전 화면 캐시 때문에 놓치는 문제를 막도록 빌드별 캐시 분리를 유지합니다.
- 문제 발생 시 이전 웹/관리 배포와 설치 자산을 복구 기준으로 사용합니다. 이미 업데이트한 Agent는 낮은 시퀀스 피드로 강제 다운그레이드하지 않고 높은 시퀀스의 수정 버전을 게시합니다.
