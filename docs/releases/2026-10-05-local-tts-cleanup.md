# 로컬 미사용 TTS 자료·중복 산출물 정리 · 2026-10-05

후속 정리: [2026-10-10 로컬 산출물 정리](2026-10-10-local-artifact-cleanup.md). 아래는 당시 기록을 보존한 것이며 후속 삭제량과 합산하지 않는다.

## 상태와 범위

- 상태: 로컬 정리 완료, 운영 배포 없음.
- 확인: 2026-10-05 04:30 KST.
- 사용자가 프로젝트 용량 정리와 미사용 TTS 소스·모델·실험 자료 전체 삭제를 승인했다.
- 이전 정리: [2026-09-28 로컬 작업 공간 정리](2026-09-28-local-workspace-cleanup.md). 이번 수치는 이전 삭제량과 별개다.

## 목적과 변경 전 문제

읽을 수 있는 작업 공간 파일이 약 32.80GiB였다. 과거 TTS 실험 환경과 모델, 배포 ZIP을 풀어 놓은 사본, 다시 생성된 Agent 빌드 결과가 용량을 차지했다. 초기 조사에는 접근 제한 경로와 링크 대상이 제외되어 전체 디스크 점유량과는 다르다.

## 변경 내용과 소유 구성요소

| 제거 대상 | 용량 | 근거 |
| --- | ---: | --- |
| 미사용 TTS 소스·모델·환경·실험 음성 | 6.022GiB | 사용자 명시적 폐기 지시. 구 TTS 서비스·릴레이, MeloTTS/CosyVoice 시제품, ONNX 실험, 음질 비교 사본 포함 |
| Agent 압축 해제 사본·publish·bin/obj·Python 바이트코드 | 3.002GiB | 압축 해제 파일은 보존한 ZIP의 개별 SHA-256과 일치 확인. 빌드 결과는 현재 소스로 재생성 가능 |
| **합계** | **9.024GiB** | **76개 경로, 58,501개 파일, 9,689,888,911바이트** |

보존한 설치 ZIP·설치 EXE·배포 영수증·현재 소스·수집 관측 자료는 삭제하지 않았다. 과거 운영 안정본과 지정된 릴리스·아카이브 복구 경로도 그대로다.

현재 별록의 룰렛·수집 처리와 연결된 TTS 호환 코드, 회귀 검사, DB 마이그레이션 이력은 유지했다. 이번 작업은 미사용 로컬 프로젝트와 대용량 실험 자료 정리이며, 현행 TTS 관련 API·권한 계약의 기능 제거 배포가 아니다. ASR 전사 모델과 룰렛 효과음도 TTS 실험 자료와 구분해 보존했다.

## 검증

| 항목 | 방법 | 결과 | 한계 |
| --- | --- | --- | --- |
| 삭제 경계 | 절대 경로·부모·하위 reparse point·파일 수·크기 확인 | 작업 공간 내 명시 목록만 삭제 | 다른 디스크나 사용자 앱 폴더 정리 아님 |
| 사용 중 파일 | 프로세스 실행 경로·명령 참조 확인 | 삭제 대상 사용 프로세스 없음 | 운영 원격 상태 변경·조사 없음 |
| 보존 자료 | 소스·프로젝트·설치 ZIP 등의 SHA-256 전후 대조 | 중복 경로 제외 1,887개 모두 일치 | 모든 과거 복구 아카이브 전체 내용 해시 검사는 아님 |
| 소스 기준 | `node tools/verify-source.mjs` | 1,183개, 기존 의도된 변경 58개, 실패 0 | 사용자 기능 재실행 검사 아님 |
| Git 범위 | 삭제 직후 추적 파일 상태 대조 | 현행 저장소 소스 동일. 과거 루트는 승인된 TTS 파일 25개 삭제만 추가 | 루트 저장소 전체 커밋·reset·stash 안 함 |
| 완료 확인 | 76개 대상 부재와 삭제 영수증 | 모두 제거, C드라이브 여유 약 56.63GiB | 여유 공간은 다른 프로그램 활동에 따라 변함 |

삭제 전 파일 열거에서 Python과 Windows 기본 도구의 TTS 환경 파일 수가 3개 차이 났다. 삭제를 시작하지 않고 Windows 기준으로 다시 확인했다. 다른 대상 변경은 허용하지 않았으며 경계·링크·사용 여부 검사를 다시 통과한 목록만 처리했다.

## 사용자 영향과 복구

- 별록 웹·수집기·Agent 운영 버전과 실행 중 설치 앱은 변경하지 않았다. WebSocket 후보의 안전 중단 상태도 변경하지 않았다.
- 빌드 폴더는 다음 빌드 때 다시 생성된다. 삭제한 압축 해제 사본은 보존한 ZIP에서 복원할 수 있다.
- 폐기한 TTS 실험을 다시 사용하려면 환경·모델을 다시 준비해야 한다. Git에 있던 구 TTS 소스는 루트 이력에서 복원할 수 있으나, 미추적 실험 모델·음성은 별도 복사본을 만들지 않았으므로 복원을 보장하지 않는다.

## 제거·보존한 파일과 근거

정확한 경로 목록·바이트·삭제 시각·보존 해시는 비공개 로컬 정리 기록에 남겼다. 공개 문서에 인증값·회원 정보·운영 원문·실험 음성은 포함하지 않는다. 용량을 다시 차지하는 삭제본 압축 백업은 만들지 않았다.
