# 월별 별풍선 통계 · 2026-09-26

## 상태와 범위

- 상태: 관리자 런타임 운영 반영 완료, 2026-09-26 02:02 KST 확인.
- 대상: 별풍선 통계의 월별 탭. 웹 저장소 사본도 동기화했으며 웹 런타임 자체는 재배포하지 않았다.
- 이전 기준: 현재 운영 소스 141개와 대조해 `lib/admin-source.html`, `lib/admin-html.js` 두 파일만 변경됨을 확인했다.

## 목적과 변경 전 문제

인원별·날짜별·풍선 개수별 통계만 있어 여러 날짜에 걸친 월간 후원 실적을 한 번에 볼 수 없었다.

## 변경 내용과 소유 구성요소

- 관리 → 별풍선 통계에 **월별** 탭 추가.
- 연도와 월별로 총 별풍선, 후원 건수, 중복을 제외한 후원 인원을 최근 월부터 표시.
- 날짜별 통계가 사용하는 저장된 `donated_date`를 공유하여 브라우저 시간대로 재해석하지 않는다. 월 경계 역시 해당 후원일 기준이다.
- 기존 구독 제외와 도전성공 정산의 인원 제외 정책을 유지한다. 날짜 없는 기록도 `날짜 미상`에 남겨 합계에서 누락하지 않는다.
- 추가 API·DB 변경 없이 이미 읽은 후원 원본을 집계한다. 기존 탭·전체 요약은 유지한다.

## 사용자 영향과 복구

새로고침 후 별풍선 통계의 월별 탭을 사용할 수 있다. 월별 인원은 같은 사람이 여러 날짜에 후원해도 한 명으로 계산하므로 일별 인원 합계와 다를 수 있다. 수집·후원 처리·인증 권한 변경은 없다.

문제 시 비공개 반영 기록에 보존한 직전 관리자 배포로 복구하고 월별 화면 두 파일의 변경을 되돌린다. 회원 데이터 변경이나 데이터 마이그레이션은 없다.

## 제거·보존한 파일과 근거

파일 삭제 없음. 후보·운영 배포 식별자, 원본 해시 대조, 화면 캡처는 비공개 `.local/monthly-stats-20260926`에 보존한다. 공개 문서에는 비밀값·회원 식별자·원문 로그를 포함하지 않는다.
