# Agent 1.0.0.44 · 백두산 화면 개선 배포 · 2026-09-29

## 상태와 범위

- 상태: **운영 반영 완료**, 2026-09-29 KST 확인.
- 대상: Windows 풍벽지 Agent, 공식 설치 다운로드, 웹·관리 런타임의 서명 업데이트 피드(sequence 10045).
- 이전: [Agent 1.0.0.43](2026-09-29-agent-10043.md), [설치기 1.0.0.43-r2](2026-09-29-installer-path-r2.md).
- 구현·화면 검증: [백두산 대화창 후보](2026-09-29-baekdusan-dialog.md).

## 목적과 변경 전 문제

백두산 만들기 화면의 작은 글씨, 흰색 기본 폼, 구분 없이 붙은 설명·후원 목록·버튼을 실제 설치본에서 개선합니다.

## 변경 내용과 소유 구성요소

- Agent: 방송과 범위 설정 / 시작 후원 선택의 두 단계, 후원자·받은 시각·수량 구분, 선택 요약과 고정 하단 버튼, 작은 창 대응을 포함합니다. UI 캐시 버전도 변경합니다.
- 설치기: 기존 r2의 UTF-8 결과 경로 수정과 한글 바로가기 처리를 유지하고 새 패키지 해시를 고정합니다.
- 웹: 공식 다운로드를 1.0.0.44 EXE로 변경합니다. 웹·관리 런타임 피드는 새 패키지에 서명한 sequence 10045로 갱신합니다.
- 후원 매칭·저장 형식·DB·사용자 설정·수집 경로는 변경하지 않습니다. 후보 배포는 현재 운영 소스를 보존하고 피드와 다운로드 경로만 명시적으로 교체합니다.

## 사용자 영향과 복구

### 배포 후 CI 검사 보정

배포 커밋 `ec574814415f6b64a6b8e1123e3644c4e8d40816`의 원격 검사에서 기존 PKCE 변조 검사가 간헐 실패했습니다. Base64url 문자열의 마지막 글자를 `A`로 치환하는 방식이 실제 암호문을 바꾸지 않는 경우가 있었으며, 로컬 128회 확인 중 2회 재현했습니다. 원래 바이트를 복사한 뒤 비트 하나를 반전해 반드시 변조된 암호문을 검사하도록 수정했습니다. 해당 검사 파일 7건 통과. 운영 암호화 소스·설치 파일·피드는 변경하지 않으며 배포 태그는 원래 커밋을 유지합니다.

- 새 설치본 및 자동 업데이트를 통해 UI가 적용됩니다. 현재 실행 중인 프로그램의 화면 변경 여부는 실제 업데이트 적용 후 확인해야 합니다.
- 이전 1.0.0.43 ZIP과 1.0.0.43-r2 설치 EXE를 보존합니다. 운영 웹·관리 배포의 이전 ID와 후보 비교 자료는 비공개 `.local`에 보관합니다.
- 서버 측 다운로드·피드 회귀는 보존한 이전 운영 배포로 되돌릴 수 있습니다. 이미 업데이트한 Agent에는 하향 버전을 강제하지 않으며 필요 시 새 sequence와 수정 버전으로 복구합니다.
- Microsoft의 이전 설치 파일 탐지 해제 결과를 이 새 EXE의 판정으로 간주하지 않습니다.

## 제거·보존한 파일과 근거

삭제한 릴리스·설치 루트 파일은 없습니다. GitHub 소스 저장소에는 서명 피드와 공개 provenance·매니페스트만 기록합니다. ZIP·EXE는 기존 전용 릴리스 저장소에만 게시하며 키·개인정보·원문 로그는 게시하지 않습니다.
