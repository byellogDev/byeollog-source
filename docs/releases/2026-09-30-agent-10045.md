## 목적과 변경 전 문제

같은 수량의 큰 후원까지 영역으로 묶여 개별 배치가 어려웠습니다. 수량 범위를 저장해 해당 카드를 독립적으로 움직일 수 있는 기능을 설치본으로 제공합니다.

## 변경 내용과 소유 구성요소

- Agent: `묶음 해제할 풍벽지`에서 양끝을 포함한 수량 범위를 저장합니다. 기존 카드는 현재 위치·크기로 분리하고 신규 카드는 좌상단에 표시합니다. 범위 제거 시 일반 묶음으로 돌아갑니다.
- 범위·좌표는 계정별로 이 PC에 저장합니다. 백두산에 포함한 후원과 구독·도전 성공 카드는 기존 방식으로 표시합니다. 원본 후원·통계·방송 선택·숨김 조건을 보존합니다.
- 설치기: UTF-8 결과 경로와 한글 바로가기 처리를 유지하고 새 패키지의 버전·해시를 고정합니다.
- 웹·관리 런타임: 현재 운영 소스를 보존하며 서명 피드와 공식 다운로드 경로만 변경합니다. 서버 기능·수집기·DB·권한은 변경하지 않습니다.

## 사용자 영향과 복구

- 새 설치본 또는 자동 업데이트 적용 후 편집기에서 사용할 수 있습니다. 다른 PC로 범위·좌표가 동기화되지는 않습니다.
- 새 카드가 여러 장 겹치면 위 카드를 옮겨 아래 카드를 배치할 수 있습니다. 기존 표시량·보관 기간을 유지합니다.
- 고객 PC에서 실제 설치·WebView2·OBS·실방송 후원·재시작은 별도 확인 범위입니다. 이전 EXE의 Microsoft 판정을 새 파일의 판정으로 간주하지 않습니다.
- 범위를 지우면 일반 묶음 표시로 복귀합니다. 이전 1.0.0.44 ZIP·EXE와 운영 배포 ID를 보존합니다. 서버 회귀 시 직전 배포로 복구하며, 이미 업데이트한 Agent에는 필요 시 새 버전·sequence로 수정본을 제공합니다.

## 제거·보존한 파일과 근거

이전 설치 자산과 설정을 삭제하지 않습니다. ZIP·EXE는 전용 릴리스 저장소에만 게시합니다. 서명 개인키·회원 정보·로컬 검증 원문은 공개하지 않습니다.
