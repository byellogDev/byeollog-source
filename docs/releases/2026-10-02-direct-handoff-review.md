## 목적과 변경 전 문제

이전에는 토큰 만료 전에 후보 연결을 종료해 대조 공백이 생겼습니다. 새 연결을 먼저 준비하는 수정본의 실제 토큰 교체와 연속 수신을 검증했습니다. 단순 시간 경과나 서비스 active를 성공으로 계산하지 않습니다.

## 변경 내용과 소유 구성요소

이번 변경은 검증 문서뿐입니다. 연구 관측기 JSONL의 세션별 최종 대조, 교체 단계, 토큰 조회 상태, 소켓 수, 회수, 운영 상태를 확인했습니다. 계정 식별자와 원문은 공개하지 않으며 두 운영 대상을 A/B로 구분합니다.

종류별 일치는 코드 5=3,862, 18=69, 105=1, 109=65, 121=4, 125=1입니다. 모두 후원으로 계산하지 않습니다. 진행 중 대조에서 최대 1건의 일시 미결 표본이 A 21회/B 22회 있었지만 최종적으로 모두 일치했으며 확정 편측 기록은 없었습니다. 이를 영구 누락이나 처음부터 미결이 전혀 없었다는 뜻으로 표현하지 않습니다.

두 교체 모두 같은 세션을 유지했고 다음 세션을 기다리는 종료·재시작 공백이 없었습니다. 41초/83초는 양쪽 연결을 유지한 대조 시간이며 수집 중단 시간이 아닙니다. 각 교체 후에도 각각 약 4시간 47분/4시간 21분 동안 방종까지 수신했습니다. 수신 지연 표본과 교체 결과로 모든 네트워크 장애에서 공백 0 또는 exactly-once를 보증하지 않습니다.

새 코드 변경이 없어 자동검사를 반복 실행하지 않았습니다. 배포 코드의 [기존 원격 검사 통과](https://github.com/byellogDev/byeollog/actions/runs/36727509813)와 이번 실방송 관측은 별도 근거입니다.

## 사용자 영향과 복구

- **정상 토큰 교체 실검증은 두 계정 각 1회 확인 완료**입니다. 새 토큰 조회 실패 동안 기존 연결 유지도 확인했습니다.
- 남은 과제는 같은 연결의 반복 갱신, 실제 네트워크·대체 연결 실패 복구, 내구성 전송 연계, DB·업보·풍벽지·OBS 종단, 계정별 단일 writer 전환·복귀입니다. 내용 일치 검증을 처음부터 다시 요구하지 않습니다.
- 운영 전환·재배포·재시작은 하지 않았습니다. 관측은 사용자 종료 선언까지 기존 정책대로 계속합니다. 강제로 토큰을 만료시키거나 테스트 후원을 주입하지 않았습니다.
- 문제가 생기면 연구 경로를 운영 writer로 승격하지 않고 기존 Chromium을 유지합니다. 연구 코드 복구 절차는 이전 배포 문서에 보존합니다.
