# Agent 1.0.0.60 · 기존 배치 비교로 인한 크기 조절 실패 수정

## 상태와 범위

- 상태: 운영 반영. 2026-10-22 22:01 KST 보호된 후보를 동일 배포로 승격하고 피드·alias를 확인했다.
- 날짜: 2026-10-22 KST.
- 대상: Windows Agent 저장·재시작, stable 피드와 온라인 설치 파일. 웹·관리 런타임은 배포 메타데이터만 변경한다.
- 이전: [1.0.0.59](2026-10-22-agent-10059.md). 고객의 동일 오류 제보를 받아 추가 저장 경로를 재현했다.

## 목적과 변경 전 문제

새 배치가 정상 범위여도 서버와 비교하려고 보관한 수정 전 배치에 같은 편집 범위 검사를 적용했다. 자동 배치의 높이가 46px인 경우 새 높이 60px로 조절한 요청까지 거부됐다. 1.0.0.59 검사는 수정된 배치를 새 값과 비교 기준 양쪽에 넣어 이 조건을 놓쳤다. 이번에는 실제 WallpaperEditorCoordinator 저장 경로에서 동일 예외를 먼저 재현했다. 고객 PC의 실제 저장 자료를 확보한 것은 아니므로 제보 원인이 이 조건과 일치하는지는 별도 확인이 필요하다.

## 변경 내용

- 새 배치는 기존 1920×1080 영역·최소 크기·구성 검사로 검증한다.
- 비교용 이전 배치는 구조·식별자를 검사하고 원래 정수 값을 보존한다. 보정하거나 화면에 적용하지 않는다.
- 재시작에도 비교 기준을 유지한다. 서버 값이 바뀌면 백업을 보류하는 충돌 방지는 유지한다.
- 배치 거절 메시지에 카드 묶음 순번·좌표·크기를 포함한다. 후원자·URL 등 개인정보는 포함하지 않는다.

## 사용자 영향과 복구

배치 초기화 없이 정상 범위의 크기 조절이 가능하도록 한다. 기존 후원·숨김·순서·로컬 설정을 보존한다. 비교 기준은 원본 그대로이므로 다른 곳에서 바뀐 서버 배치를 덮어쓰지 않는다. 이전 운영 후보·피드·설치 자산을 보존하며 웹은 기존 후보로 복구 가능하다. 이미 업데이트된 Agent는 낮은 sequence를 강제 적용하지 않고 필요 시 높은 버전으로 복구한다.

## 제거·보존한 파일
