# 사용자 선언 기준 관측 종료 · 2026-09-26

## 상태와 범위

- 연구 감독기 반영: 2026-09-26 13:43 KST.
- 사용자가 관측완료를 선언할 때까지 수집하며 비교 검증은 요청할 때 수행한다.
- 이전의 9월 26일 14:00 종료 결정은 이번 요청으로 대체됐다. [이전 관측기 수정](2026-09-26-monitor-control-frames.md).

## 목적과 변경 전 문제

고정된 48시간 종료 정책은 사용자 의도와 달랐다. 캠페인 종료와 연결별 시한을 분리해 관측을 계속한다.

## 변경 내용과 소유 구성요소

- 연구 감독기에서 명시적인 `stopPolicy: user_declared`와 `endEpoch: null` 조합만 종료 시각 없는 관측으로 허용한다. 실수로 시각을 누락한 설정은 실패한다.
- 개별 세션의 48시간 상한·OAuth 만료 전 종료는 유지하고 정상 종료 후 다음 제한된 세션을 시작한다. 방송 대기는 계정별로 독립한다.
- 서버 `RuntimeMaxUSec=infinity`, 캠페인 `endEpoch=null`을 확인했다. 과거 14:00 자동 종료가 적용되지 않는다.
- 중단·재시작을 포함한 이전 구간은 별도로 보존했다. 실제 관측 시간에 전환 공백·방송 대기를 포함하지 않는다.
- 기존 소켓·수신 코드 및 비교 알고리즘은 그대로다. 운영 수집기·회원 데이터·권한·취소한 Codex 자동화는 변경하지 않았다.

## 사용자 영향과 복구

후보는 수신 전용이며 운영 데이터는 기존 경로만 반영한다. 검증 요청은 그 시점까지의 비교를 뜻하며 관측 종료 선언으로 해석하지 않는다. 오류·계정 혼선·수신 불일치·자원/증거 용량 상한의 안전 중단은 유지된다. 무기한 가동 또는 서버 장애 후 자동 복구를 보증하는 변경은 아니다.

사용자가 관측완료를 선언하면 해당 연구 서비스만 정리하고 전체 구간을 보존·집계한다. 문제 시 새 연구 서비스만 중지하며 운영 수집기를 건드리지 않는다. 취소된 예약 점검은 재개하지 않았다.

## 제거·보존한 파일과 근거
