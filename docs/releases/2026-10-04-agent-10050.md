# Agent 1.0.0.50 · 기존 PC 자동 로그인 재연결 수정

## 상태와 범위

- 상태: 서버 인증 수정, Agent 설치본·서명 업데이트 피드 운영 반영 완료.
- 확인일: 2026-10-04 KST. 이전 버전: [1.0.0.49](2026-10-04-agent-10049.md).
- 대상: 기존 PC 재등록 RPC, Agent 연결 상태 안내, 정식 설치본과 업데이트 경로.

## 목적과 변경 전 문제

저장된 로그인으로 프로그램을 재실행할 때 장치 등록 RPC가 기존 PC 여부를 확인하기 전에 로그인 후 10분 경과를 검사했습니다. 유효한 계정 세션과 등록된 장치 키가 있어도 `BL101`로 거절됐고, Agent는 저장 세션을 해제했습니다. 이후에도 로컬 재시도 루프가 실행 중이라는 이유로 화면에 ‘서버 재연결 중’을 표시해 자동 복구가 가능한 것처럼 안내했습니다.

## 변경 내용과 소유 구성요소

- **DB 인증**: 계정·세션·운영 허용 조건을 먼저 검사한 뒤, 같은 워크스페이스의 기존 PC는 유효한 장치 키로 재인증합니다. 새 PC 등록에만 최근 대화형 로그인 조건을 적용합니다. 취소된 장치, 다른 키, 세션당 1회 등록 및 활성 PC 5대 제한은 유지합니다. 함수 실행 권한은 기존 `postgres`·`service_role`로 유지합니다.
- **Agent UI**: 로그인 정보가 없는데 재시도 루프만 실행 중이면 ‘다시 로그인해주세요’를 표시합니다. 로컬 초기화 실패는 별도로 안내하며 정상 로그인 상태의 일시적 네트워크 오류는 기존 재연결 안내를 유지합니다.
- **설치/업데이트**: 1.0.0.50, sequence 10051. 기존 설치·복구 루트 9개를 보존합니다. 웹/관리 프로젝트에서는 업데이트 피드와 설치 다운로드 경로만 변경합니다.

## 사용자 영향과 복구

- 정상적으로 저장된 로그인과 장치 키가 있는 기존 PC는 재실행할 때 최근 로그인 제한에 걸리지 않습니다.
- 이전 오류로 이미 로그인 정보가 지워진 PC는 한 번 직접 로그인해야 합니다. 이 수정이 지워진 세션을 되살리지는 않습니다.
- 원본 후원 데이터·풍벽지 배치·뽑기판·장치 키를 삭제하거나 초기화하지 않습니다. 실제 고객 PC에서 다시 로그인한 뒤 정상 연결되는지는 사용자 확인이 남아 있습니다.
- 서버 복구는 비공개로 보관한 변경 전 함수 정의를 사용합니다. 앱/웹 복구는 이전 배포와 1.0.0.49 자산을 보존하며, 자동 다운그레이드는 별도 단조 증가 버전이 필요합니다.
