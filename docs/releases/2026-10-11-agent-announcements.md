# Agent 1.0.0.57 · 2026-10-11

## 상태와 범위

- 상태: 공지 페이지·웹/관리 안정 업데이트 피드 운영 반영, 정식 Agent 설치 자산 게시.
- 확인 시각: 2026-10-11 20:15 KST 이후 운영 별칭·파일 확인.
- 대상: Agent 메인 공지 링크, 공개 정적 공지 페이지·피드, 설치/업데이트 메타데이터.
- 기존 후원·업보 데이터, 수집기, DB 권한은 변경하지 않습니다.
- 이전 안내: [현행 안내·크레딧·특수룰렛 관리](2026-10-11-guide-credit-history.md). 이전 Agent: 1.0.0.56.

## 목적과 변경 전 문제

수집 구조가 바뀌어 오버레이 주소와 수집 ON 설정이 필요하지만 Agent 사용자가 변경 안내를 바로 확인할 수 없었습니다. 향후 공지도 Agent를 매번 재배포하지 않고 안내할 수 있어야 합니다.

## 변경 내용과 소유 구성요소

- Agent: 서버 연결 상태 제목 아래 기존 남색·금색 디자인으로 “새로운 공지가 있어요! (10/11)” 링크를 표시합니다. 게시 시각부터 72시간이 지나면 숨기고 클릭 시 기본 브라우저에서 공지를 엽니다.
- 공개 공지: 오버레이 주소 저장 → 업보 수집 ON → 미분류 결과 최초 분류를 안내합니다. 룰렛 사전 등록 없이 월·수량으로 이벤트명이 생성되는 예와 선택적인 이벤트명 사전 등록을 설명합니다.
- 정적 피드: 최초 및 30분 간격으로 읽고 최근 유효 공지를 선택합니다. 로그인 정보를 보내지 않으며 5초·32 KiB 제한, 외부 주소·리디렉션 차단, 네이티브 링크 검증을 적용합니다. 실패해도 유효 캐시만 남기고 만료는 계속 적용합니다.
- 이후 게시 절차: [Agent 공지 게시](../agent-announcements.md). 앞으로는 페이지·피드만 게시하면 Agent 새 버전 없이 표시됩니다.

## 사용자 영향과 복구

- Agent 1.0.0.57로 업데이트하면 새 공지 링크가 보입니다. 클릭 후에도 게시 72시간까지 표시하며, 공지 페이지는 계속 열 수 있습니다.
- 향후 공지 감지는 Agent 최대 30분 + CDN 캐시 최대 5분이 걸릴 수 있습니다. 네트워크 없이 새로 켜면 공지는 표시되지 않습니다. PC 시각을 기준으로 표시 기간을 판단합니다.
- 이상 시 피드의 공지를 제거하거나 이전 웹/관리 배포로 복구합니다. 배포 기록은 비공개로 보존합니다. 이미 설치한 Agent는 다운그레이드 피드로 강제 복귀하지 않고 필요 시 높은 시퀀스의 수정 버전을 게시합니다.
- 기존 설치 루트·이전 버전·후원 데이터는 보존합니다.
