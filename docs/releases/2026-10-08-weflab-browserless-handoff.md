# 위플랩 브라우저 없는 조회·담당 인계 후보 · 2026-10-08

## 상태와 범위

- 상태: 연구 후보. 운영 미배포, 설치 파일 변경 없음.
- 확인 시각: 2026-10-08 07:41 KST 실제 API 조회.
- 대상: 위플랩 결과 조회 계획, 중앙 담당권/예약 저널, 서버·PC 공통 후보 워커.
- 이전 기준: [표시 결과 경로 검토](2026-10-08-weflab-displayed-results.md). 기존 예약 관측은 수신 전용으로 보존.

## 목적과 변경 전 문제

주소의 소켓 연결만으로는 테스트 결과 알림을 받지 못했다. 브라우저 없이 원본 페이지와 같은 조건의 저장 결과를 조회하고, 서버 기본·Agent 준비 시 PC 우선이라는 사용자 결정에 맞춰 중복 요청을 막는 후보가 필요했다.

## 변경 내용과 소유 구성요소

- 연구 도구: 계정 고정·정확 금액 규칙·원본 테스트 UID·회차 수를 검증하고 요청을 구성.
- 중앙 연구 RPC: 계정별 담당권, 서버 요청 마무리 후 Agent 인계, Agent 유효기간 종료 후 서버 복귀, 후원별 영속 예약.
- 공통 워커: 한 번의 요청과 비공개 전체 응답 보존. 타임아웃·완료 전달 실패 때 자동 재조회 금지.
- 승인 범위: 화면 결과를 확인한 테스트 계획만 실제 조회. 운영 자동 조회는 거절.

## 검증

| 항목 | 방법 | 결과 | 확인하지 못한 범위 |
| --- | --- | --- | --- |
| 자동 검사 | 두 Weflab 테스트 파일 | 28건 통과 | 모든 제품 회귀 재실행 아님 |
| 담당권 통합 | 같은 PC의 두 역할·HTTP RPC | Agent 우선·서버 복귀·중복 요청 방지 | 실제 두 호스트/Windows Agent |
| 실제 조회 | 사용자 확인된 30개 테스트 1건 | 브라우저 없이 `sql`의 `꽝` 수신, 화면 보고와 일치 | 실방송·다회·범위 룰렛 |
| 독립성 | 요청 입력·실행 코드 확인 | 기존 채팅·별록 DB 결과 불필요 | 자동 방송 완료 판정 |
| 후보·운영 | 배포 미실행 | 기존 운영 유지 | 제품 인증·설치·종단 전송 |

자세한 설계·증거 범위는 [연구 기록](../research/2026-10-08-weflab-browserless-handoff.md)에 남겼다. 결과 API의 `save`는 이미 생긴 부작용일 수 있으므로 사후 오류 처리만으로 비생성을 보증하지 않는다.

## 사용자 영향과 복구

- 현 사용자 프로그램 변화 없음. 제품 Agent 통합·자동 운영 수집은 남아 있다.
- 중앙 조정 서비스 장애 시 새 요청을 중단한다. 불확실한 예약은 재시작으로 풀지 않는다.
- 후보 중지로 복구하며 비공개 요청/응답/저널은 유지한다. 기존 운영 수집은 독립적으로 그대로 둔다.

## 제거·보존한 파일과 근거

WebView 실험은 브라우저 없는 구조 결정에 따라 비공개 보관으로 옮겼다. Agent 기능 소스 변경은 남기지 않았다. 기존 관측 근거·개인 데이터·원본 응답은 공개 게시하지 않는다.
