# 2026.09.24 · 마크 연동 후보 운영 반영

## 목적과 결정

사용자가 아직 사용하지 않는 마크 연동의 남은 실제 검증·후속 개선은 이후 진행하기로 하고, 준비된 후보의 운영 반영을 명시적으로 승인했습니다. 기존 자동검사와 보호된 후보 검증을 근거로 웹·관리자 런타임을 반영했습니다. 실제 사용자 OAuth 완료를 새로 확인했다고 표현하지 않습니다.

## 반영 내용

- 웹 프록시의 Minecraft 서버 인증 헤더 전달.
- 게임 연동과 일반 SOOP 가입·연결의 쿠키 충돌 처리 및 흐름 선택.
- 정지한 계정 연동의 재활성화 거절과 충돌 응답. DB 방어는 앞서 별도 적용했습니다.
- Minecraft 조회 요청의 파싱·본문 제한·오류 응답 및 만료 세션 처리.
- 앞서 반영한 읽기 전용 `observe` 계약 유지.

후원→Minecraft 게임 동작 전달 기능은 아직 구현되지 않았으며 이 배포에 포함되지 않습니다. 서버 키 발급 도구 수정은 로컬 도구에 해당하며 운영 키를 발급·회전하지 않았습니다.

## 배포와 검증

관리자는 현재 canonical 소스와 일치를 확인한 기존 보호 후보를 사용했습니다. 웹은 임시 후보 관리자 URL을 넣지 않고 기존 운영 환경의 관리자 주소로 별도 후보를 만들었습니다. 임시 Preview 환경 대상은 원복했습니다.

- 앞선 Node 22 전체 자동검사 **774건 통과** 이후 실행 소스 변경이 없어 같은 전체 검사를 반복하지 않았습니다.
- 반영 전 기준 소스 1,183개 대조 성공, 의도한 차이 34개, `git diff --check` 통과.
- 관리자 업로드 소스 **141개**, 웹 업로드 소스 **647개**가 각각 후보와 운영에서 일치했습니다.
- Vercel 승격은 별도 운영 빌드를 생성했습니다. BUILDING 상태를 조회한 뒤 배포를 반복하지 않고 같은 배포의 READY 완료와 실제 소스를 확인했습니다.
- 최종 웹 후보 및 10:12 KST 운영에서 로그인·가입 화면 200, 게임 연결 health/status 200, 미인증 SOOP 상태 조회 401을 확인했습니다.
- 일반 가입 연결 시작 302와 남은 게임 쿠키 삭제, cross-site 게임 시작 403과 쿠키 불변, 잘못된 Minecraft 서버 키 401을 확인했습니다.
- 운영 화면·CSS·JS 등 **41개 파일의 응답 바이트가 배포 원본과 모두 일치**했습니다.

이번 확인에서 실사용 계정·연동·권한을 변경하지 않았습니다. 앞서 보호 후보에서 수행한 서버별 허용·거절·nonce 중복·정지·폐기·키 회전 검사는 [후보 릴리스](2026-09-24-minecraft-candidate.md)에 별도 기록되어 있으며, 이번 운영 배포에서 반복한 것으로 계산하지 않습니다.

## 남은 범위와 복구

실제 SOOP·Microsoft 인증 완료, 동시 탭의 실제 사용자 흐름, 분산 요청 제한과 정기 자료 정리는 후속 항목입니다. 사용자 승인으로 운영 반영했으며 미검증 항목을 검증 완료로 바꾸지 않습니다.

기존 수집 런타임·NCP 수집기·관측 예약·Agent·백업은 반영 대상이 아닙니다. 웹·관리자의 이전 운영 배포와 신규 배포, 소스 대조·HTTP 결과는 비공개 `.local/minecraft-release-20260924/`에 보관합니다. 필요시 기록한 이전 배포로 복구하며 관리자 이전 배포에는 관측용 API가 포함되어 있습니다. 정지 우회 방어 DB 변경은 유지합니다.
