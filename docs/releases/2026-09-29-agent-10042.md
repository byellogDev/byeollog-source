# Agent 1.0.0.42 · 2026-09-29

## 상태와 범위

- 상태: 공식 다운로드·자동 업데이트·관리자 최신 버전 피드 운영 반영 완료.
- 확인 시각: 2026-09-29 03:31 KST 이후 최종 공개 주소 확인.
- 대상: Windows 풍벽지 Agent, 웹 다운로드/서명 피드, 관리자 서명 피드.
- 이전: [설치 EXE 1.0.0.41-r2](2026-09-28-installer-r2.md). 구현·화면 검증: [풍벽지 편집 수정 후보](2026-09-29-wallpaper-editor-controls.md).

## 목적과 변경 전 문제

풍벽지 편집 도구가 카드 캔버스와 함께 축소되어 글씨가 작았습니다. 주변 카드의 정렬 잠금 때문에 화면 끝까지 끌어도 여백이 남는 오류도 있었습니다. 검증한 수정본을 사용자가 설치할 수 있도록 새 Agent 버전으로 배포했습니다.

## 변경 내용과 소유 구성요소

- Agent 1.0.0.42: 화면 크기가 유지되는 편집 도구막대와 조절점, 화면 경계 우선 정렬. 카드 출력 크기와 저장·인증·설치 프로토콜 유지.
- 웹: 다운로드를 1.0.0.42 온라인 EXE로 연결하고 RSA-PSS 서명 업데이트 피드를 sequence 10043으로 갱신했습니다.
- 관리자: 같은 서명 피드로 최신 버전 표시를 갱신했습니다.
- 운영 원본과 대조하여 웹 소스 647개 중 2개, 관리자 소스 142개 중 1개만 변경했습니다. 로컬의 다른 미배포 웹 변경 3개는 기존 운영 파일로 보존했습니다. 도쿄 hnd1 유지.
- 기존 업데이트 설치 루트 9개는 바이트 단위로 동일하게 보존했습니다. 온라인 설치 래퍼의 Unicode 바로가기 수정도 유지했습니다.

## 사용자 영향과 복구

- 새 버전으로 업데이트하면 편집 도구와 오른쪽 경계 수정이 적용됩니다. 기존 카드·배치·로그인 설정을 초기화하지 않습니다.
- 공식 다운로드: <https://byeollog.com/agent/download>
- 고정 설치 파일: <https://byeollog.com/agent-updates/releases/1.0.0.42/Byeollog-Wallpaper-Setup-v1.0.0.42-online.exe>

- EXE SHA-256: `22ff5b8eee8c8f6a16c3984da5e65aec67a529ceacea96202410ba639f6cc622`
- 장애 시 웹·관리자 각각의 직전 배포로 되돌려 피드·다운로드 안내를 복구합니다. 이미 1.0.0.42를 받은 PC를 피드의 sequence를 낮춰 강제로 다운그레이드하지 않습니다. 기존 설치기의 보존된 이전 버전 복구 경로를 사용합니다.

## 제거·보존한 파일과 근거

기존 EXE·ZIP·프로토콜 루트·개인 설정과 복구본을 삭제하거나 덮어쓰지 않았습니다. 공개 저장소에는 서명 피드·공개 매니페스트·해시만 포함하며 개인키·인증값·로그 원문은 포함하지 않습니다. 실행 파일은 기존 전용 릴리스 저장소에 게시했습니다.
