# 소스 연결 지도 · 2026-10-13

## 상태와 범위

- 상태: 연구 체크포인트 / 분석 도구 및 문서 변경, 운영 미배포.
- 대상: 기존 Graphify 결과를 읽는 로컬 지도 생성기.
- 기존 웹·Agent·수집기·DB·설정·설치 파일은 변경하지 않습니다.
- 이전 기준: `b6e8178d5c174d162cd6281ee5465d5faaed884a`.

## 목적과 변경 전 문제

Graphify가 HTTP·RPC·콜백 경계를 잇지 못해 Agent가 별도 섬처럼 보이고 SQL·테스트·설정이 서비스 구조와 섞였습니다.

## 변경 내용과 소유 구성요소

- 12개 역할과 주요 연결 20개, 근거 53곳을 대조한 별도 지도를 생성합니다.
- 파일 1,558개 분류, RPC 이름 101개 대조 후보, 외딴 커뮤니티 588개 분석을 검색 가능한 화면으로 제공합니다.
- 소스 근거 앵커가 사라지면 생성이 실패합니다. 파일·그래프 SHA-256과 분석 커밋을 기록합니다.
- 외부 호출 측 근거, 단순 이름 일치 후보, 현재 운영 상태 미검증을 구분합니다.

로컬 `architecture.html`에서 주요 서비스 경계를 볼 수 있습니다. 기존 `graph.html`은 그대로 열 수 있습니다. 생성 도구·뷰어만 제거하면 되며 서비스 복구 작업은 필요하지 않습니다.
