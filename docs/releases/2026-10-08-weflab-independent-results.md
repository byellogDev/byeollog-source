# 위플랩 독립 결과 수신 경로 조사 · 2026-10-08

## 상태와 범위

연구 체크포인트. [URL 관측 준비](2026-10-08-weflab-observation.md)의 후속이며 운영 배포 없음.

## 목적과 변경 전 문제

기존 별록 결과를 기다리는 조회 방식은 독립 수집기를 만들지 못한다. 추첨을 생성하지 않는 결과 수신 대안을 조사했다.

## 변경 내용과 소유 구성요소

관리 화면의 후원 UID 기반 결과 알림과 실제 렌더러 응답 관측 대안을 정리했다. 처음 검토한 위플랩 채팅 경로는 위플봇 송신 누락을 해결하지 못하므로 사용자 정정에 따라 제외했다. 결과 알림도 봇 전송 성공에 의존하지 않아야 한다. 결과 채널을 오버레이 URL만으로 받을 수 있는지는 미검증이다. 운영 코드·환경·서버 예약은 변경하지 않았다.

검증 기준도 정정했다. 기존 채팅 수집은 누락될 수 있으므로 후보에만 있는 결과를 바로 오류로 판정하지 않는다. 실제 화면 또는 원래 추첨 응답으로 대조하며, 테스트 환경에서 봇 결과 채팅 없이도 수신하는 것을 필수 조건으로 추가했다. 이 조건은 아직 실검증하지 않았다.

## 검증

| 항목 | 방법 | 결과 | 미검증 |
| --- | --- | --- | --- |
| 공개 코드 | 공식 JavaScript 재조회·해시 대조 | 동일, 결과 알림 처리 확인 | 서버 채널 배포·권한 |
| 테스트 API | 인자 생략 2건 | noparam | 내부 처리 전체 |
| 테스트 API | 빈 확률표 1건 | save 및 빈 결과, 추가 호출 중단 | 서버측 저장 변경 범위 |
| 응답 관측 | WebView2 공식 문서 | 실제 응답 관측 API 존재 | Agent/OBS 구현 |

실방송 성공 건수나 단위 검사 건수를 추가하지 않는다. 원래 테스트 응답과 새 빈 결과 응답을 구분해 보존했다.

## 사용자 영향과 복구

실제 방송 계정에는 결과 API를 호출하지 않았다. 테스트 계정에서 save 응답을 받았으므로 읽기 전용이었다고 주장하지 않는다. 인자 우회는 채택하지 않는다. 되돌릴 운영 배포는 없다. 기존 예약은 후원 수신 연구이며 독립 룰렛 결과 수신은 미완성이다.

## 제거·보존한 파일과 근거

삭제 없음. 공개 코드는 링크·해시·분석만 기록하고 주소·회원 정보·API 원문은 비공개 `.local`에 보존했다.
