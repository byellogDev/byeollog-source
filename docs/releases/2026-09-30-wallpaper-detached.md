# 풍벽지 금액 범위 묶음 해제 · 2026-09-30

> 후속 배포: [Agent 1.0.0.45](2026-09-30-agent-10045.md)에 운영 반영했습니다. 아래는 설치본 발행 전 후보 단계의 구현·검증 기록입니다.

## 상태와 범위

- 상태: 구현·로컬 검증 후보. 설치 EXE·운영 업데이트 피드 미배포.
- 대상: Windows Agent의 로컬 풍벽지 편집기·설정 저장·OBS 렌더링.
- 이전 기준: [Agent 1.0.0.44](2026-09-29-agent-10044.md).
- 서버 API, 후원 수집기, 원본 후원·통계, DB·권한은 변경하지 않았습니다.

## 목적과 변경 전 문제

같은 금액의 후원이 영역 단위로 묶여 큰 후원 한 건만 독립적으로 배치하기 어려웠습니다. 사용자가 금액 범위를 지정하면 해당 후원을 카드별로 직접 배치할 수 있도록 합니다.

## 변경 내용과 소유 구성요소

- `묶음 해제할 풍벽지` 버튼에서 최소·최대 별풍선을 입력하고 저장합니다. `1000~1000`은 1,000개 후원만, `1000~1000000`은 지원 수량 내 1,000개 이상 후원을 지정합니다. 양끝 포함, 최대 20범위, 겹침·역전·잘못된 숫자는 거절합니다.
- 기존 카드는 현재 보이는 위치와 크기로 분리합니다. 묶음 영역·다음 열 공간 없이 카드 자체를 드래그하거나 방향키로 이동합니다. Shift+방향키는 10픽셀 이동입니다.
- 새로 표시되는 해당 범위 후원은 좌상단 `(0,0)`에서 시작합니다. 같은 금액의 이전 카드 위치를 물려받지 않습니다. 여러 장이 겹치면 위 카드를 먼저 옮겨 아래 카드를 꺼낼 수 있습니다.
- 원본 카드의 일반 배치는 변경하지 않습니다. 범위를 지우고 저장하면 일반 묶음 표시로 복귀합니다. 구독·도전 성공 카드와 백두산에 직접 포함한 후원은 개별 카드 대상으로 처리하지 않습니다.
- 선택한 방송 회차, 숨김 설정, 기존 표시량·보관 기간을 유지합니다. 숨김 후원을 강제로 표시하거나 원본 로그에서 새로운 후원을 만들지 않습니다.
- 범위와 카드별 좌표는 기존 계정별 로컬 디렉터리에 원자적으로 저장합니다. 다른 계정과 공유하지 않으며 재시작 후 복원합니다. 서버 백업·다른 PC 동기화 대상은 아닙니다. 좌표 기록은 최대 4,096개로 제한하며 가장 오래 사용하지 않은 기록부터 정리합니다.
- 편집기와 OBS용 HTML은 같은 카드 렌더러를 사용합니다. 로컬 설정 버전을 표시 상태에 포함해 원본 후원 revision이 같아도 카드 이동이 반영됩니다. 추가 주기 조회나 운영 서버 쓰기 요청을 만들지 않습니다.
- 새 스크립트를 실행 파일에 포함하고 UI 캐시 경로를 변경했습니다.

## 사용자 영향과 복구

후보이므로 현재 설치본은 바뀌지 않습니다. 운영 반영에는 새 Agent 설치본 발행이 필요합니다. 반영 후에는 범위를 제거해 일반 묶음으로 돌아갈 수 있으며, 이전 설치본을 사용하면 별도 개별 배치 설정을 읽지 않고 기존 일반 배치를 표시합니다. 원본 후원·통계는 유지됩니다. 설정 파일 손상 시 원본 파일을 덮어쓰지 않고 오류를 표시합니다.

개별 카드는 원래 카드 크기를 유지하며, 새 카드에는 해당 금액의 크기 규칙을 적용합니다. 실제 사용자 PC에서 WebView2·OBS·실방송 인입·재시작 확인은 후속 배포 검증 대상입니다.

## 제거·보존한 파일과 근거

운영 파일·설치 자산 삭제 없음. 합성 응답, 실행 로그 등 검증 자료는 비공개 `.local`에만 보관합니다.
