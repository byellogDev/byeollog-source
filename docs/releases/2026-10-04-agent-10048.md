# Agent 1.0.0.48 · 풍벽지 글자 영역 배경 수정 · 2026-10-04

## 상태와 범위

- 상태: **운영 반영 완료**. 2026-10-04 07:49 KST 기준 Windows 풍벽지 설치본과 서명 업데이트 피드(sequence 10049), 실제 다운로드 검증 완료.
- 이전 기준: [Agent 1.0.0.47](2026-10-04-agent-10047.md).
- 일반 카드·작은 카드·묶음 해제 카드의 글자 배경 적용 범위 수정. 웹 서비스의 업무 기능과 수집기는 변경하지 않습니다.

## 목적과 변경 전 문제

커스텀 배경색을 카드 전체 컨테이너에도 적용하여 투명한 후원 이미지 뒤가 단색 사각형으로 덮였습니다. 사용자가 의도한 배경은 닉네임과 후원 수량 뒤의 영역입니다.

## 변경 내용과 소유 구성요소

- 편집기·OBS용 공통 렌더러에서 카드 전체 배경 규칙을 제거하고 글자 영역에만 색상을 적용합니다. 백두산의 채워진 글자 칸은 설정한 배경색을 유지합니다.
- 설정 이름을 **글자 영역 배경**으로 변경하고 이미지 영역의 투명도를 유지한다고 안내합니다.
- 계정별 기존 `backgroundColor` 값과 글자·폰트 설정을 그대로 사용합니다. 데이터 변환이나 초기화는 없습니다.
- Agent와 UI 캐시 버전을 1.0.0.48로 갱신하여 기존 설치 환경에서도 수정된 UI를 불러옵니다.
- 기존 운영 웹·관리 소스에서 업데이트 피드와 다운로드 주소만 후보에 반영합니다.

## 사용자 영향과 복구

- 1.0.0.48 업데이트 후 이미지 뒤의 단색 배경이 사라집니다. 저장한 색상은 닉네임·수량 뒤에 유지됩니다.
- 문제가 있으면 커스텀의 기본 스타일 복원 기능을 사용할 수 있습니다. 필요시 비공개 운영 기록의 직전 배포와 보존한 1.0.0.47 자산을 사용합니다. 자동 업데이트 복구는 sequence가 증가하는 수정본으로 수행합니다.
- 실제 고객 PC의 업데이트 완료·방송 OBS 사용은 별도 확인 대상입니다.

## 제거·보존한 파일과 근거

카드 전체 배경 CSS 한 규칙을 제거했습니다. 이미지·후원 자료·사용자 설정·이전 설치 자산·서명 신뢰 키를 보존합니다. 비공개 키와 배포 자격증명은 게시하지 않습니다.
