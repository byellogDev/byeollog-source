## 상태와 범위

- 상태: **후보 서버 생성·기본 설정. 기존 NCP 운영과 관측 유지, 운영 전환 미실행.**
- 확인 시각: 2026-10-05 06시 KST.

- 범위: iwinv 후보 호스트, 전용 관리 키, 제한 방화벽, 운영 이미지의 격리 검사. 사용자 데이터·운영 인증값 이전은 포함하지 않는다.

## 목적과 변경 전 문제

소규모 운영의 서버 고정비를 줄이되 메모리 여유와 기존 복구 경로를 유지한다. 사용자가 iwinv 로그인·본인인증·카드 등록을 완료하고 전용 SSH 키 등록 및 후보 한 대 생성을 승인했다.

## 변경 내용과 소유 구성요소

- KR1-Z03에서 gna_2.8_n 단독형 2vCPU/8GB/NVMe 50GB, Ubuntu 24.04 후보 한 대 생성. 추가 블록 스토리지·NAT 게이트웨이 없음.
- 전용 공개키를 등록하고 로컬 비밀키 접근을 사용자 계정으로 제한했다. 클라우드/호스트 방화벽에서 관리 IP의 SSH만 허용하고 비밀번호 로그인을 차단했다.
- Ubuntu 공식 패키지의 Docker·Compose 설치. 운영 이미지 ID가 같은 이미지만 스트리밍 복사하여 로컬 대용량 사본 생성을 피했다.
- [이전·검증·복구 절차](../../operations/iwinv/README.md)에 수집기 외 여섯 호스트 타이머와 연구 관측기 이전 조건을 기록했다.

## 사용자 영향과 복구

- 사용자 화면·수집 경로·데이터 변경 없음. 후보는 운영 반영하지 않는다.
- 후보 요금은 VAT 포함 월 36,740원 또는 일 1,364원. 월 중간 사용은 일 요금 조건이며 검증 중에는 NCP 비용도 겹친다. 부가 서비스와 초과 트래픽은 별도다.
- 남은 조건: 실제 SOOP 연결·전달·연속성, 기존 타이머·백업·연구 자료 이관, 재부팅 복구, 단일 운영 수집기로 전환 후 계정별 확인.
- 후보 장애 시 기존 NCP가 계속 운영한다. 실제 전환 뒤 복구는 신규 쓰기 중지와 큐 대조를 먼저 수행한다. 기존 서버 삭제는 이번 작업에 포함하지 않는다.

## 제거·보존한 파일과 근거

기존 자료 삭제 없음. 신청 화면·실행 결과·이미지 ID·키·호스트 정보는 비공개 로컬 증거에 보존한다. 테스트 컨테이너만 종료 후 회수한다.
