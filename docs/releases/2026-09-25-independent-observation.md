# 2026.09.25 · 세 계정 독립 관측 시작 조건 수정

## 목적과 변경 전 문제

세 계정을 함께 관측하라는 요청과 달리 테스트 계정의 실제 비교 통과를 다른 두 후보의 시작 조건으로 구현했습니다. 테스트 방송이 꺼져 있어 9월 24일 운영 방송의 후보 비교를 놓쳤습니다. 운영 수집 실패와 후보 비교 미실행은 별개입니다.

## 상태와 변경

2026-09-25 04:27 KST 연구 감독기만 교체했습니다. 각 계정이 자신의 기존 연결 상태에 따라 관측을 시작하며, 60초·프레임 1건 일치는 계정별 증거로만 기록합니다. 계정별 컨테이너·인증·대상 소유자 확인·불일치 중단·회수 검사는 유지했습니다. 운영 웹·수집기·사용자 데이터·권한은 변경하지 않았습니다.

기존 연구 서비스의 기록이 대기뿐이며 후보 잔류가 없음을 확인한 뒤 종료했고, 이전 디렉터리·설정·기록을 보존했습니다. 새 연구 구간을 분리하고 종료 예정은 9월 26일 14:00 KST로 유지했습니다. 이전 오류를 무시하거나 오류 후보를 강제로 재시작한 변경은 아닙니다.

## 검증과 미검증

- 로컬 및 서버에서 감독기 9건·대조기 6건 통과. 테스트 계정이 오프라인이어도 다른 두 계정이 각자 연결을 시작하는 조건과 모든 계정의 불일치 중단을 검사했습니다.
- 반영 후 서버의 세 계정 모두 각자의 `waiting_for_live / broadcast_offline`을 조회하여 대기함을 확인했습니다. 다른 계정 통과 대기는 제거됐습니다.
- 확인 시 모두 방송 대기이므로 수정 후 실제 메시지·후원 비교와 동시 수신은 아직 미검증입니다. 서비스 active를 수신 성공으로 보지 않습니다.
- 교체 전 관측계정A·관측계정B 비교 실적은 0건입니다. 원래 예약 기간의 경과를 48시간 실검증으로 표현하지 않습니다.

## 영향과 복구

연구 후보의 시작 정책 변경이며 기존 Chromium 경로만 운영 데이터를 반영합니다. 불일치·격리 실패·회수 실패 시 기존 중단 정책을 유지합니다. 관측에 문제가 있으면 연구 서비스만 중단하고 증거를 보존하며 운영 경로는 그대로 둡니다. 잘못된 계정 선행 조건을 자동 복원하지 않습니다.
