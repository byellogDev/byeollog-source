# Agent 1.0.0.47 후보 · 풍벽지 커스텀 · 2026-10-04

## 상태와 범위

- 상태: 로컬 빌드·검증을 완료한 소스 후보. 설치 EXE·업데이트 피드에는 미반영.
- 확인 시각: 2026-10-04 06:53 KST.
- 대상: Windows Agent의 로컬 풍벽지 배치 편집기·로컬 OBS 출력 페이지.
- 이전 운영 기준: [Agent 1.0.0.46](2026-10-02-agent-10046.md). 수집기·DB·웹 운영 배포는 변경하지 않았습니다.

## 목적과 변경 전 문제

풍벽지의 폰트와 빨간 닉네임, 후원 수량 글자, 카드 배경이 고정되어 방송 화면에 맞게 조정하기 어려웠습니다. 작은 카드의 기존 한 줄 출력에도 같은 커스텀이 필요했습니다.

작은 카드의 문구·순서·한 줄 표시는 그대로 유지합니다. 줄 수 선택과 텍스트 편집 기능은 포함하지 않습니다.

## 변경 내용과 소유 구성요소

- 로컬 배치 화면의 **풍벽지 커스텀** 버튼에서 폰트 파일 링크, 닉네임 색, 후원 수량 색, 카드 배경색, 글자 크기를 설정합니다.
- 실제 카드 크기를 기준으로 글자 크기 허용 범위와 미리보기를 제공합니다. 다른 크기의 카드는 각 카드의 범위로 제한하고 긴 문구는 말줄임 처리합니다.
- HTTPS WOFF2·WOFF·TTF·OTF 파일 링크를 지원합니다. 외부 CSS를 삽입하지 않으며 폰트 확인 실패 시 저장을 막고 작성 중인 값을 유지합니다. 파일 제공 서버의 CORS 허용이 필요합니다.
- 일반 카드·묶음 해제 카드·백두산의 채워진 칸이 같은 렌더링 모듈을 사용합니다. 빈 백두산 칸은 변경하지 않습니다.
- 작은 카드의 기존 한 줄 문자열을 보존하면서 닉네임 부분에 별도 색을 적용합니다. 닉네임은 HTML로 해석하지 않습니다.
- 설정은 이 PC의 계정별 디렉터리에 원자적으로 저장됩니다. 재실행 복원, 취소, 기본 스타일 복원, 손상 파일 보존을 지원합니다. 후원 원본과 배치는 수정하지 않습니다.
- 설정만 바뀌어도 OBS 표시 리비전이 갱신됩니다. UI 캐시 버전을 올려 새 화면이 적용되도록 했습니다.

## 사용자 영향과 복구

- 운영 사용자는 아직 변경되지 않습니다. 1.0.0.47 설치본 배포 후 커스텀 버튼을 사용할 수 있습니다.
- 기본 스타일로 복원하면 기존 출력으로 돌아갑니다. 설정창 취소는 실제 화면과 저장 값을 바꾸지 않습니다.
- 폰트 링크가 나중에 끊기면 기본 폰트로 표시합니다. 새 PC로의 커스텀 설정 동기화·외부 폰트 파일의 오프라인 보관은 이번 범위에 없습니다.
- 원격 데이터나 통계를 바꾸지 않으므로 후보 적용 실패 시 운영 1.0.0.46을 유지할 수 있습니다.
