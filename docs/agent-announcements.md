# Agent 공지 게시

Agent 1.0.0.57부터 공개 정적 공지 피드를 읽습니다. 공지마다 Agent를 다시 빌드할 필요가 없습니다.

1. `apps/web/announcements/YYYY-MM-DD-topic.html`에 공지를 작성합니다. 현재 페이지와 `announcement.css`를 기본으로 사용하고, 사용자가 해야 할 일을 먼저 설명합니다.
2. 새 HTML을 `apps/web/scripts/build-public-assets.mjs`의 공개 파일 목록에 추가합니다. 이전 공지 페이지는 보존합니다.
3. `announcements/feed.json`의 `notices`에 `id`, `publishedAt`, `path`를 추가합니다. `publishedAt`은 실제 게시 시각과 시간대가 포함된 ISO 8601 값이며 `path`는 `/announcements/영문소문자-숫자` 경로입니다. HTML 확장자·쿼리·외부 URL은 사용하지 않습니다.
4. 공지와 피드를 동일한 검증된 웹 후보로 배포합니다. 게시일을 다시 쓰지 않습니다. 오탈자 수정으로 표시 기간을 연장하지 않습니다.

Agent는 시작할 때, 이후 최대 30분 간격으로 피드를 확인합니다. 새 공지 중 게시된 지 72시간이 지나지 않은 가장 최근 공지를 표시합니다. 날짜는 한국 시간 기준 `M/d`입니다. 클릭해도 기간 동안 링크는 유지됩니다. 페이지 자체는 3일 뒤에도 열립니다.

연결 실패 시 메모리에 남은 유효 공지를 유지하지만 기간이 끝나면 숨깁니다. 재시작 후 피드를 읽지 못하면 공지를 표시하지 않습니다. 빈 목록을 정상 수신하면 링크를 지웁니다. 피드 캐시는 CDN 최대 5분, Agent 최대 30분이며 공지 철회가 즉시 반영되는 구조는 아닙니다.

요청에는 로그인·계정 정보를 보내지 않습니다. 응답은 32 KiB·5초로 제한하고 리디렉션을 따라가지 않습니다. 링크는 네이티브 코드가 검증된 별록 공지 경로로만 열며 WebView가 임의 URL을 전달할 수 없습니다. 별도 DB·수집 API 호출은 없습니다.

검증: AgentStoreTests의 발표 전/72시간 경계/한국 날짜/네트워크 실패/철회/후속 공지/외부 주소 차단, 브라우저 화면과 클릭, 공개 후보의 본문·CSS·피드 및 운영 반영을 확인합니다. 공개 안내의 지원 범위는 실제 제품 동작과 일치해야 합니다.
