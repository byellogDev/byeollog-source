Node **22.23.2**에서 **25건 통과, 실패·건너뜀 0건**. 합성 루프백 소켓을 사용했다.

- UTF-8 길이, 다중 패킷, 잘린/과대/손상 프레임 거부.
- 두 계정 수신 분리, 계정별 순서, 동일 내용 연속 후원 보존.
- 인증 거부·입장 거부·다른 방 ACK·입장 전 콘텐츠 차단.
- 고정 HTTP 목적지, 반환 소유자 및 응답 크기 검사.
- 전송 무응답·방송 종료·감독 중단 구분과 소켓 정리.
- 공식 SDK 대비 **24개 합성 이벤트**의 기존 별록 분류기 업무 결과 일치: 일반/관리자/OGQ 채팅, 일반/중계/VOD/영상 별풍선, 애드벌룬, 미션 후원, 금액별 기본 이미지.
- 인증 요청·로그인/입장 바이트 일치. 대조에서 초기 로그인 플래그 차이를 발견해 수정한 뒤 통과했다. 수정 전 후보를 실제 계정에 연결하지 않았다.

후보는 SDK/vm을 import하지 않는다. 공식 SDK는 비공개 검사 oracle로만 사용한다. 실제 OAuth 접속·후원·룰렛·DB/OBS 종단 동등성은 이 합성 검사만으로 확정하지 않는다.

## 관측 규칙과 판정

9월 25일 정정 이후 세 계정은 서로 독립적으로 기존 연결 안정·대상 소유자를 확인한 뒤 각자의 후보를 연결한다. 다른 계정의 방송이나 통과를 기다리지 않는다. 계정별 60초 이상 공존과 실제 프레임 최소 1개 일치는 `initial_comparison_passed`로 기록하며 다른 계정의 시작 조건으로 사용하지 않는다. 초기 대조는 장기 안정성 합격이 아니다.

양쪽 비교에 이전 관측에서 빠진 영상후원 105, 관리자 채팅 26, 애드벌룬·미션·OGQ를 포함한다. 오류 단계·종료 코드·미지원 코드 수를 기록한다. 원문·계정 ID·인증값은 공개 자료에 남기지 않는다.

실제 연결 시간, 동시 관측 시간, 대기/단절 공백, 종류별 일치·한쪽 수신, 지연, RSS/heap/CPU, 종료·회수를 분리 집계한다. 기존 컨테이너는 DB 전송·큐·관측 보조 프로세스를 포함하고 후보는 수신 전용이므로 자원 수치의 단순 비율을 절감률로 쓰지 않는다.

**후원·토큰 갱신·재연결이 실제 발생하지 않으면 미검증이다. 48시간 경과만으로 안전성이나 500명 수용을 확정하지 않는다.**

비공개 `read-campaign.mjs`로 한 번의 SSH 집계를 읽어 `campaign-status.json`에 저장한다. 이전 SDK 기록은 `previous-sdk-campaign/`에 보존했다. 새 관측 종료 후 원격 JSONL을 내려받아 이 문서·CHANGELOG를 갱신하고 자동화를 중지한다.

교체 전 직접 연결 관측의 receipt는 `before-independent-targets.json`, 원격 증거 위치는 현재 receipt의 `previousGateSegment`에 보존했다. 기존 `startEpoch`는 원래 예약 기간이고 `segmentStartEpoch`는 수정 구간 시작 시각이다. 이전 `waiting_for_canary` 기록은 당시 잘못된 조건의 증거이며 현재 시작 정책이 아니다.
