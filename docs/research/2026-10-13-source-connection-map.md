# Graphify 단절 원인과 소스 연결 보강

기준: 소스 `b6e8178d5c174d162cd6281ee5465d5faaed884a`. 로컬 정적 분석이며 현재 배포·고객 PC·실방송을 재검증한 결과가 아닙니다.

## 왜 외딴 점이 많았나

- 원본 시각화의 점은 개별 함수가 아니라 커뮤니티 923개입니다. 커뮤니티 내부 선을 접은 상태에서 588개는 다른 커뮤니티와 연결선이 없습니다. 개별 노드가 실제로 고립된 수는 171개입니다.
- Agent의 HTTP 주소, 서버 rewrite·operation 분기, RPC 함수명, C# 안에 들어 있는 JavaScript 문자열은 언어별 AST만으로 끝까지 연결되지 않습니다. 따라서 Agent와 웹/서버의 직접 그래프 간선이 0개여도 서비스가 분리되어 있다는 뜻은 아닙니다.
- SQL 변경 이력, 테스트, 빌드 및 운영 설정이 실행 서비스와 같은 화면에 섞였습니다. 반복 함수 정의를 모두 현재 서비스로 해석하면 구조가 과장됩니다.
- 출처가 없는 노드도 1,495개입니다. 외부 이름·미해결 참조를 코드 파일처럼 억지로 배정하지 않았습니다.

## 확인한 핵심 연결

| 흐름 | 확인한 소스 계약 | 해석 |
| --- | --- | --- |
| 로컬 방송 화면 → Agent | `ByeollogOverlayService.cs`의 `/overlay/wallpaper-state` fetch와 처리 분기 | 서로 다른 언어 영역이 같은 로컬 서버로 이어짐 |
| Agent → 웹 → 관리 API | `agent-support`, `selectLoginRuntime`, 프록시, 내부 핸들러 | HTTP·설정·권한 경계를 건너는 실제 소스 경로 |
| Agent → Edge → DB | `agent-runtime-g3a`, `g3a_get_wallpaper_snapshot_v1` | 서버와 분리된 섬이 아님 |
| SOOP → 게이트웨이 → 웹 → 수집 API | 직접 연결 콜백, durable outbox, rewrite, `event`·`heartbeat` 분기 | 이벤트 전달은 함수 import만으로 표현되지 않음 |
| 공개 조회 → DB | `fetchPublicRead`, `byeollog_public_read_v1` | 전용 공개 조회 계약을 유지 |
| 관리 API → 백업 워커 → DB | worker URL 검증, 전용 계정, `byeollog_backup_worker_v1` | 파일 중복이 있어도 권한 경계를 합치면 안 됨 |
| Agent / 오버레이 서버 워커 → DB | `byeollog_weflab_trial_rpc_v1`의 소유권·결과 계약 | 둘 사이에 직접 통신선을 만들지 않고 DB를 통한 인계를 표시 |
| 오버레이 운영 진입점 → DB | `production-server.mjs`, `byeollog_overlay_runtime_v1`의 discover·publish | lab·Trial 이름이 남아 있어도 운영 진입점이 재사용하는 코드가 있음 |

별도 지도에는 주요 연결 20개, 소스 근거 53곳을 기록했습니다. 이 중 내부 경계·콜백 17개는 호출/처리 소스를 대조했고, 외부 플랫폼 3개는 로컬 호출 측만 확인했습니다. 각 근거의 경로·줄·앵커·해시는 비공개 로컬 산출물에 저장합니다.

## 보는 방식

`tools/architecture-map/build.py`로 기존 Graphify 결과 옆에 `architecture.html`을 생성합니다.

- 서비스 연결: 고정된 12개 역할. 선택한 역할에 관계된 선만 표시하며 클릭하면 소스 근거를 제시합니다.
- 파일 분류: 원본 그래프에 출처가 있는 1,558개 파일. 테스트·SQL·구성·도구를 별도로 검색합니다.
- RPC 이름 대조: 101개 함수 이름의 호출 문자열과 SQL 정의 후보. 모두 저장소 정의가 발견됐지만 실행·권한·배포 검증으로 간주하지 않습니다.
- 외딴 점 분석: 588개 커뮤니티를 분류하고 혼합 구성과 출처 미해결 수를 표시합니다.

## 남은 한계

주요 서비스 경계를 사람이 보강한 지도이지 모든 함수의 완전한 동적 호출 그래프는 아닙니다. Graphify 원본의 추론 간선 1,097개를 모두 확정하지 않았고, 동적 RPC·간접 테이블 접근·환경변수 실값·배포된 DB 정의·CI/타이머 실행 상태는 별도 검증 대상입니다. 파싱되지 않은 파일, SQL의 실행 시점, 차단된 operation 분기까지 소스 존재만으로 운영 중이라고 판단하지 않습니다.

운영 요청·추첨·DB 변경·배포는 수행하지 않았습니다. 원본 그래프와 비공개 자료는 보존하며, 분석 도구와 설명 문서만 버전 관리합니다.
