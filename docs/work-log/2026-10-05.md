# 2026-10-05 작업 기록

## 직접 WebSocket 비교 중단 상세 분석

- 배포된 7개 연구 파일 해시와 실제 중단 기록을 대조했다. 코드 18의 양쪽 원문 HMAC 차이 뒤 감독자가 연결을 종료했다.
- 공식 SDK와 32개 합성 패킷 처리 결과를 대조했고, 업무에 쓰지 않는 필드만 달라도 기존 Python 비교기가 중단시키는 경로를 재현했다.
- 실제 차이 필드는 남겨진 해시로 복원할 수 없다. 당시 오탐으로 단정하지 않으며 재시작하지 않았다.
- [연구 릴리스·한계·다음 수정 방향](../releases/2026-10-05-direct-mismatch-analysis.md).

## SDK 페이지 수명과 직접 연결 후보 확인

- SDK가 소켓 종료 때 없앤 페이지 공용 이벤트 처리기를 다시 사용한 원인을 재현하고 세션 종료 시 컨텍스트를 폐기하도록 수정했다.
- 기존 이미지에서 실패를 재현한 뒤 동일 후보에서 실제 Chromium 14개 시나리오·회수·격리를 확인했다.
- 직접 연결 후보는 일반 별풍선 패킷의 양쪽 해시가 달라 안전 중단된 상태다. 원문 필드 차이는 기록 부족으로 미확정이며 재시작하지 않았다.
- [릴리스·배포·검증·복구 기록](../releases/2026-10-05-sdk-lifecycle.md).
