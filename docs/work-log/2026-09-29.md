## 설치기 완료 경로 오류 수정

- 사용자 화면의 `설치된 실행 파일의 위치가 올바르지 않습니다`를 PowerShell UTF-16 결과와 Inno LoadStringsFromFile 사이의 불일치로 재현했습니다. 이전 VERIFYONLY가 해당 단계를 건너뛰어 결함을 놓친 점을 기록했습니다.
- UTF-8 BOM으로 수정 후 실제 Inno 경로 3건 통과·경로 이탈 4건 거부. 전체 Node 836건 및 한글 바로가기 검증 통과.
- 설치 EXE만 1.0.0.43-r2로 발행하고 공식 다운로드를 운영 반영했습니다. 소스 647개·7개 응답·실제 파일 해시와 기존 EXE 보존 확인. Agent ZIP·서명 피드·원본 후원·사용자 설정은 유지합니다. [릴리스 기록](../releases/2026-09-29-installer-path-r2.md).
