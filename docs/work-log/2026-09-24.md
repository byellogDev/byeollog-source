# 2026-09-24 작업 기록

## 목적

마크 연동 후보의 결함을 운영 반영 전에 수정하고, 브라우저 없는 SOOP 후보를 기존 수집과 격리하여 비교할 준비를 마쳤습니다. 주요 작업마다 GitHub에 남기고 최소 하루 한 번 누락을 확인하는 규칙도 추가했습니다.

## 운영 반영 완료

- 정지된 게임 연동이 재인증으로 활성화되는 문제를 DB 완료 단계에서 차단했습니다.
- SOOP 일반 가입/연결과 게임 연동의 쿠키 충돌, Minecraft 인증 헤더 전달·요청 오류 처리를 수정했습니다.
- 관측 토큰을 갱신하지 않는 읽기 전용 API를 기존 관리자 인증 경계에 추가했습니다. 최초 잘못 선택한 수집 런타임 위치는 운영 적용 전에 바로잡았습니다.
- 사용자의 명시적 승인 후 웹·관리자 후보를 운영 반영했습니다. [마크 연동 운영 기록](../releases/2026-09-24-minecraft-production.md), [관측 API 기록](../releases/2026-09-24-observation-api.md).

## 연구·관측 준비

- 기존 SDK 후보 실험과 직접 WebSocket 후보의 구현·검사·비교 근거를 보존했습니다.
- 관측 종료 직전 불일치 및 비교 공백을 검토 대상으로 올리도록 수정했습니다.
- 직접 연결 후보는 9월 24일 14:00부터 26일 14:00까지 별도 관측하도록 예약했습니다. 오전 확인 시 시작 전 대기 상태였으며, 기존 Chromium 경로만 운영 데이터를 반영합니다.
- [직접 연결 관측 기록](../research/2026-09-23-direct-soak.md), [코드 리뷰와 재현](../reviews/2026-09-24-candidate-code-review.md).

## 확인한 근거

- Node 22 전체 회귀 774건, 직접 연결 합성 25건, Python 비교·감독 12건 통과.
- 승인된 테스트 워크스페이스의 DB 트랜잭션 검사 후 롤백. 실제 계정의 정지나 소유권을 바꾸지 않았습니다.
- 운영 관리자 소스 141개·웹 소스 647개가 검증 후보와 일치했습니다. 운영 화면·CSS·JS 41개 응답 바이트도 배포 원본과 일치했습니다.
- 세 관측 계정의 준비 API 응답 성공, 무서명 차단, 조회 전후 연결 행 불변을 확인했습니다. 원문과 식별자는 비공개 증거에만 남겼습니다.

## 남은 범위

실제 SOOP·Microsoft 인증 완료, 분산 요청 제한·자료 정리, 후원→Minecraft 게임 동작 전달 구현은 완료됐다고 보지 않습니다. 48시간의 실제 수신 일치·격리·후원·재연결 결과와 500개 방송 수용성도 아직 판정하지 않았습니다.
