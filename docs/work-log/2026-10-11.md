# 2026-10-11 작업 기록

## 신규 WebSocket 읽기 전용 재검증

- [릴리스·검증·한계](../releases/2026-10-11-direct-revalidation.md): 새 비교 4세션·20시간 29분 42초·6,196건 일치, 업무 제외 패킷 5건 별도 일치. 실제 교체 3회 확인.
- 직접 운영 대상은 두 방송 16시간 58분 45초, 전달 76건 완료. 실제 별풍선 24건·3,455개와 풍벽지 타일 저장 확인.
- 교체 보류 1회는 기존 연결 유지 및 이후 실제 후원 저장으로 검증. 방송 대기 중 HTTP 실패 1회는 1.617초 뒤 대기로 복귀했으나 공급자 원인 미확정.
- 업무 제외 패킷을 빠뜨린 비공개 집계 검산식만 보정. 제품 코드·배포·재시작·운영 데이터 변경 없음. 무이벤트 교체 성공·화면 출력·미발생 유형은 미검증.
- [PR #4](https://github.com/byellogDev/byeollog/pull/4), [연구 릴리스](https://github.com/byellogDev/byeollog/releases/tag/research-2026.10.11-direct-revalidation). 이전 기록·원문은 비공개 보존.
