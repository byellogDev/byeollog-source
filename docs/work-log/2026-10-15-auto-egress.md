# 2026-10-15 SOOP 자동 출발 통신

- [릴리스 기록](../releases/2026-10-15-auto-egress-production.md).
- 사용자 승인한 API 키와 단일 운영 IP 제한을 확인하고 암호화 전달·root 전용 저장을 완료했다.
- 실제 API 조회 및 중복 /32 시험 규칙 생성·조회·삭제를 확인했다. ENUM 거절을 OUT/TCP로 수정했다.
- Linux 정책 16개·소켓 5개·후보 이미지 전송 8개·실제 모니터의 가짜 알림 4개·배포 준비 2개 검사를 통과했다.
- 호스트 소켓 그룹 설치 및 계정 초기화 시차를 처리했다. 동일 후보 승격 후 04:21 KST 5계정 방송 대기·큐 0·자동 허용 활성·제어기 오류 없음과 권한 보존을 확인했다.
- 실방송에서 신규 포트가 배정되는 사건은 아직 관측하지 않았다. 개인정보·키·원문·관련 없는 그래프 파일은 게시 제외.
