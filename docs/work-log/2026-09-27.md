# 2026-09-27 작업 기록

## 신규 WebSocket 후보 검수

현재 및 이전 다섯 구간을 읽기 전용 보존·분리 집계했다. 현 수정본은 두 운영 계정 약 8시간 35분 동시 관측, 7,646개 프레임 일치·편측 0이었다. 두 계정의 파싱 오류 중단, SDK와 빈 본문 메시지 처리 차이, 동시각 기존 SDK 401을 확인했다. 기존 Node 36건 및 Python 로컬·서버 각각 21건은 통과했지만 새 호환성 재현 결함과 종단·복구 검증 미완료 때문에 운영 전환 보류로 기록했다. 운영 변경·후보 재시작·관측 종료는 하지 않았다.

## 설치 후 바로가기 실패

실제 설치 로그에서 1.0.0.41 앱 설치 이후 바탕화면 바로가기 생성 실패를 확인했다. Windows PowerShell 5.1의 BOM 없는 UTF-8 해석으로 금지 문자가 생기는 문제를 재현하고 래퍼 인코딩·오류 안내를 수정했다. 관련 검사 2건 통과. 설치 파일·운영 배포는 변경하지 않았으며 시작 메뉴 경고와 다른 PC의 백신 탐지는 별도 미완료 항목이다.
