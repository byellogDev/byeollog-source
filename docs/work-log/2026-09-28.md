## GitHub CI 바로가기 생성 실패

사용자가 전달한 실패 메일의 실제 Actions 로그를 확인했다. 소스 대조·게시 검사는 통과했고 Node 802건 중 한글 바로가기 저장 1건이 실패했다. BOM 적용 뒤에도 WScript.Shell 저장 경로가 깨진 증거에 따라 설치 래퍼를 Unicode Shell Link API로 변경하고 실제 helper로 한글 경로 왕복 검사를 보강했다. 로컬 전체 802건·소스 대조·웹 빌드 통과. GitHub 재검사 결과는 해당 수정 커밋의 PR Checks에 남긴다. 운영·연구 수집기·설치 EXE 배포는 변경하지 않았다.

[릴리스·검증·제한](../releases/2026-09-28-shortcut-unicode-ci.md) · [PR #4](https://github.com/byellogDev/byeollog/pull/4)

첫 원격 재검사에서 저장 단계는 통과했고 경로 문자열 비교가 실패했다. 8.3 짧은 임시 경로를 로컬에서 강제해 같은 파일의 긴 경로 반환을 재현하고 실제 경로를 정규화하여 검사하도록 보강했다. 해당 회귀 검사 통과 후 원격 검사를 다시 실행한다.

## 설치 EXE r2 배포

사용자 승인에 따라 바로가기 수정 래퍼를 새 EXE로 빌드하고 공식 다운로드를 교체했다. 기존 EXE·ZIP·서명 feed는 보존했다.
