# 2026-10-16

- [야추 독립 서버 이전](../releases/2026-10-16-yatch-independent-hosting.md): 사용자 승인 TCP 80/443을 적용하고 검증한 공개 경로를 승격했다. 게임 0.8.0은 별도 소스/프로세스/SQLite/제한 자원으로 운영한다. 공개 Chromium 38개, WebKit 37개, API 9개와 실제 재시작 보존을 확인했다. 기존 별록 홈/setup 해시·앱 배포·수집기 시작 시각은 유지했다. 기존 게임 주소/데이터 보존, 물리 Safari 및 원격 재해 복구 한계는 릴리스에 기록했다.

- [자동 출발 통신 알림 지연 개선](../releases/2026-10-16-auto-egress-alert-latency.md): 첫 정상 표본 이후 2분 6초의 확인 지연 확인. 로컬 감시 30초 타이머를 배포하고 원본 시각 중복 제거·다른 알림 상태 보존·오래된 표본의 허위 복구 차단을 검증했다. 대상 회귀 15개, 실제 모니터 소스 통합 5개 통과. 실제 운영 표본 31초 간격, 기존 수집기 무재시작·오류 0 확인. API 장애 자체의 지속 시간 개선이나 새 실장애 종단 검증을 의미하지 않는다.
