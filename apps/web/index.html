풍벽지와 업보
관리 기능

별록은 룰렛을 직접 실행하지 않습니다. SOOP 후원과 룰렛 결과를 받아 풍벽지 표시와 업보 관리에 사용합니다.

01 · WALLPAPER

별록 풍벽지

후원 이미지를 카드처럼 쌓아 방송 화면에 보여주는 Windows용 오버레이입니다.

  • PC 로컬 편집기에서 배치·크기·겹침·스냅을 바로 조절합니다.
  • OBS와 프릭샷에 브라우저 소스로 연결해 같은 화면을 송출합니다.
  • 시그니처 이미지와 기본 후원 이미지를 금액별로 적용합니다.
  • 받아둔 이미지는 인터넷이 끊겨도 배치를 계속 편집할 수 있습니다.
로컬 편집기 제공
02 · UPBO

업보 관리

SOOP 후원 정보와 룰렛 결과를 연결해 누가 어떤 약속을 받았는지 정리합니다.

  • 학습된 분류와 고정 업보 규칙으로 결과를 자동 정리합니다.
  • 팬·이벤트·업보 종류별로 남은 수량과 완료 상태를 관리합니다.
  • 하나의 결과에 묶인 여러 상품도 각각의 작업으로 나누어 기록합니다.
  • 필요한 경우 시청자용 공개 페이지로 진행 상황을 공유합니다.
후원·룰렛 결과 연결
이용 방식

설치 및 이용 순서

웹에서 이미지와 업보 설정을 관리하고, 풍벽지 배치는 PC에 설치한 별록 풍벽지에서 편집합니다.

1

별록 계정 연결

승인된 계정으로 로그인하고 방송에 사용할 SOOP 계정을 연결합니다.

2

풍벽지 설치와 배치

Windows 앱에서 이미지를 내려받아 배치한 뒤 OBS·프릭샷에 오버레이 주소를 추가합니다.

3

방송 중 자동 반영

새 후원은 풍벽지에 쌓이고, 연결된 룰렛 결과는 업보 분류와 진행 관리로 이어집니다.

⌁

로컬 편집 및 오프라인 동작

이미 내려받은 풍벽지와 배치는 인터넷 연결이 없어도 편집할 수 있습니다. 새 후원과 이미지는 연결이 복구되면 다시 동기화됩니다.
