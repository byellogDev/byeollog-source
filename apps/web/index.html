업보 수집과 풍벽지 편집

웹 대시보드에서 수집·분류·진행 상태를 관리하고, 방송 PC에서는 풍벽지를 배치합니다.

룰렛 결과 기반 업보 수집

후원알림 오버레이에서 확인한 후원·룰렛 결과를 기준으로 업보를 기록합니다.

  • 오버레이 주소 등록 후 수집 ON업보 수집 설정에서 지원하는 주소를 저장하면 수집을 켤 수 있습니다.
  • 룰렛 사전 등록 없이 자동 이벤트명룰렛이 돌아간 월과 후원 수량으로 이름을 붙입니다. 다른 이름이 필요할 때만 ‘이벤트명 사전 등록’을 사용합니다.
  • 처음 나온 결과는 직접 분류미분류 결과를 업보인지 지정하면 같은 결과를 다음부터 자동 처리합니다.
  • 남은 수량과 완료 상태 관리후원자·이벤트·업보 종류별로 조회하고, 시청자용 공개 페이지로 진행 현황을 공유할 수 있습니다.

풍벽지 배치·카드 커스텀

별풍선 수량별 후원 이미지를 카드로 표시하고, 방송 화면에 맞게 직접 배치합니다.

  • 배치·크기·겹침 조절PC의 풍벽지 배치 편집에서 조정하면 연결된 방송용 오버레이에 반영됩니다.
  • 개별 숨김과 복원카드의 ×로 숨기고 ‘숨긴 풍벽지’에서 복원합니다. 숨긴 카드는 쌓기에서 제외됩니다.
  • 백두산과 묶음 해제시작 후원과 목표 수량으로 백두산을 구성합니다. 지정한 수량 범위는 카드별로 따로 이동할 수 있습니다.
  • 글꼴·색상·글자 크기 설정글꼴 링크, 닉네임·본문 색과 카드 크기에 맞는 글자 크기를 설정합니다. 배경색은 이미지 아래 글자 영역에 적용됩니다.

별풍선 통계·리포트

후원자별·날짜별·월별·별풍선 수량별 내역을 조회합니다. ‘별풍선 리포트 받기’에서 기간을 정하면 방송 시작 후 후원 흐름과 시작 시각별 기록을 PNG로 내려받을 수 있습니다. 기본 기간은 기록된 첫 방송일~최근 방송일입니다.

채팅창 꾸미기

방송용 채팅창의 글꼴·색상·배경을 미리 보고 CSS를 만듭니다. 채팅창에 적용할 코드를 복사해 사용할 수 있습니다.

업보 자동 수집 시작 방법

가입·로그인 후 방송에 사용할 본인 SOOP 계정의 연결 상태를 확인하세요.

  1. 오버레이 주소 저장

    ‘업보 수집 설정’에 방송에서 사용하는 후원알림 오버레이 주소를 입력합니다. 연결 가능한 주소인지 저장 시 안내를 확인하세요.

  2. 업보 수집 ON

    주소 등록을 마치고 수집을 켭니다. 룰렛을 별록에 다시 등록할 필요는 없습니다.

  3. 미분류 결과 확인

    처음 나온 결과를 업보인지 분류합니다. 같은 결과는 이후 자동으로 처리되며, 업보 목록에서 수량과 진행 상태를 관리합니다.

풍벽지를 방송에 표시하려면
Windows 프로그램에 로그인하고 이미지를 등록한 뒤, OBS·프릭샷의 브라우저 소스에 풍벽지 주소를 넣으세요.

이용 전 확인할 사항

업보 수집과 풍벽지는 별도 설정입니다

업보 수집을 OFF로 바꾸면 새 후원부터 업보 처리를 멈추고, 이미 시작한 건은 마무리합니다. 후원 통계와 풍벽지 수집은 계속됩니다.

방송용 풍벽지는 PC에서 실행합니다

로컬 풍벽지 화면에는 Windows 프로그램 실행이 필요합니다. 업보 오버레이 수집은 Agent를 꺼도 서버에서 이어집니다. 외부 서비스 지원 여부와 연결 상태에 따라 결과 반영이 지연될 수 있습니다.
