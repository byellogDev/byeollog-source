Design JSON: original theme schema versions 33–35 supported. New files additionally include adapter/product/savedAt. Old files without adapter require choosing the output environment. Images are embedded, never uploaded. Limits: 20 images, 8 MiB per image, 24 MiB JSON; PNG/JPEG/WebP/GIF; decoded images limited to 8192 pixels per side and 24 million pixels. Imports validate all fields and decode images before replacing the current design. Invalid imports keep current work. Unsaved changes prompt before replacing/leaving. No cloud persistence or autosave claim.

Weflab users, including OBS users displaying a Weflab URL, select `위플랩` and paste CSS into its custom CSS field. Compatibility was tested against the Weflab basic theme, normal name layout and observed SOOP event markup; other provider themes with their own decorative layers are not all verified. Actual message movement, incoming data and retention remain with Weflab. No automatic Weflab account access.

Canvas X/Y controls only position the editor preview. Width/height are exported for compatible HTML; Weflab keeps its existing viewport dimensions. This distinction is explained next to the controls. Images embedded in a saved design remain local. Existing copies of exported CSS do not update automatically: load the saved design and copy the newly generated CSS to replace the old CSS.
