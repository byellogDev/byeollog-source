방송 준비 확인

현재 계정의 연결과 설정을 확인합니다. 아래 체크 표시는 직접 확인한 내용을 적어두는 메모입니다.

연결 상태를 확인하고 있습니다.

1. 가입과 로그인

스트리머 본인의 SOOP 계정으로 연결한 뒤 이메일·표시 이름을 입력해 가입합니다. 가입 이메일의 비밀번호 설정 링크로 비밀번호를 정하고 로그인해주세요.

메일이 없다면 스팸함을 확인하고 설정 메일 다시 요청을 이용하세요. SOOP 계정 연결이 만료되면 다시 연결하면 됩니다.

로그인

2. 방송 계정 연결 확인

대시보드의 마이페이지 → SOOP 방송 계정에서 연결된 아이디와 연결 상태를 확인하세요. 가입한 스트리머 본인의 방송 계정이어야 합니다. 방송 중인데 수집되지 않으면 연결 자가진단과 후원 내역을 확인해주세요.

3. 풍벽지 설치

풍벽지 메뉴에서 별풍선 개수별 이미지를 등록합니다. 설치 중 바탕화면 바로가기 만들기를 선택할 수 있고, 마지막 화면에서 바로 실행할 수 있습니다. Windows PC에 별록 풍벽지를 설치하고 같은 계정으로 연결한 뒤 풍벽지 표시를 켜세요. 개수별 표시·숨김은 풍벽지 프로그램의 풍벽지 편집 화면에서 조절할 수 있습니다.

설치 → 로그인 → 이미지 등록 → 방송 화면에 추가 순서로 진행하세요. 방송 PC에서 프로그램의 풍벽지 표시를 켜고, OBS·프릭샷의 브라우저 소스에 아래 주소를 넣으세요. 휴대폰에서는 방송 PC의 화면을 확인할 수 없습니다.

http://127.0.0.1:43120/overlay/wallpaper

먼저 프로그램과 브라우저 소스가 열리는지 확인하세요. 실제 후원이 들어왔을 때 이미지가 방송 화면에도 표시되는지 최종 확인하면 됩니다. 후원 전에는 실제 표시까지 확인된 것으로 판단하지 않습니다.

풍벽지 설치 프로그램 다운로드

4. 후원 금액과 룰렛 연결

업보 분류 설정에서 별풍선 최소~최대 개수, 이벤트명, 후원 한 건당 총 회전 수를 입력합니다. 최소·최대 개수 모두 포함하며, 같은 개수만 받으려면 두 칸에 같은 수를 입력하세요. 범위는 서로 겹칠 수 없습니다. 보너스를 포함한 회전 수를 입력하며 상품 종류의 개수와는 다릅니다. 활성 스위치를 끄면 이후 후원부터 적용됩니다. 이미 대기 중인 후원과 고정 업보는 유지됩니다.

고정 업보는 정한 후원 금액에 바로 적용합니다. 특수룰렛은 지정한 결과가 나왔을 때 같은 후원자의 다음 결과에 배수를 적용하며, 비업보 결과를 만나거나 12시간이 지나면 소멸합니다.

예: 33~50개에 총 1회가 돌아가는 룰렛은 최소 33 · 최대 50 · 회전 수 1을 입력합니다. 33개 후원만 받으면 최소·최대를 모두 33으로 입력하세요.

룰렛 설정하기

수동 룰렛 사용 전 꼭 확인해주세요

수동 룰렛과 실제 후원 결과는 채팅 문구만으로 구분할 수 없습니다. 후원 결과가 기다리고 있으면 수동 결과가 그 후원에 잘못 연결될 수 있습니다.

모든 후원의 결과 처리가 끝나고 연결 대기 후원이 없는 상황에서 수동 룰렛을 사용하도록 권장합니다. 업보 메뉴의 ‘룰렛 연결 대기 확인’에서 대기 상태를 새로고침하고 실행 전후를 확인하세요. 0건 확인 후에도 새 후원이 들어올 수 있습니다.

5. 업보 분류와 예외 처리

학습 필요한 별풍선에서 처음 들어온 결과를 업보 또는 비업보로 분류합니다. 이후 같은 결과에는 저장한 분류가 적용됩니다.

후원에 연결되지 않은 룰렛은 예외 처리된 룰렛에서 제외하거나 후원자를 지정해 업보로 등록합니다. 비업보로 학습된 결과는 자동 제외됩니다.

정상 등록된 업보·확정 후원 내역은 30일 정리 대상이 아닙니다. 예외 결과에서 후원자를 지정해 등록한 업보도 유지됩니다.

30일 정리 대상은 후원·룰렛 연결용 원본 기록과 예외 처리 기록입니다. 보류 중인 예외 결과도 서버 수집일로부터 30일이 지나면 정리되므로, 필요한 예외 기록은 미리 CSV로 저장하세요.

처리 취소 후 후원자를 다시 지정할 수 있습니다. 이미 일부 완료되거나 내용이 바뀐 업보는 잘못 차감하지 않도록 취소가 제한됩니다.

6. 방송 전 최종 점검

관리 → 최근 후원·구독 내역에서 날짜를 지정해 실제 후원이 저장됐는지 확인하세요. 각 후원의 처리 단계에서 결과 연결·업보 처리·풍벽지 준비 상태를 볼 수 있습니다. 풍벽지 프로그램의 실제 화면 표시는 방송 PC에서 확인해야 합니다.

시청자 페이지는 관리 → 시청자용 페이지 관리에서 공개 설정과 주소를 확인해 공유하세요. 전체 공개는 완료된 업보까지, 미완료 건만 공개는 남은 업보만 보여줍니다. 비공개는 시청자 조회를 막습니다. 기존 공개 페이지는 미완료 건만 공개로 유지됩니다. 공개 코멘트도 함께 확인해주세요.

선택 기능 · 역팬데이 환급 관리

업보 분류 설정 → 역팬데이에서 회차 이름, 한국 시간 기준 시작·종료 시각, 별풍선 최소~최대 범위와 환급률을 입력합니다. 최소·최대 개수는 포함하며, 시작 시각부터 종료 시각 전까지의 저장된 후원을 계산합니다. 구독은 제외됩니다.

후원 건마다 환급 수량의 소수점을 버린 뒤 SOOP 아이디별로 합산합니다. 실제 지급 후 지급완료를 표시하세요. 추가 후원이 들어오면 다시 계산으로 추가 지급 수량을 확인할 수 있습니다. 잘못 표시한 기록은 취소할 수 있지만, 실제 별풍선이 회수되지는 않습니다.

지급 기록이 있는 회차의 조건 수정·삭제는 잠깁니다. 역팬데이 설정과 지급 상태는 관리자 페이지에서만 관리하며 시청자 페이지에는 표시되지 않습니다. 이 기능은 계산·기록 기능으로 실제 별풍선을 자동 전송하지 않습니다.
