룰렛 서비스

SOOP 계정, 실시간 채팅, 공통 OBS 오버레이와 현재 방송 적용본을 한곳에서 확인합니다.
확인 중
1 · SOOP 계정확인 중
2 · 실시간 연결확인 중
3 · 방송 상태방송 대기
4 · 방송 적용본선택 필요
일반풍·등록 시그풍·룰렛 후원을 같은 실제 정규화·OBS·TTS 경로로 확인합니다. 테스트는 통계, 업보, 액션, 풍벽지 기록에 반영되지 않습니다. 공통 OBS 브라우저 소스를 먼저 켜주세요.
OBS 브라우저 소스 크기는 460×450으로 설정하고, 위치와 최종 크기는 OBS의 소스 변환에서 직접 조절합니다. 후원 종류 강조 영역과 최대 120자 후원 멘트를 수용하는 고정 경계이며 재생 중 소스 크기는 바뀌지 않습니다.
룰렛 서비스 상태를 불러오고 있습니다.
방송 적용은 명시적으로 선택합니다. 설정을 저장해도 현재 방송 적용본은 바뀌지 않습니다. 룰렛 카드의 방송 적용을 눌러야 새 버전이 실제 후원에 반응합니다.

내 룰렛

여러 룰렛을 각각 다른 이벤트명으로 관리합니다.

위플랩 공개주소에서 이전

공개된 상품명과 확률만 읽습니다. 가져올 확률표를 고르면 열린 편집 화면에서 새 이벤트명을 입력합니다.

새 룰렛

표시와 집계에 쓰일 이름은 반드시 별록에서 새로 정합니다.
효과음·TTS 음량은 현재 방송 적용 설정을 사용합니다. 화면 위치와 크기는 OBS의 브라우저 소스에서 직접 조절합니다.

룰렛 이미지

기본 제공 이미지를 고르거나 스트리머 이미지를 직접 업로드할 수 있습니다.

단차 이미지 직접 업로드

PNG, JPG, WebP, GIF · 최대 12MB · 가로·세로 4096px 이하

연차 이미지 직접 업로드

연차 이미지를 별도로 지정하지 않으면 단차 이미지를 사용합니다.

상품과 확률

업보로 지정한 상품은 당첨 즉시 업보로 보내고 연출·TTS를 생략합니다.
이미지 우선순위 정확한 개수의 시그풍 → SOOP이 전달한 실제 이벤트 이미지 → 아래 금액 범위의 기본 후원 이미지 → SOOP 공식 기본 이미지 순서로 표시합니다. 기본 후원 이미지는 SOOP 이미지가 없는 별풍선·도전미션 후원의 알림과 풍벽지에 함께 적용됩니다. 룰렛 이미지도 시그풍으로 등록해주세요.

기본 후원 이미지

SOOP 기본 이미지가 없는 후원에 사용할 이미지를 등록합니다. 범위는 서로 겹칠 수 없습니다.

기본 후원 이미지 등록

후원알림과 풍벽지에 같은 이미지를 사용합니다. 움직이는 GIF 원본도 그대로 표시됩니다.
두 칸 모두 비우면 1개부터 제한 없이 적용됩니다. 한쪽만 입력하면 1~최대값 또는 최소값~제한 없음으로 저장됩니다.

기본 후원 이미지 필수

PNG, JPG, WebP, 움직이는 GIF · 최대 12MB. SOOP에서 이미지를 보내주지 않은 별풍선·도전미션 후원은 이 이미지를 풍벽지에도 사용합니다.
이미지를 선택해주세요.

등록한 시그풍

같은 별풍선 개수는 하나만 등록할 수 있습니다. 카드를 누르면 수정할 수 있습니다.

시그풍 등록

OBS 세레모니와 풍벽지에 쓸 이미지를 용도별로 분리해 안전하게 보관합니다.
권장 이미지 크기 · PC 195×145px · 모바일 293×248px. 풍벽지용 이미지는 결과 슬롯이나 문구가 없는 깨끗한 원본을 권장합니다.

PC 이미지 필수

OBS 공통 오버레이에서 실제로 표시할 세레모니 이미지입니다.
PC 이미지를 선택해주세요.

모바일 이미지 필수

모바일용 원본을 별도로 안전하게 보관합니다.
모바일 이미지를 선택해주세요.

풍벽지용 이미지 자동 생성

PC 원본을 320×240 투명 캔버스의 아래쪽에 맞춰 자르지 않고 자동 보관합니다.
저장하면 PC 원본을 바탕으로 자동 생성됩니다.
풍벽지 이미지 우선순위는 시그니처 후원 이미지 → SOOP 제공 풍선 별 이미지 → 등록 기본 이미지 → SOOP 기본 이미지입니다. 풍벽지 프로그램을 실행해주셔야 사용이 가능합니다.
SOOP API 이용정책에 따라 현재 회차의 방송만 숲 제공 별풍선 이미지의 풍벽지를 사용할 수 있습니다.
