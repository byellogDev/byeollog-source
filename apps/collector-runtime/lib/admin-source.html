처음 들어온 룰렛 결과를 분류하면, 같은 결과는 다음부터 자동으로 처리됩니다.

처음 보는 유형만 수동 분류하며, 학습된 유형은 자동 처리됩니다.
수신함을 불러오세요.

룰렛 연결 대기 확인

후원에 연결될 룰렛 결과가 남아 있는지 확인하세요.

수동 룰렛은 후원들의 결과 처리가 모두 끝나고, 연결 대기 후원이 없는 상황에서 사용해주세요.
수동 결과와 후원 결과의 채팅 문구가 같아 자동으로 구분할 수 없습니다. 대기 후원이 있으면 수동 결과가 그 후원에 연결될 수 있습니다. 0건 확인 후에도 새 후원이 들어올 수 있으니 실행 전후로 확인해주세요.

확인 전입니다.

대기 후원 상세 · 자동 종료 내역

후원 후 첫 결과 또는 마지막 결과부터 3분 동안 추가 결과가 없으면 연결 대기가 자동 종료됩니다. 후원 금액과 이미 수집한 결과·업보는 그대로 남습니다.

최근 자동 종료 내역

특수룰렛 배수 대기 · 최근 결과

배수 대기는 방송 단위이며, 다음 결과가 비업보이면 효과가 소멸합니다. 아래 배수는 결과 수신 시 확정된 값이며 실제 업보 등록 여부는 후원 내역에서 확인해주세요.

예외 처리된 룰렛

후원에 연결되지 않은 결과를 확인하고, 제외하거나 후원자를 지정해주세요.

다른 후원에 자동으로 배정되지 않습니다. 비업보로 분류된 결과는 자동 제외됩니다.

기록 보관 기간 안내

정상 등록된 업보·확정 후원 내역은 30일 정리 대상이 아닙니다. 여기서 후원자를 지정해 등록한 업보도 유지됩니다.
30일 정리 대상은 후원·룰렛 연결용 원본 기록과 예외 처리 기록입니다. 보류 중인 예외 결과도 서버 수집일로부터 30일이 지나면 정리되므로, 필요한 예외 기록은 미리 내보내세요.

후원자를 지정해 업보 등록

후원 금액은 추가하지 않으며, 입력한 업보와 수량만 등록합니다. 특수룰렛 배수는 적용하지 않습니다.

후원자를 선택해주세요.

검색되지 않는 후원자 새로 지정

SOOP 아이디를 정확히 확인해주세요. 업보 등록과 함께 후원자 목록에 추가됩니다.

별풍선 통계
별록이 수집한 전체 SOOP 후원 원본을 기준으로 집계합니다. 룰렛 결과나 업보 분류 여부와 관계없이 후원 자체는 유지됩니다.
통계를 불러오지 않았습니다.
비업보 관리
비업보로 분류된 SOOP 후원 원본을 삭제하지 않고 보관합니다. 잘못 분류된 항목은 여기서 바로 업보로 변경할 수 있습니다.
비업보 기록을 불러오세요.

별풍선 유형 분류

저장된 분류를 수정하는 화면입니다. 처음 보는 유형의 최초 분류는 수신함 상단에서 처리합니다.
학습된 분류 관리
한 번 분류해 저장한 룰렛 결과를 업보 / 비업보로 수정하거나 삭제할 수 있습니다. 삭제한 결과는 다음에 다시 들어오면 처음 보는 데이터로 분류됩니다.
후원 1건에서 여러 번 돌아간 룰렛을 하나의 묶음으로 보여줍니다. 룰렛 무효는 별풍선 후원 원본/통계는 유지하고, 해당 후원에서 생성된 업보만 취소합니다.
룰렛 기록을 불러오세요.

Collector에서 아래 8자리 코드를 입력하세요. 10분 후 만료됩니다.
