별록 에이전트 v0.7.0.43

- 수집 중 위플랩 세션 만료 신호가 연속으로 확인되면 사용자 화면을 열기 전에 자동 복구를 시도합니다.
- 1차로 저장된 WebView2 로그인 프로필을 조용히 다시 불러옵니다.
- 1차 복구가 되지 않으면 별록 전체가 아니라 위플랩 수집 WebView2만 새로 시작합니다.
- 자동 복구 중에도 사용자가 시작한 방송 수집 세션은 종료하거나 새로 만들지 않습니다.
- 복구되면 수집 스크립트를 자동으로 다시 연결하고 최근 구간을 겹쳐 확인합니다.
- 자동 복구가 제한 시간 안에 되지 않을 때만 기존 위플랩 재로그인 화면을 표시합니다.
- 동일한 만료 신호가 반복돼도 복구 작업은 한 번만 실행합니다.

검증 필요:
- 실제 만료된 위플랩 세션에서 자동 복구 성공 여부
- 복구 전후 후원·룰렛 누락 및 중복 0건
- 복구 중 방송 수집 세션과 시작 시각 유지
- 실제 재인증이 필요한 경우 수동 로그인 화면으로 정상 전환

기존 로그인 프로필, 별록 계정, OBS·마이크 설정, 규칙, 수집 데이터와 자동 업데이트 신뢰키는 보존됩니다.
