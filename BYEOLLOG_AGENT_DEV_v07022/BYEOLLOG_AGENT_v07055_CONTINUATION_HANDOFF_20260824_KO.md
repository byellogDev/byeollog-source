# 별록 에이전트 v0.7.0.55 인계

기준선은 `v0.7.0.55`이다. v0.7.0.54 산출물은 불변으로 유지한다.

## 수정 원인

- 운영 로그에서 `PT409: only one raffle ticket rule can be active at a time`을 확인했다.
- 해당 workspace에는 정상 활성 추첨 액션 `33추첨`이 이미 존재했다.
- 신규 추가 화면이 두 번째 추첨을 만들 수 있는 것처럼 보여 서버의 단일 활성 추첨 규칙 계약과 UI가 충돌했다.

## 수정 내용

- 추첨 액션이 이미 있으면 `추첨` 기능 추가가 기존 액션의 수정 화면을 연다.
- 단일 추첨 액션, 열린 추첨 회차, 지원하지 않는 PC의 `PT409`를 각각 사용자 문구로 변환한다.
- 추첨권 풀과 기존 회차 보존을 위해 서버의 단일 활성 추첨 규칙 제한은 유지한다.

## 비회귀

- 기존 추첨 규칙·추첨권·당첨 기록·오버레이 위치·등록 PC는 변경하거나 삭제하지 않는다.
- v0.7.0.32 프로토콜 설치 파일을 그대로 재사용한다.
- 사용자는 설치형 별록을 실행할 때 서명된 자동 업데이트 피드를 통해 이 버전을 받는다.
