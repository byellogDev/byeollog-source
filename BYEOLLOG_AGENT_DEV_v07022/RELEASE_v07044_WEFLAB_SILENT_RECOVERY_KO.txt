별록 에이전트 v0.7.0.44

- 위플랩 세션 만료 신호를 연속 확인하면 사용자 화면보다 자동 복구를 먼저 시도합니다.
- 저장된 로그인 프로필 재탐색 후에도 복구되지 않으면 수집 WebView2만 새로 시작합니다.
- 자동 복구 중 기존 방송 수집 세션과 시작 시각을 유지합니다.
- 연결이 복구되면 수집 스크립트를 자동으로 다시 연결합니다.
- 자동 복구가 제한 시간 안에 되지 않을 때만 위플랩 재로그인 화면을 표시합니다.
- 수동 로그인 안내가 열린 뒤에는 자동 복구를 반복 실행하지 않습니다.
- 제한 시간 경계에서 늦게 도착한 성공 신호도 정상 복구로 인정해 불필요한 WebView 재생성을 막습니다.

실제 만료 세션에서 자동 복구, 누락·중복 0건, 활성 세션 보존을 확인한 뒤 공개 stable로 승격해야 합니다.
