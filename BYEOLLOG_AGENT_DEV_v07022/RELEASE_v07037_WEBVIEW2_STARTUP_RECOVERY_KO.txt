별록 에이전트 v0.7.0.37 / 공개판 35

- 로그인 전에 로그인 화면, 메인 화면과 위플랩 수집 WebView2까지 사전 준비합니다.
- 로그인 완료 직후 세 번째 WebView2 컨트롤 생성과 로그인 창 정리가 겹치던 시작 순서를 제거했습니다.
- WebView2 E_ABORT·일시 상태 오류는 새 컨트롤에서 한 번 자동 재시도합니다.
- 사전 준비 실패는 로그인을 막지 않으며 메인 화면 표시 후 다시 시도합니다.
- E_ABORT를 WebView2 Runtime 미설치로 오판해 Microsoft 설치 페이지를 안내하지 않습니다.
- 기존 로그인, 위플랩 프로필, 방송 설정, 자동 업데이트와 여러 구버전 설치는 그대로 보존합니다.
