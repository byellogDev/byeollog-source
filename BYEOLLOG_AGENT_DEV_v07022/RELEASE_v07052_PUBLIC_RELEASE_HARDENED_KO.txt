별록 에이전트 v0.7.0.52

공개 배포 전 안정화판입니다.

- 서버가 전달한 대시보드·계정 지원 URL은 별록 공식 HTTPS 출처만 엽니다.
- 외부 출처, 파일 URI, 원격 평문 HTTP 주소는 열지 않습니다.
- localhost 개발 환경의 HTTP 주소는 기존 개발 호환을 유지합니다.
- 기존 v0.7.0.51의 시작 화면, 로그인 전환, 위플랩 자동 복구, 별록 액션, 자동 업데이트 계약을 보존합니다.
- 사용자 설정과 수집 데이터는 기존 `%LOCALAPPDATA%\ByeollogAgent` 경로에 그대로 유지됩니다.

이 버전은 기존 v0.7.0.51 바이트를 덮어쓰지 않는 새 불변 업데이트입니다.
