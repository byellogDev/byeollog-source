별록 에이전트 v0.7.0.94 · 액션 생성 화면 마이크 설정 내장

- 신원보호 필터를 처음 설정할 때 OBS 연결과 필터 자동 준비, 선택 톤 확인·5초 미리보기를 같은 화면에서 진행할 수 있습니다.
- 아봉 설정에서는 선택한 제어 방식에 맞춰 OBS 또는 Windows 마이크 설정만 자연스럽게 표시합니다.
- 기존 마이크 설정 화면은 그대로 유지하며 두 화면의 설정값과 준비 상태를 자동으로 동기화합니다.
- 다른 등록 PC가 선택된 경우 현재 PC의 로컬 설정을 잘못 변경하지 않도록 조작을 차단하고 해당 PC에서 설정하도록 안내합니다.
