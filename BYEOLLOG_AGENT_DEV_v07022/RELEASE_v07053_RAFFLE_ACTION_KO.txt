별록 에이전트 v0.7.0.53

별록 액션에 새 기능 `추첨`을 추가한 공개 업데이트입니다.

- 기준 후원 수량마다 추첨권을 자동 지급합니다. 예: 기준 33개, 후원 100개는 3장입니다.
- 지급 내역은 서버 원장에 한 번만 기록되어 같은 후원이 중복 처리되지 않습니다.
- 스트리머가 당첨 횟수와 동일 시청자 중복 당첨 허용 여부를 직접 선택합니다.
- 당첨 횟수가 3회면 서버가 가중 추첨을 정확히 3번 수행하고 Agent가 1/3, 2/3, 3/3 순서로 송출합니다.
- 추첨권 지급과 당첨 발표에 서로 다른 내장 애니메이션 GIF를 사용합니다.
- 진행 중인 추첨 회차가 있으면 해당 규칙의 비활성화·삭제·수정을 차단해 추첨권을 보존합니다.
- 사용자 설정과 수집 데이터는 기존 `%LOCALAPPDATA%\ByeollogAgent` 경로에 그대로 유지됩니다.

이 버전은 기존 v0.7.0.52 바이트를 덮어쓰지 않는 새 불변 업데이트입니다.
