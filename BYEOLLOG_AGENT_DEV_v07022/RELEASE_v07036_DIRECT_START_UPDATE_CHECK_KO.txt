별록 에이전트 v0.7.0.36 / 공개판 34

- 기존 PowerShell 관리 런처뿐 아니라 새 `별록` 직접 실행 바로가기에서도 업데이트를 확인합니다.
- 네이티브 로딩 창이 먼저 그려진 뒤 별도 숨김 프로세스가 서명 Feed를 확인합니다.
- 관리형 설치 경로에서 검증된 현재 EXE일 때만 자동 확인 프로세스를 시작합니다.
- 새 버전은 방송 중인 프로세스를 종료하지 않고 다음 실행용으로 설치합니다.
- 실행마다 확인하며 기존 예약 시각은 업데이트 생략 조건으로 사용하지 않습니다.
- 여러 구버전 폴더, 별도 설치 루트와 다른 바로가기는 삭제하거나 덮어쓰지 않습니다.
