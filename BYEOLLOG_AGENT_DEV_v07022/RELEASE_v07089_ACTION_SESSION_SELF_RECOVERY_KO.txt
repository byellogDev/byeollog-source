별록 에이전트 v0.7.0.89 · 별록 액션 세션 자가복구

- 별록 액션 서버가 401을 반환해도 정상인 갱신 토큰을 즉시 삭제하지 않습니다.
- 같은 세션의 401은 한 번만 강제 갱신하고, 성공한 경우 원 요청을 정확히 한 번 재전송합니다.
- 여러 요청이 동시에 401을 받아도 세션 epoch와 token revision을 확인해 갱신을 한 번으로 합칩니다.
- 갱신 뒤에도 실패하면 세션을 파괴하지 않고 재연결 대기로 전환합니다. 기존 후원 수집과 운영 업로드는 계속됩니다.
- 검증된 refresh token만 Windows 현재 사용자 DPAPI로 암호화 저장해 앱 재시작 뒤 자동으로 복구합니다.
- 비밀번호와 access token은 저장하지 않으며, 복구 시 offsl issuer·사용자·workspace 권한을 다시 검증합니다.
- 사용자가 별록 액션 연결 해제를 선택하면 tombstone을 먼저 기록해 자동복구를 확실히 중단합니다.
- 트레이와 로컬 로그에 자동 복구/재연결 상태를 개인정보 없이 표시해 다음 장애 진단이 가능합니다.
