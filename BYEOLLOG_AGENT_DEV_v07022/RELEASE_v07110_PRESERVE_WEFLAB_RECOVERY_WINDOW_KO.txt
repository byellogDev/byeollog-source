별록 에이전트 v0.7.0.110 · 위플랩 자동 복구 대기 보존

- 복구 중 명시적인 nologin/API 실패가 오면 고정 타임아웃을 끝까지 기다리지 않습니다.
- 응답이 전혀 없는 경우에는 기존과 동일하게 1차 30초, 2차 60초까지 자동 복구를 기다립니다.
- 자동 확인 중에도 상태 카드를 눌러 즉시 위플랩 로그인 화면을 열 수 있습니다.
- 사용자가 로그인 화면을 열면 자동 복구가 WebView를 다시 만들지 않고 즉시 제어권을 넘깁니다.
- 유효한 저장 세션의 무인 복구와 로그인 직후 자동 수집은 그대로 유지합니다.
