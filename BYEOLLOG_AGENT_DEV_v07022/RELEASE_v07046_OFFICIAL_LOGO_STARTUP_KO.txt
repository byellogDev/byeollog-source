별록 에이전트 v0.7.0.46

- 시작 화면의 레거시 꼬리 별 심볼을 제거했습니다.
- 별록 앱 전체에서 사용하는 공식 흰색 별록 로고를 시작 화면과 네이티브 대체 화면에 동일하게 적용했습니다.
- 중복 로고와 장식 요소를 줄이고 현재 준비 단계가 먼저 읽히도록 화면 구성을 다시 정리했습니다.
- 로그인 전에 화면·설정·방송 연결 리소스를 준비하는 기존 사전 로딩 동작은 유지합니다.
- WebView2가 늦거나 실패해도 공식 로고가 적용된 불투명 네이티브 화면으로 계속 시작합니다.
- 외부 웹 주소나 네트워크 이미지를 사용하지 않고 공식 로고를 프로그램 안에 포함합니다.

v0.7.0.45는 운영 피드에 배포하지 않은 폐기 디자인 기준본이며, v0.7.0.46이 이를 대체합니다.
