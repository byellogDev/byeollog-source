별록 에이전트 v0.7.0.66 · 자연음성 재생 수정

수정 사항
- 추첨 테스트 및 실제 송출 TTS가 Windows 기본 음성으로 재생되던 문제를 수정했습니다.
- NAudio의 바이트 기반 출력 버퍼를 안전한 샘플 단위로 기록하도록 변경했습니다.
- 자연음성 팩 준비 또는 재생 실패를 Windows 기본 음성으로 조용히 대체하지 않습니다.
- 테스트 송출과 실제 추첨 액션이 동일한 로컬 MeloTTS 음성과 재생 경로를 사용합니다.

검증
- 고정 SHA-256 MeloTTS 모델의 실제 ONNX 합성 통과
- 실제 Windows 오디오 장치 재생 통과
- AgentStore 및 전체 계약 테스트 통과

기준선
- 현재 소스 기준선은 0.7.0.66이며, 이전 공개 산출물은 수정하지 않습니다.
