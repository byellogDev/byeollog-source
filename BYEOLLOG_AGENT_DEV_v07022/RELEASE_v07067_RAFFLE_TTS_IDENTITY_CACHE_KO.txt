별록 에이전트 v0.7.0.67 · 추첨 당첨 음성 신원 보호

- 추첨함 봉인 시 당첨 후보 음성을 미리 준비해 당첨 발표 지연을 줄입니다.
- DB 실행 기록, TTS 요청, 서버 응답과 로컬 캐시를 하나의 당첨자 음성 키로 묶습니다.
- 음성 키·버전·SHA-256·WAV 형식 중 하나라도 일치하지 않으면 음성을 재생하지 않습니다.
- 다른 후보의 음성이나 변조된 캐시가 감지되면 해당 파일을 격리하고 당첨 화면만 송출합니다.
- 후보 이름은 캐시 파일명이나 manifest에 저장하지 않습니다.
- 고정 추첨권 안내 음성은 기존처럼 로컬에서 재생합니다.

이 버전은 v0.7.0.66 자동 업데이트 프로토콜과 사용자 설정·수집 기록을 그대로 보존합니다.
