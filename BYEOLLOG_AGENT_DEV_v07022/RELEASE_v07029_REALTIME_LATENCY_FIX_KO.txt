별록 에이전트 v0.7.0.29 · 공개판 27
실후원 자동화 지연 최우선 수정

[핵심 변경]

- 위플랩 실시간 후원 확인 주기를 5초에서 2초로 단축했습니다.
- 새 후원을 발견한 뒤 자동화 서버 전송 전 기다리던 최대 2.5초 묶음 대기를 제거했습니다.
- 서버가 실행 큐 생성을 응답하면 같은 프로세스의 Local Agent를 즉시 깨웁니다.
  기존 최대 2초 Agent 대기 주기는 장애 fallback으로만 남습니다.
- `sourceAgeMaxMs`, `mirrorElapsedMs`, 실행 큐 수를 개인정보 없이 로컬 로그에 기록합니다.
  다음 실후원에서 위플랩 자체 결과 노출 지연과 별록 내부 지연을 구분할 수 있습니다.
- v0.7.0.28의 OBS 브라우저 소스 자동 새로고침, 실제 상태·이미지 요청 확인,
  마이크 상태 검증과 복원 기능을 그대로 유지합니다.

[지연 경계]

- 별록이 제어하던 고정 대기의 이론상 최댓값을 9.5초에서 2초로 줄였습니다.
  (위플랩 조회 5초 + 전송 대기 2.5초 + Agent 대기 2초 → 위플랩 조회 2초)
- 네트워크·Supabase 처리 시간과 위플랩이 룰렛 결과를 실제 조회 API에 공개하기 전
  걸리는 시간은 별록이 직접 제거할 수 없습니다.
- 실제 후원 1회 검증 후 새 단계별 로그를 기준으로 남은 병목을 확정해야 합니다.
