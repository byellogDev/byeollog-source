별록 에이전트 0.7.0.117

- 기존 액션 OBS 주소는 액션만 출력하고, 새 `/overlay/wallpaper` 주소는 풍벽지만 출력하도록 분리했습니다.
- OBS에서 `별록 액션` 소스를 위에, `별록 풍벽지` 소스를 아래에 두는 전용 안내 화면을 추가했습니다.
- 에이전트 왼쪽 메뉴에 `별록 풍벽지` 탭을 추가하고 메인 화면의 `수집 목록 보기` 바로가기를 풍벽지 바로가기로 교체했습니다.
- 실행할 액션이 있으면 서버가 풍벽지 스냅샷을 기다리지 않고 액션을 먼저 반환합니다.
- 풍벽지 동기화 확인 주기를 5초로 분리해 유휴 트래픽을 줄였습니다.
