별록 에이전트 v0.7.0.65 · 추첨 실방송 안정화

- 추첨 오버레이를 OBS 브라우저 소스가 실제로 읽은 뒤에만 TTS와 성공 처리를 진행합니다.
- 아봉과 추첨이 동시에 실행될 때 화면·마이크·TTS 순서가 어긋나지 않도록 하나의 송출 순서로 동기화합니다.
- 일시 오류의 중간 ACK를 최종 실패로 표시하지 않고 서버 자동 재시도 결과를 기다립니다.
- 테스트 송출, 한 장씩 추첨, 동일 당첨 재송출의 성공·실패 안내를 실제 로컬 ACK 기준으로 표시합니다.
- 오래 대기하거나 발생 시각을 확인할 수 없는 이벤트는 추첨 원장만 보존하고 늦은 화면·TTS·마이크 동작은 실행하지 않습니다.
- 같은 위플랩 후원이 새 수집 세션에 다시 보이더라도 추첨권이 중복 지급되지 않도록 원본 식별자를 안정화합니다.
- 추첨 참여자·티켓·회차 총량 상한을 넘는 비정상 입력은 원본 후원 처리를 막지 않고 안전하게 비지급 처리합니다.

배포 메모
- 이 버전은 Supabase의 추첨 안정화 마이그레이션과 event-runtime-g3a 업데이트가 함께 적용되어야 합니다.
- 관리형 설치 사용자는 별록 시작 시 자동 업데이트로 수신하며 수동 재설치할 필요가 없습니다.
- 실행 파일의 공개 Authenticode 서명은 아직 적용되지 않았고, 업데이트 ZIP과 피드는 기존 RSA 서명으로 검증합니다.
- 현재 소스 기준선은 0.7.0.65이며, 0.7.0.64 산출물은 수정하지 않습니다.
