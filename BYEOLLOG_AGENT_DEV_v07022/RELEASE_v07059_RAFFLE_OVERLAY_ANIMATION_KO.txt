별록 에이전트 v0.7.0.59

변경 사항
- 추첨권 지급 오버레이를 투명 배경의 공식 추첨권 애니메이션으로 교체했습니다.
- 추첨 진행 오버레이를 별 장식 없는 추첨함에서 동일한 추첨권이 한 장 올라오는 애니메이션으로 교체했습니다.
- 추첨권은 완전히 나온 뒤 역재생하지 않고 처음 프레임으로 돌아가 다시 재생됩니다.

호환성
- 기존 추첨 액션 설정, 출력 위치·크기, 추첨권, 추첨 기록은 그대로 유지됩니다.
- 서버 데이터베이스 구조와 Supabase 런타임은 변경하지 않습니다.
- 관리형 설치 사용자는 시작 시 서명된 자동 업데이트로 새 버전을 받습니다.
