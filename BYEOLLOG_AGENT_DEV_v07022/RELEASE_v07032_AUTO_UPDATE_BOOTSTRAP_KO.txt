별록 에이전트 v0.7.0.32 / 공개판 30
안전한 자동 업데이트 시작판

[새 기능]

- 다음 공개판부터 별록 에이전트가 새 버전을 백그라운드에서 자동으로 확인하고 준비합니다.
- 실행 중인 방송·수집·아봉·마이크를 종료하거나 재시작하지 않습니다.
- 새 버전은 별도 불변 버전 폴더에 완전히 설치·검증한 뒤 다음 실행 포인터만 전환합니다.
- 현재 버전과 직전 버전을 함께 보존해 기존 수동 롤백 기능을 유지합니다.

[공급망 보호]

- HTTPS만으로 신뢰하지 않고, 별록 오프라인 RSA-3072 공개키로 업데이트 카탈로그의 RSA-PSS-SHA256 서명을 확인합니다.
- 서명 도구는 선택한 인증서가 에이전트에 고정된 공개키와 정확히 일치할 때만 카탈로그를 만듭니다.
- 서명된 ZIP 크기·SHA-256과 ZIP 내부 release-manifest의 SHA-256을 모두 확인합니다.
- ZIP 경로 탈출, 심볼릭 링크, 중복·예상 외 파일, 과대 압축 해제를 거부합니다.
- 서명·해시·다운로드·사전 실행 검사 중 하나라도 실패하면 현재 검증 버전을 그대로 유지합니다.
- Windows Authenticode 인증서는 이번 기능과 별개이며 기존 방침대로 추후 도입할 수 있습니다.

[설치 전환]

- v0.7.0.32는 자동 업데이트 기능을 심는 최초 공개 설치판이므로 이번 한 번은 ZIP을 받아 INSTALL_AND_CHECK.cmd로 설치해야 합니다.
- v0.7.0.33 이후부터는 설치된 Launcher를 통해 자동 업데이트됩니다.
- 단독 EXE 실행은 관리형 설치 포인터를 사용하지 않으므로 자동 업데이트 대상이 아닙니다.

[업데이트 동작]

- 설치된 Launcher가 현재 검증 버전을 실행한 뒤 별도 백그라운드 프로세스로 새 버전을 확인합니다.
- 다운로드와 설치가 끝나도 실행 중인 별록은 건드리지 않고, 다음 실행부터 새 버전을 사용합니다.
- 업데이트용 Launcher 프로토콜 v1은 이번 시작판에 고정하며, 이후 앱 본체만 서명된 새 버전 폴더로 갱신합니다.
- 네트워크·디스크·서명 검증 오류는 현재 앱 실행을 막지 않으며, 15분이 지난 뒤 다음 앱 실행에서 다시 확인합니다.

[보존되는 항목]

- v0.7.0.30의 OBS 오버레이 성공 판정과 실후원 지연 개선을 모두 유지합니다.
- `%LOCALAPPDATA%\ByeollogAgent`의 로그인 프로필, 설정, 규칙, SQLite, 업로드·ACK 상태를 변경하지 않습니다.
- 업데이트 오류는 `%LOCALAPPDATA%\ByeollogAgent\updates\update-state.json`에 개인정보 없는 오류 코드로만 기록합니다.
- 운영 DB·Supabase 스키마 변경은 없습니다.
