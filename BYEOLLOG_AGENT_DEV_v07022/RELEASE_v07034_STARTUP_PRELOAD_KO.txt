별록 에이전트 v0.7.0.34 / 공개판 32

- 실행 직후 WebView2와 무관한 네이티브 로딩 창을 먼저 표시합니다.
- 로그인 화면과 메인 화면의 WebView2 컨트롤, 로컬 HTML, 최초 상태를 로그인 전에 미리 준비합니다.
- 로그인 성공 뒤에는 준비된 메인 화면만 표시해 검은 화면 대기를 없앴습니다.
- 현행 관리형 바로가기는 PowerShell/CMD를 거치지 않고 검증된 EXE를 직접 실행합니다.
- current.json이 바뀌면 이전 버전 EXE가 manifest와 SHA-256을 확인한 뒤 현재 버전으로 조용히 넘깁니다.
- 다른 설치 루트와 구버전 바로가기·버전 폴더는 삭제하거나 덮어쓰지 않습니다.
- 같은 이름의 바로가기가 다른 설치본에 속하면 `별록 최신` 이름으로 분리합니다.
