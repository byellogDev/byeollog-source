# 별록 에이전트 v0.7.0.25 인계

## 기준선

- 제품 버전: `0.7.0.25`
- 공개 표시: `0.7.0 공개판 23`
- 소스 기준: `BYEOLLOG_AGENT_DEV_v07022`

## 이번 변경

- 일반 사용자 트레이 메뉴를 열기, 상태, 계정 연결 해제, 종료 중심으로 단순화했다.
- 진단·더미 데이터·실기기 검증 등은 `BuildInfo.ShowInternalTesterTools` 게이트 뒤에 보존했다.
- OBS 마이크 설정 카드에 초보자용 WebSocket 연결 4단계 안내를 추가했다.
- 사용자가 OBS 브라우저 소스를 초기화하고 1920×1080으로 재등록한 뒤 오버레이 위치·크기 문제가 해소됨을 확인했다. 서버 저장값과 송출 좌표는 정상으로 판정한다.

## 비회귀

- 기존 사용자 설정, 로그인, 업보 규칙, 별록 액션, 실행 이력, 업로드 큐를 보존한다.
- 운영 서버·DB·Auth·Storage·Edge·Vercel 변경 없음.
- 공개판은 무서명 배포를 유지하며 코드 서명은 후속 과제다.

## 다음 확인

1. 새 빌드에서 트레이 메뉴가 단순화됐는지 확인한다.
2. 마이크 설정의 OBS 연결 안내가 잘림 없이 보이는지 확인한다.
3. OBS 브라우저 소스 1920×1080에서 사용자 지정 위치·크기를 실방송이 아닌 상태로 1회 확인한다.
