별록 에이전트 v0.7.0.64 · 로컬 자연음성

- 추첨권 지급: “시청자님께 추첨권 한 장 드렸어요!” 말투로 변경했습니다.
- 추첨 당첨: “시청자님, 당첨을 축하드려요!” 말투로 변경했습니다.
- 앱 시작 후 검증된 한국어 MeloTTS ONNX 음성팩을 백그라운드에서 준비합니다.
- 합성 문장과 사용자 정보는 외부 서버로 보내지 않고 사용자 PC에서만 합성합니다.
- 음성팩은 고정 HTTPS 소스·크기·SHA-256을 모두 검증한 뒤 사용합니다.
- 음성팩 준비 실패, 지원하지 않는 닉네임, 출력 장치 오류에서는 기존 Windows TTS로 안전하게 전환합니다.
- 기존 추첨 오버레이, 액션 실행, ACK는 TTS 실패와 무관하게 계속 진행합니다.
- 선택된 음성 설정: 속도 +25%, 자연 발화 파라미터, 전역 피치 약 +29Hz.

배포 메모
- 첫 실행에서 음성팩 약 87MB를 한 번 내려받습니다.
- 음성팩 준비 전 테스트/실제 송출은 Windows TTS로 재생될 수 있습니다.
- 현재 소스 기준선은 0.7.0.64이며, 0.7.0.63 산출물은 수정하지 않습니다.
