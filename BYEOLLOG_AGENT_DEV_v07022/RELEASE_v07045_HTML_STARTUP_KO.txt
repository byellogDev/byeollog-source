별록 에이전트 v0.7.0.45

- 시작 화면을 760×450 크기의 HTML 기반 디자인으로 전면 개편했습니다.
- X 버튼을 우상단의 일관된 여백과 크기로 정리했습니다.
- 현재 준비 단계와 진행률을 설정 확인·화면 준비·방송 연결·준비 완료 순서로 보여줍니다.
- 로그인과 방송 설정이 유지된다는 안내를 시작 화면에서 바로 확인할 수 있습니다.
- HTML 화면이 준비되기 전에는 불투명한 네이티브 화면을 즉시 표시해 흰 화면이나 투명 깨짐을 막습니다.
- WebView2 시작이 늦거나 실패해도 네이티브 화면으로 계속 진행하므로 앱 시작을 막지 않습니다.
- 외부 웹 주소나 네트워크 자산을 사용하지 않고 프로그램에 포함된 HTML/CSS/SVG만 표시합니다.
- 창 드래그와 시작 취소 기능을 새 HTML 화면에서도 유지합니다.

기존 v0.7.0.44 위플랩 무인 세션 복구 동작과 사용자 설정·수집 데이터는 그대로 보존합니다.
