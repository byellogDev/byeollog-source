별록 에이전트 0.7.0.124

- SOOP 이미지 주소와 응답 헤더가 JPEG여도 실제 파일이 PNG이면 파일 서명을 기준으로 올바르게 저장하고 표시합니다.
- 이전 버전이 이미지 주소 없이 저장한 풍벽지 상태를 시작 시 감지하고 서버의 전체 스냅샷을 자동으로 다시 받아 복구합니다.
- 같은 풍벽지 이미지가 여러 카드에 쓰일 때 한 번만 내려받고 로컬 콘텐츠 주소를 재사용합니다.
- 새 풍벽지 이미지 중 하나라도 준비되지 않으면 빈 카드 상태를 저장하지 않고 기존 OBS 화면을 그대로 유지합니다.
- 액션 Realtime 즉시 실행, 후원 알림, DB 영속 큐, 장치 lease, 로컬 ACK outbox 동작은 변경하지 않습니다.
