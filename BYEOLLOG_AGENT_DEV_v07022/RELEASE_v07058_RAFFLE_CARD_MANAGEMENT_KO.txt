별록 에이전트 v0.7.0.58

변경 사항
- 상단의 독립된 추첨 관리 탭을 제거했습니다.
- 설정된 추첨 액션 카드에 추첨 관리 버튼을 추가했습니다.
- 추첨 카드에서 추첨 관리, 테스트 송출, 수정, 삭제를 한곳에서 시작할 수 있습니다.
- 추첨 관리 화면에 액션 목록으로 돌아가는 버튼을 추가했습니다.

호환성
- 기존 추첨권, 추첨 라운드, 당첨 기록과 액션 설정은 그대로 유지됩니다.
- 서버 데이터베이스 구조와 Supabase 런타임은 변경하지 않습니다.
- 관리형 설치 사용자는 시작 시 서명된 자동 업데이트로 새 버전을 받습니다.
