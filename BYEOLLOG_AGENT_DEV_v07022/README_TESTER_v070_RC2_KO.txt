별록 에이전트 v0.7.0.32 · 안전한 자동 업데이트 시작판

[설치 및 실행]

1. Tester ZIP을 새 폴더에 완전히 풉니다.
2. INSTALL_AND_CHECK.cmd를 실행합니다.
3. 설치가 끝나면 LAUNCH_BYEOLLOG.cmd로 별록 에이전트를 실행합니다.
4. 기존 별록 계정으로 로그인합니다.

[자동 업데이트]

- 이번 버전은 자동 업데이트를 시작하기 위한 최초 설치판입니다.
- 이번 ZIP만 한 번 `INSTALL_AND_CHECK.cmd`로 설치하면 다음 공개판부터 새 버전을 백그라운드에서 확인하고 검증해 준비합니다.
- 업데이트는 별록이 실행 중인 방송·아봉·마이크를 강제로 종료하지 않으며, 준비된 새 버전은 다음 실행부터 적용됩니다.
- 서명이나 SHA-256이 맞지 않거나 다운로드가 중단되면 기존 검증 버전을 그대로 실행합니다.
- 단독 EXE를 바로 실행하지 말고 설치된 시작 메뉴의 `별록 에이전트` 또는 `LAUNCH_BYEOLLOG.cmd`를 사용해야 자동 업데이트가 동작합니다.

[이번 버전의 별록 액션]

- 기존 `방송 자동화` 메뉴 이름을 `별록 액션`으로 바꿨습니다.
- 액션 카드의 `테스트 송출`을 누르면 확인 후 실제 마이크와 오버레이가 한 번 실행됩니다.
- 방송 중 테스트하면 시청자에게 보일 수 있으므로 확인창을 반드시 읽어주세요.
- 10초 아봉 도중 10초 아봉이 다시 들어오면 마이크와 화면을 중간에 복원하지 않고 10초를 더합니다.
- 연속 세션은 안전을 위해 최대 15분까지만 누적합니다.

[후원 조건]

- 이벤트가 `후원`이면 입력칸은 `고정 별풍선`입니다.
- 444개로 저장한 규칙은 별풍선이 정확히 444개일 때만 실행됩니다.
- 443개와 445개를 포함해 미만·초과 후원에는 실행되지 않습니다.
- 이벤트가 `룰렛 결과`이면 별풍선 금액 없이 룰렛 결과 이름만으로 실행됩니다.

[위플랩 로그인 복구]

- 수집 중 위플랩 세션이 만료되면 재로그인이 필요하다는 안내와 로그인 화면이 즉시 표시됩니다.
- 위플랩 로그인을 완료하면 별록이 수집 스크립트를 자동으로 다시 연결합니다.
- 로그인 비밀번호나 위플랩 쿠키를 별도 파일로 복사하거나 저장하지 않습니다.

[룰렛 결과 분리]

- 결과 이름에 `&`가 있으면 각 부분을 독립 결과로 저장합니다.
- 예: `A 단컷 & A 네컷 & A 세컷` → `A 단컷`, `A 네컷`, `A 세컷`

[확인 순서]

1. 별록 액션 → 액션 추가 → 아봉 → 조건 설정으로 이동합니다.
2. 이벤트를 `후원`으로 고릅니다.
3. `고정 별풍선`에 444를 입력합니다.
4. 저장 전 확인 문장이 `별풍선이 정확히 444개이면`으로 표시되는지 확인합니다.
5. 제어 방식, 실행 시간, 출력 화면을 선택해 저장합니다.

[보존되는 항목]

- 안정판 v0.5.1.8 및 기존 설치 버전
- %LOCALAPPDATA%\ByeollogAgent의 사용자 설정과 수집 데이터
- 기존 로그인, 룰렛·고정 규칙, 업로드 큐
- 기존 Collector API·JSON·source_scope 호환 계약

[복구 및 지원]

- VERIFY_INSTALL.cmd: 현재 설치와 manifest 검증
- ROLLBACK_LAST_VERSION.cmd: 직전 검증 버전으로 실행 포인터 복구
- RESTORE_PREUPDATE_STATE.cmd: 별도 확인 후 사용자 상태 snapshot 복원
- CREATE_SUPPORT_BUNDLE.cmd: 비밀번호·토큰·원문 로그를 제외한 지원 자료 생성

Tester 패키지는 `trusted_channel_internal` 무결성 모드로 봉인되며, 지원 자료는
개인 공개 채널이 아닌 별록 내부 확인 경로로만 전달합니다.

운영 DB에는 `dispatch_guided_rule_test_v2`가 적용되어야 아봉과 추첨 테스트 송출 버튼을 사용할 수 있습니다.
