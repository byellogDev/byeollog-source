별록 에이전트 v0.7.0.47

[배포 대체] 고정 760×450 배치가 실제 DPI 환경에서 작고 잘리는 문제가 확인되어 v0.7.0.48로 교체했습니다.

- 앱 실행 즉시 표시되는 네이티브 시작 화면을 공식 HTML 디자인과 같은 구성으로 다시 만들었습니다.
- 기본 Windows 흰색·초록색 ProgressBar와 잘린 STARTING 배지를 제거했습니다.
- 공식 별록 로고, 현재 단계, 원형 준비 표시, 별록 전용 진행 카드가 첫 프레임부터 나타납니다.
- HTML WebView2가 준비되기 전에 사전 로딩이 끝나더라도 예전 시작 화면이 노출되지 않습니다.
- HTML 화면이 늦거나 실패하는 경우에도 같은 디자인 언어의 네이티브 화면으로 계속 시작합니다.

v0.7.0.46의 공식 로고·사전 로딩·위플랩 자동 세션 복구와 기존 사용자 데이터는 그대로 보존합니다.
