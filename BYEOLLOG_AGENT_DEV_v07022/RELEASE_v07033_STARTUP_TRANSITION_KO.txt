별록 에이전트 v0.7.0.33 / 공개판 31

이번 업데이트
- 로그인 성공 뒤 로그인 창이 먼저 사라지고 메인 창이 늦게 나타나던 전환을 개선했습니다.
- 로그인 화면이 유지되는 동안 메인 창과 WebView2 환경을 미리 준비합니다.
- 메인 UI를 먼저 표시한 뒤 숨은 위플랩 브라우저와 후속 네트워크 초기화를 진행합니다.
- 다크·화이트 모드에 맞는 배경을 즉시 적용해 빈 화면 노출을 줄였습니다.
- 로그인 창을 옮겨 둔 경우 메인 창이 같은 위치에서 이어지도록 했습니다.
- 메인 화면 준비만 실패하면 비밀번호와 장치 등록을 반복하지 않고 화면 준비만 다시 시도합니다.
- 초기화가 끝난 뒤 창을 뒤늦게 앞으로 다시 끌어오는 동작을 제거했습니다.

자동 업데이트
- v0.7.0.32 설치형 사용자는 시작 메뉴의 '별록 에이전트'로 실행하면 서명된 업데이트를 받습니다.
- 업데이트는 현재 실행을 강제 종료하지 않으며 다음 실행부터 v0.7.0.33을 사용합니다.
- 기존 로그인 프로필, 위플랩 세션, OBS·마이크 설정, 규칙, 수집 데이터는 유지합니다.

검증
- Node 계약 110개
- AgentStore 310개
- self-contained Windows x64 Release 빌드
- v0.7.0.32 updater protocol v1 호환 패키지 및 RSA-PSS-SHA256 카탈로그 검증

알림
- Windows Authenticode 공개 인증서는 아직 적용하지 않았으므로 새 PC에서 Windows 경고가 나타날 수 있습니다.
- 이 안내는 v0.7.0.33 변경 기록이며 자동 업데이트 ZIP 내부의 설치 도구는 v0.7.0.32 protocol v1 바이트를 그대로 보존합니다.
