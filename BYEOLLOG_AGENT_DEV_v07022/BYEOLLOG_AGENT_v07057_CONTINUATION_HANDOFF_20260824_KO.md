# 별록 에이전트 v0.7.0.57 인계

기준선은 `v0.7.0.57`이다. v0.7.0.56 및 이전 산출물은 불변으로 유지한다.

## 핵심 변경

- 관리형 설치에서는 로딩창이 표시된 뒤 업데이트 확인 프로세스의 완료를 기다린다.
- updater가 새 `current.json`을 커밋하면 exit code 10으로 설치 성공을 호출자에게 알린다.
- 현재 프로세스는 새 current 버전의 EXE와 manifest SHA-256을 다시 검증한 뒤 `--continue-after-update <pid>`로 실행한다.
- 신버전은 구버전 PID가 완전히 끝날 때까지 최대 30초 기다린 후 정상 시작한다. 따라서 mutex 경합이나 ‘이미 실행 중’ 알림 없이 한 번의 실행으로 전환된다.
- 레거시 PowerShell 런처가 동시에 updater를 띄운 경우, 앱 updater는 설치 잠금을 기다리며 current 포인터가 새 버전으로 바뀌면 동일한 성공 코드로 합류한다.
- 설치 실패·네트워크 실패는 현재 검증 버전으로 fail-open 한다.

## 비회귀

- 다운로드·서명·ZIP·manifest·preflight·원자적 포인터 전환 검증은 그대로 유지한다.
- updater는 방송 중인 기존 프로세스를 강제로 종료하지 않는다. 자동 전환은 로그인·방송 화면이 열리기 전 시작 단계에서만 수행한다.
- portable EXE는 기존과 같이 관리형 자동 업데이트 대상이 아니다.
