별록 에이전트 v0.7.0.21 · 공개판 19

이번 공개판
- 사용자 기능 이름을 `방송 자동화`에서 `별록 액션`으로 통일했습니다.
- 각 아봉 액션 카드의 수정·삭제 버튼 왼쪽에 `테스트 송출`을 추가했습니다.
- 테스트 확인 후 선택한 PC에서 실제 마이크 제어와 오버레이를 한 번 실행합니다.
- 온라인 상태와 지원 기능이 최근 확인된 PC에만 테스트를 보냅니다.
- 같은 마이크의 아봉이 겹치면 기존 종료 시각에 새 실행 시간을 그대로 더합니다.
- 누적 중에는 마이크를 다시 켜거나 오버레이를 숨기지 않고, 최종 시각에 한 번만 원상 복구합니다.
- 시작 복구 검사는 작업 수신 전에 한 번만 끝내므로 실행 중인 아봉이 후속 아봉의 누적을 막지 않습니다.
- 연속 음소거 안전 상한은 15분이며 로컬 실행과 ACK 전송은 제한된 동시성으로 처리합니다.

보존 사항
- 기존 로그인, 수집, 룰렛, 업보, 장치 등록, OBS/Windows 마이크 설정을 유지합니다.
- 기존 규칙, 실행 이력과 패키지 오버레이 이미지 키를 그대로 사용합니다.
- 사용자 설정 및 수집 데이터는 %LOCALAPPDATA%\ByeollogAgent 에서 그대로 사용합니다.
- 데이터 삭제, DROP/TRUNCATE, Auth·Storage, 비밀키, DNS·결제 변경은 없습니다.
