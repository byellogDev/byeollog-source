# 별록 에이전트 v0.7.0.62 인계

기준선은 v0.7.0.62이다. v0.7.0.61 및 이전 산출물은 불변으로 유지한다.

## 핵심 변경

- 추첨권 지급과 당첨 발표 오버레이에 Windows 내장 한국어 TTS를 함께 재생한다.
- 티켓 수는 한국어 단위 표현으로 변환한다. 예: 1장 → 한 장, 2장 → 두 장, 135장 → 백 서른다섯 장.
- 추첨권 지급·당첨 발표 TTS 음량을 각각 저장하며 기본값은 80%, 허용 범위는 0~100%이다.
- 위치·크기 조정창 안에서 음량을 조절하고 즉시 테스트 재생할 수 있다.
- DB 저장 계약은 save_guided_rule_v11이며, 실행 큐에는 저장된 액션별 음량만 서버가 주입한다.
- 음성 합성 실패는 오버레이 실행을 실패시키지 않으며, 0%는 해당 TTS만 생략한다.
- 기존 추첨 규칙·추첨권·좌표·배율·GIF 자산과 아봉 동작은 유지한다.

## 검증 기준

- Agent Node 계약 전체 통과
- AgentStore/Local Agent 전체 통과
- .NET 8 Release publish 성공
- protocol v1 설치 루트 비트 보존
- package manifest v2 검증과 ZIP 왕복 검증
- RSA-PSS-SHA256 서명 피드와 공개 ZIP의 바이트 일치
- 운영 Supabase v11 함수 권한과 실행 트리거 활성 상태 확인

## 운영 범위

- Supabase에는 additive v11 함수와 실행 전 음량 주입 트리거만 추가한다.
- Agent 정적 업데이트 피드와 immutable ZIP을 갱신한다.
- Auth, Storage, Edge Function, 기존 사용자 데이터는 변경하지 않는다.
