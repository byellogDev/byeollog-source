별록 에이전트 v0.7.0.135

- OBS 액션이 실제 첫 화면을 그린 시점과 풍벽지 이미지 준비 완료 시점을 익명 지연 수치로 기록합니다.
- 이미지 디코딩과 두 번의 화면 페인트를 확인하며, 영상 액션은 실제 영상 프레임이 표시된 뒤 기록합니다.
- 계측 전송은 화면 표시 이후 별도 비동기 큐에서 실행되어 액션·후원 알림·풍벽지 반영·ACK를 기다리게 하지 않습니다.
- 네트워크 오류나 서버 지연 시 계측만 생략하고 사용자 기능은 정상 진행합니다.
- 후원자명, 메시지, 이미지 주소 등 개인정보와 콘텐츠는 계측 데이터에 포함하지 않습니다.
