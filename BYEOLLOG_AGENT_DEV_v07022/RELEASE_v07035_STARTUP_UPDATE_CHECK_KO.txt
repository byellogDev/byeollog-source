별록 에이전트 v0.7.0.35 / 공개판 33

- 관리형 별록을 실행할 때마다 작은 서명 업데이트 피드를 백그라운드에서 한 번 확인합니다.
- 별록 화면을 먼저 실행한 뒤 별도 숨김 프로세스가 확인하므로 네트워크가 느려도 시작 화면을 기다리게 하지 않습니다.
- 새 버전은 방송 중인 프로세스를 종료하지 않고 검증·설치한 뒤 다음 실행부터 적용합니다.
- 인터넷 오류와 서버 오류는 현재 버전 실행을 방해하지 않습니다.
- 기존 6시간 예약 값은 호환용으로만 읽고 더 이상 업데이트 확인을 건너뛰는 조건으로 사용하지 않습니다.
- 여러 구버전 폴더와 별도 설치 루트·다른 바로가기는 그대로 보존합니다.
