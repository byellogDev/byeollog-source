별록 에이전트 v0.7.0.51

- 로그인보다 먼저 나타나는 네이티브 시작 화면에서 긴 한국어 문구의 마지막 단어가 잘리거나 줄바꿈되던 문제를 수정했습니다.
- 제목과 설명을 측정과 출력이 같은 단일행 GDI 렌더링으로 통일하고, 실제 DPI에 맞춰 필요한 경우에만 자연스럽게 축소합니다.
- 실제 Windows 150% 배율에서 `내 설정을 안전하게 확인하는 중`이 끝 글자까지 표시되는 것을 확인했습니다.
- 1040×640 고정 레이아웃을 유지하므로 100%와 150% 모두에서 로고, 진행 카드, 하단 문구가 흔들리거나 잘리지 않습니다.
- WebView2 전환 뒤에도 긴 제목과 설명은 실제 표시 폭에 맞춰 자동 조정됩니다.
- 기존 로그인, 방송 설정, 수집 데이터와 자동 업데이트 설치 구조는 유지합니다.
