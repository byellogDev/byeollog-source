별록 에이전트 v0.7.0.30 / 공개판 28
OBS 오버레이 성공 판정 수정

[수정 내용]

- 테스트 송출에서 마이크와 오버레이가 정상 실행됐는데도 액션 기록이
  `확인 필요`로 표시되던 문제를 수정했습니다.
- OBS 브라우저 소스는 에이전트 재시작 뒤에도 동일한 검증된 이미지를
  메모리에 유지할 수 있습니다. 이때 화면은 정상 표시되지만 같은 이미지
  파일을 다시 요청하지 않아 기존 판정이 실행을 실패로 잘못 보고했습니다.
- 이제 이번 실행 중 OBS 브라우저 소스가 `활성 상태`를 실제로 읽었는지를
  성공 근거로 사용합니다. 이미지 파일은 화면 활성화 전에 기존과 동일하게
  별록 허용 목록과 SHA-256으로 검증합니다.
- 진단 로그에 활성 상태 확인 증가량과 이미지 요청 누계를 함께 기록합니다.

[유지되는 개선]

- v0.7.0.29의 실후원 지연 개선을 그대로 유지합니다.
  - 위플랩 결과 확인 주기 2초
  - 수집 직후 서버 즉시 전송
  - 실행 생성 직후 로컬 Agent 즉시 깨우기
- OBS/Windows 마이크 복원, 오버레이 위치·크기, 테스트 송출,
  위플랩 세션 복구, 룰렛 `&` 분리 동작을 유지합니다.

[호환성]

- 기존 설정과 `%LOCALAPPDATA%\ByeollogAgent` 데이터는 보존합니다.
- 운영 서버·DB 스키마 변경은 없습니다.
- 기존 v0.7.0.29 설치 위에서 실행할 수 있습니다.

[테스트]

- 정상 표시 상태를 읽었지만 동일 이미지 파일을 다시 요청하지 않는
  OBS 캐시 시나리오를 성공으로 판정하는 회귀 테스트를 추가했습니다.
- 활성 상태를 읽지 않은 경우는 계속 실패로 판정합니다.
